# MCP 를 고쳤으면 확인한다

**절차의 정본은 [mcp_server/README.md](../../../mcp_server/README.md) §6 이다** —
무엇을 고쳤을 때 무엇을 도는지, 명령까지 거기 있다. 여기 베껴 두지 않는다(한쪽만
고쳐지면 사람마다 다른 절차를 따르게 된다). 먼저 그 절을 읽어라.

아래는 **에이전트가 그 절차를 밟을 때만 걸리는 것들**이다.

## 밟게 되는 함정

- **`claude -p` 를 Bash 로 부르면 멈춘다** — stdin 이 없어서다. PowerShell 로
  부를 것. 그리고 윈도우에서는 `claude` 가 아니라 `claude.cmd` 다(경로를 직접
  넘길 때).
- **프로브를 배경으로 돌릴 때 서버 출력을 파이프로 잡지 마라.** 안 읽으면 버퍼가
  찬 순간 서버가 멈추고, 그러면 「그 도구가 서버를 죽였다」 처럼 보인다. 파일로
  받아라(`probe.py` 는 그렇게 한다).
- **오류라고 다 결함은 아니다.** 없는 물성으로 채택을 시도하면 「담을 값이
  없습니다」 가 맞는 답이다. 무엇을 물었는지와 함께 읽어라.
- **AI 검증 과제에 「바로 담아 줘」 류를 넣으면 정말로 쓴다.** 개발 DB 가 바뀐다 —
  사용자에게 먼저 말하고, 무엇이 바뀌었는지 확인해 보고할 것.
- **점검용 토큰은 끝나고 폐기한다.** 발급했으면 그 자리에서 폐기까지 하나의 일로
  본다.

## 고치고 나면

도구를 더했으면 `mcp_server/README.md` §5 의 목록과 개수도 함께 고친다 — 한 번은
도구가 41개인데 문서가 4개 시절 그대로였다.
