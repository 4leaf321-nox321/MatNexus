00 / 위치Starter 안에서의 자리

Radioss 는 파일이 둘로 갈립니다. Starter(_0000.rad) 가 모델 전부 — 절점·요소·물성·파단 — 를 담고, Engine(_0001.rad) 은 시간·출력·제어만 담습니다. 물성 카드는 전부 Starter 에 있습니다.

참조 사슬은 요소 → /PART → (/PROP, /MAT) 입니다. 파단은 물성에 얹힙니다.

/PART/1
part_title
#  prop_ID   mat_ID   subset_ID
         1        1        0

/MAT/LAW36/1/1        ← /MAT/LAW<번호>/<mat_ID>/<unit_ID>
DP600 sheet

/FAIL/TAB1/1          ← /FAIL/<모델>/<mat_ID>  ← 재료에 직접 붙는다

/FAIL 은 자기 ID 가 아니라 붙일 재료의 ID 를 씁니다. 이것이 Radioss 파단 카드의 핵심 규칙이고, 하나의 재료에 여러 /FAIL 을 붙일 수 있습니다 — 먼저 만족되는 기준이 이깁니다.

/UNIT — 카드마다 단위를 선언한다

Radioss 가 다른 명시적 솔버와 확연히 다른 점입니다. unit_ID 를 카드 끝에 붙이면 그 카드의 숫자를 어떤 단위로 읽을지 선언할 수 있고, Starter 가 모델 단위계로 자동 환산합니다.

/UNIT/1
model units: kg mm ms
#          MU_M                MU_L                MU_T
             kg                  mm                  ms

/UNIT/2
supplier data in SI
             kg                   m                   s

순서는 질량 · 길이 · 시간입니다 — 길이를 앞세워 적는 실수가 흔한데, kg 과 mm 은 서로 자리를 바꿔도 문법 오류가 나지 않습니다.

이 기능 덕분에 공급사가 SI 로 준 카드를 그대로 붙여 넣고 unit_ID 만 2 로 지정할 수 있습니다. 다만 /BEGIN 블록에 모델 전체의 작업 단위계가 선언돼 있어야 하고, unit_ID 를 0 이나 빈칸으로 두면 모델 단위계로 읽습니다 — 이 기본값을 잊고 SI 숫자를 넣는 것이 가장 흔한 사고입니다.

충돌 해석의 관용 단위계

kg · mm · ms (힘 kN, 응력 GPa) 와 ton · mm · s (힘 N, 응력 MPa) 가 대부분입니다. Radioss 문서의 필드 단위는 SI(kg·m·s, Pa)로 적혀 있으므로, 문서의 “Pa” 를 그대로 믿고 210e9 를 넣으면 mm 계 모델에서는 완전히 틀립니다.

필드뜻기본값 · 주의
ε_p^max요소 삭제 소성변형률기본 1e20
ε_t항복응력이 줄기 시작하는 인장변형률기본 1e20 — 연화 시작점

ε̇_i각 함수의 변형률속도엄격한 오름차순
fct_ID_E, E_inf, C_E탄성계수 감소E(ε_p) = E − (E−E_inf)(1−exp(−C_E·ε_p)). 판재 스프링백에

함수의 첫 점은 (0, σ_y)

“항복응력 함수의 첫 점은 소성변형률 ε_p 가 0 이어야 한다” 는 것이 문서의 명시적 요구입니다. 그리고 넣는 값은 진응력 대 진소성변형률입니다 — 공칭을 넣으면 대변형에서 조용히 낮은 응력으로 계산됩니다.

탄성계수 감소(E_inf, C_E)는 판재 성형의 스프링백에서 의미가 큽니다. 실제 강판은 소성이 쌓이면 제하 기울기가 10~20% 낮아지는데, 이것을 무시하면 스프링백을 일관되게 작게 예측합니다.

구조가 단순합니다 — ID, 제목, (x, y) 쌍의 나열. 물성·파단·접촉 어디서든 이 ID 로 부릅니다. /TABLE 은 독립변수가 둘 이상일 때(예: 삼축도 × 변형률속도) 씁니다.

표 밖으로는 외삽하지 않는다

가장 큰 x 를 넘어가면 마지막 값을 그대로 유지합니다. 속도 함수도 마찬가지라, 시험 최고 속도가 100/s 인데 해석에서 2000/s 가 나오면 그 구간은 100/s 물성으로 계산됩니다. Engine 출력에서 최대 변형률속도를 뽑아 대조하는 것이 검증 절차입니다.

07 / 비금속고무 · 폼 · 복합재

LAW42 (OGDEN) 이 고무의 기본입니다. μ_i, α_i 쌍을 최대 5개까지 주고, 비압축성 정도는 포아송비(0.495 부근)로 조절합니다. 점성이 필요하면 같은 카드에 Prony 항을 이어 붙입니다.

폼은 어떤 물리를 볼 것인지로 갈립니다 — 흡수 에너지가 목적이면 LAW70(압축 곡선 직접 입력)이 단순하고 확실합니다. 반발·이력이 중요하면 LAW77·LAW90 처럼 점성 항이 있는 쪽으로 갑니다.

복합재는 LAW25(COMPSH)가 중심입니다. Iform 으로 Tsai–Wu 와 CRASURV 를 고르는데, 충돌처럼 파손 후 거동이 필요하면 CRASURV 를 씁니다 — 손상 후 응력 감쇠를 방향별로 제어할 수 있기 때문입니다. 층 구성은 물성이 아니라 /PROP/TYPE11 (SH_SANDW) 또는 /PROP/TYPE17 (STACK) 에서 옵니다.

10 / 함정자주 틀리는 지점

  1. unit_ID 를 0 으로 두고 SI 숫자를 넣는다모델 단위계로 읽힙니다. mm 계 모델에 210e9 를 넣으면 자릿수가 통째로 어긋납니다.
  2. 문서의 “Pa” 를 그대로 믿는다Radioss 문서는 SI 기준으로 필드 단위를 적습니다. 실제 모델은 대개 mm 계입니다.
  3. /FAIL 의 ID 를 파단 자체의 번호로 오해한다/FAIL/JOHNSON/3 의 3 은 재료 ID 입니다. 다른 재료에 붙습니다.
  4. Ifail_sh 를 1 로 둔다적분점 하나만 파단해도 요소가 사라져 조기 파단이 됩니다. 5적분점이면 3 정도가 흔한 선택입니다.
  5. 속도 함수를 선형 보간(Fsmooth=1)으로 두고 자릿수로 벌린다0.001 과 100 사이를 선형 보간하면 중간 속도가 거의 최고 속도 곡선이 됩니다. 로그(2)로 둡니다.
  6. LAW2 에서 ρC_p 를 비운다온도항이 계산에 관여하지 않습니다. m 과 T_melt 만 채워 넣어도 아무 일이 일어나지 않습니다.
  7. 함수 첫 점의 x 가 0 이 아니다문서가 명시적으로 요구합니다. 초기 응답이 어긋납니다.
  8. 공칭 곡선을 넣는다진응력–진소성변형률이어야 합니다.
  9. ε_t / ε_m 을 기본값으로 두고 연화를 기대한다기본값이 1e20 이라 연화는 일어나지 않습니다.
  10. LS-DYNA 에서 변환한 파단 값을 그대로 믿는다재보정이 필요합니다(09장).
