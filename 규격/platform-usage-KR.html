00 / 한눈에데이터가 흐르는 길

고유 번호: 이름 대신 쓰는 식별자

층마다 번호 부여: 재료 M-000082, 시료 S-000041, 시편 P-000187, 시험 T-000203, 물성 카드 C-000038. 이름은 재료명 변경이나 다른 두께로의 이동 시 함께 바뀌나, 번호는 한 번 부여되면 불변. 삭제된 자료의 번호도 재사용하지 않음. 메신저 · 보고서 · 시편 라벨에서는 번호 사용 권장.

  • 재료 · 시험 화면 제목 옆 번호 선택 시 복사. 목록에서는 첫 열 「번호」.
  • T-203 · t203 처럼 줄여 입력해도 같은 번호로 인식.
  • 어느 목록에서든 어느 층의 번호로든 검색 가능. 시험 목록에 시편 번호 입력 시 그 시편의 시험, 재료 목록에 시험 번호 입력 시 해당 재료 표시.
  • 물성 카드 번호: 카드 줄의 번호 선택 시 복사. 「물성 카드」 목록 · 카드 고르기 창에서 카드 번호로, 재료 목록에서 카드 번호로 그 재료 검색 가능. 카드는 시료 · 시편 · 시험의 계층 밖이라 시편 · 시험 목록에서는 카드 번호로 검색되지 않음. 덱 머리의 근거 줄에 「카드 C-000038 · …」 로 기재.

재료 · 시험 목록의 찾기 칸에도 같은 세 방식 적용. 찾기 칸 옆 「상세 조건」 에서 이름 외 조건 추가, 「이 조건으로 찾기」 선택 시 적용(「초기화」 로 해제).

01 / 등록재료 · 시료 · 시편 등록

시험 등록 전 시료 · 시편 등록 필요. 층을 나눈 이유는 층마다 그 층에만 속하는 정보가 있기 때문: 재료에는 규격, 시료에는 로트, 시편에는 방향과 실측 치수.

재료

「재료」 목록 우측 상단 「재료 등록」 선택. 입력 칸은 다음과 같음.

  • Family · Category · Grade: 온톨로지에서 선택. Metal → Steel → SECC 처럼 단계적으로 범위 축소.
  • Details: 같은 규격을 구분하는 말(예: MDOI).
  • 스펙 두께 (mm): 재료의 기준 두께. 같은 Grade 라도 두께가 다르면 별도 재료로 등록.
  • 별칭 · 적용 제품 · 적용 파트 · 밀도 · 푸아송비: 선택 입력. 적용 제품 · 파트는 복수 선택 가능.

재료명은 입력값 기준 자동 생성(창의 「이름 (자동)」 에 미리 표시). 통칭은 별칭에 입력. 같은 이름의 재료가 이미 있으면 등록 불가(Details 로 구분 필요), 비슷한 재료가 있으면 경고만 표시(같은 재료이면 기존 재료 사용 권장).

복수 등록은 「여러 개 등록」 사용. 엑셀 표를 그대로 붙여 넣고, 한 줄에 재료 · 시료 · 시편 칸을 함께 기재. 재료 칸이 빈 줄은 윗줄의 재료에, 시료 칸이 빈 줄은 윗줄의 시료에 연결. 모든 칸이 채워진 표(DB 추출본 등)도 내용이 같은 재료는 하나로 합침(시료는 로트가 같을 때만 합침). 한 번에 최대 2,000줄.

새 Grade · 새 제조사 생성은 자료 관리자 권한. Family · Category · Grade · 제조사 · 거래처는 기존 값 선택은 누구나, 새 값 생성은 자료 관리자. 오타 하나(SECC / SECC강판)로 재료가 둘로 갈리면 이후 검색 · 통계 · 카드가 함께 갈리기 때문. 생성이 거부되면 비슷한 기존 값과 요청할 자료 관리자 이름을 함께 표시.

시료

사이드바에 「시료」 메뉴 없음. 재료 상세 「시료·시편」 탭의 「시료 추가」 로 등록. 입력 칸은 제조사 · 유통사 · 주 벤더 · 판매 유형 · 로트번호 · 별칭 · 생산일 · 밀도(이 로트 실측) · 메모, 전부 선택 입력. 시료 밀도는 해당 로트에서 실측한 경우에만 입력(카드가 재료의 공칭 밀도보다 우선 사용). 푸아송비 · 적용 제품은 로트마다 달라지는 값이 아니므로 재료에 기재. 시료명은 재료별 일련번호로 부여되므로 로트번호를 나중에 입력해도 이름 불변.

시료 목록 머리의 「밀시트」 선택 시 「밀시트 — 〈시료명〉」 창 표시. 「밀시트가 준 값」 에 해당 로트 성적서 값(항복강도 · 인장강도 · 연신율 등)을 근거 문서와 함께 기재. 기재 후 「우리가 잰 값과 비교」 표에 밀시트 값 · 우리가 잰 값(채택된 처리 결과만 집계) · 차이 · 근거 문서 병기. 합부 판정 미수행(허용 차이는 규격 · 용도가 결정). 자료 관리자는 같은 창에서 밀시트 값 승인 가능.

시편

시료 선택 후 「시편 추가」.

  • 방향: MD · TD · DD · NA(기본 MD, NA 는 방향이 무의미한 시험용). 방향은 절취 시점에 결정, 번호는 방향별 연번.
  • 시편 규격: 온톨로지에서 선택. 규격이 치수 칸을 결정.
  • 치수: 「이 시편이 규격과 다르면 적으세요 (보통은 비웁니다)」 안의 두께 · 폭 · 게이지 길이(mm). 통상 공란.

치수 출처는 세 곳이며 우선순위는 아래 순서.

순위출처화면 표시
1시험 파일이 잰 값「이 시험이 잰 값」
2시편에 기재한 값「시편에 적힌 값」
3규격의 공칭 치수「규격 공칭」

시편 목록에서 실측이 아닌 치수는 흐린 기울임꼴로 표시, 마우스를 올리면 출처(규격의 공칭 · 재료의 스펙 두께 등) 표시. 처리 탭에도 사용 중인 치수의 출처 표시.

「시편」 목록: 규격 기준 조회

「시편」 메뉴는 재료를 거치지 않는 시편 조회 화면. 규격 · 방향 · 치수가 시편에 귀속되므로 「이 규격으로 절취한 시편 전체」 조회는 이 화면에서 수행. 열 머리에서 재료 · 로트 · 방향 · 규격 · 치수로 필터링.

행 선택 후 가능한 작업은 두 가지.

  • 「일괄 수정」: 선택한 시편의 「시편 규격」 또는 「방향」 을 일괄 변경(한 번에 한 칸). 방향 변경 시 새 방향의 번호를 다시 받고 시험 이름도 함께 변경. 치수는 시편마다 실측값이므로 일괄 수정 대상에서 제외.
  • 「다른 두께로 옮기기」: 아래 별도 기술.

다른 두께에 넣은 시편의 조회와 이동

1.0 mm 재료에 1.2 mm 시편을 넣은 실수는 드러나지 않은 채 통계를 왜곡. 「치수」 열에서 「기준 두께와 5% 이상 차이」(10% · 20% 도 선택 가능, 해당 시편이 있는 단계만 표시) 선택 시, 시편에 기재한 두께와 시험 파일이 잰 두께를 재료의 스펙 두께와 비교해 어긋난 시편만 표시. 5% 이상 차이 나는 행에는 「기준 대비 +25%」 형식의 표시. 재료 선택 오류인지 파일의 두께 값 오류인지는 사용자 판단.

이동 절차: 대상 선택 → 「다른 두께로 옮기기」 → 「기준 두께 (mm)」 만 입력. 실행 전 무엇이 어디로 가는지 미리 표시.

  • 해당 두께의 같은 재료가 있으면 그 재료로 합침, 없으면 원 재료를 복사해 두께만 바꾼 재료 생성(분류 · 용도 · 밀도 · 선언 물성 유지).
  • 시료의 시편 전체 선택 시 시료째 이동, 일부만 선택 시 같은 로트로 새 시료를 만들어 연결.
  • 해당 시험으로 만든 카드가 있으면 카드마다 「코멘트만」 또는 「정리(사용 중지)」 선택. 확정 카드가 걸려 있어도 이동 가능, 카드에는 근거 시험이 다른 두께의 재료로 옮겨졌다는 코멘트 자동 기재. 정리한 카드는 나중에 초안으로 복원 가능.

이동 후 묶음 재생성 필요. 이동된 시험이 포함된 기존 묶음(글로벌 피팅)으로는 카드 신규 생성 불가. 확정 카드의 정리(사용 중지)는 자료 관리자만 가능.

Zwick .tra 는 인장 · 굽힘 · 압축이 같은 파서로 읽음(채널 이름 영문 · 독일어 모두 인식: Standard force · Standardkraft, Standard travel · Standardweg, Deflection · Durchbiegung, Strain · Dehnung). 파일만 보고 종류를 정하는 자리(일괄 등록 · 장비 커넥터)에서는 파일 안의 이름이 한 종류만 가리킬 때만 자동 선택: 처짐 · 굽힘 이름이면 굽힘, Compressive · Druck 이면 압축, 가공경화 · 이방성 항목이면 인장. 하중 · 변위뿐인 파일은 자동 선택 없이 종류 선택 필요 — 커넥터는 경로 규칙의 시험 종류(test_type) 지정으로 해결. Instron Bluehill 원시 데이터 CSV 는 굽힘 방법(Flexure …) · 압축 방법(Compressive …) 열 이름으로 자동 판정, 괄호 단위 행((mm) · (N) · (sec))과 이름 안 단위(Load (kN)) 모두 인식. Time · Extension · Load 만 있는 파일은 종류를 고른 뒤 업로드. 두 장비 형식 모두 실파일 확인 전이므로 열 이름이 다르면 「장비 파일 정의」 에서 연결.

표 입력의 시험 종류. 재료 상세 「표로 시험 입력」 창 상단 「시험 종류」 에서 선택(기본 인장시험). 종류 선택 시 「요약값 열」 이 그 종류의 필수 조건과 묶음이 읽는 요약값 키로 자동 구성: 피로 「응력 진폭 (MPa), cycles_to_failure, runout, 응력비 R, 주파수 (Hz), 시험 온도 (°C)」, 크리프 「가한 응력 (MPa), 시험 온도 (°C), min_creep_rate (1/s)」, 굽힘 「flexural_modulus (MPa), flexural_strength (MPa)」 와 숫자 조건(보고서만 있는 굽힘 시험도 「굽힘 등가 탄성률」 묶음에 투입). 요약값은 열 이름이 곧 저장 키이므로 키 이름 변경 시 묶음(S-N · 크리프 식)에서 제외. 런아웃은 runout 에 1, 아니면 빈칸.

DMA 는 조건 「변형 모드」 기재 권장. 선택지: 이중 캔틸레버 · 단일 캔틸레버 · 3점 굽힘 · 인장 · 압축 · 전단 샌드위치 · 비틀림 · 평행판. 「저장 탄성률」 열만으로는 E′ 인지 G′ 인지 구별 불가하기 때문. 전단 모드(전단 샌드위치 · 비틀림 · 평행판)로 잰 G′ 는 카드 생성 시 E = 2(1+ν)G 로 환산(푸아송비 필요), 덱에는 잰 G 그대로 반영. 모드 미기재 시험은 E′ 로 간주하고 카드에 그 사실 기재. 전단 모드와 그 밖의 모드가 섞인 시험으로는 카드 생성 불가.

사전 정의: 시험 정의와 장비 파일 정의

메뉴정의 내용
「시험 정의」(화면 제목 「시험종류 정의」)받을 시험 종류와 그 채널(곡선의 열) · 조건(온도 · 속도 등 입력 칸). 부서에 필요한 시험 종류를 배포 없이 생성. 조건 칸마다 「표준 조건」(온도 · 변형률속도 · 주파수 등)을 지정하면 부서마다 칸 이름이 달라도 같은 조건으로 인식(시험 목록의 조건 범위 검색도 이 연결 기준).
「장비 파일 정의」(화면 제목 「형식 프로파일」)장비 파일 읽는 방법. 예제 파일을 올려 여섯 단계(장비 파일 → 이 형식을 알아볼 지문 → 읽을 표 → 각 열의 뜻 → 표 앞의 키-값 → 이름 지정) 진행. 「저장하기 전에 적용해 보기」 로 확인 후 저장.
「보유 장비」보유 설비 각 대의 위치 · 상태 · 교정. 「장비 추가」 또는 「엑셀에서 붙여넣기」 로 등록.

세 가지 모두 생성은 누구나, 수정은 등록자 · 편집을 받은 부서 · 자료 관리자 · 시스템 관리자. 시험이 이미 등록된 시험 종류는 삭제 불가, 편집에서 「중단」 으로 전환. 파일을 읽는 파서 자체는 화면에서 생성 불가.

업로드 시 형식 선택 불필요. 서버가 지문으로 장비 파일 정의를 골라 읽음(업로드한 사람 부서의 정의 우선, 부서 없는 정의 다음). 잘못 고른 경우 시험 상세 「다시 읽기」 ▸ 「형식을 골라 읽기」 로 고정.

「장비 커넥터」 화면의 탭은 「전체」 · 「커넥터」 · 「수집함」 · 「실패」 · 「연결 정보」. 항목 선택 시 서버가 좁힌 후보 표시, 「이 시편에 연결」 로 연결. 목록 범위는 「우리 부서」(기본) · 「모든 부서」 중 선택, 「승인 대기」 건은 여러 개를 골라 「고른 N건 승인」 가능. 목록 열람은 누구나, 연결 · 승인 · 폐기는 해당 커넥터 소속 부서의 부서 관리자와 시스템 관리자가 수행.

시험 상세

탭 구성: 「원본」 · 「처리」 · 「점탄성」(DMA 처럼 저장 · 손실 탄성률이 있는 경우만) · 「결과」. 상단 진행 띠에 남은 단계 표시: 「읽힘」 → 「값 내기」 → (DMA 는) 「점탄성」. 「값 내기」 는 채택 시점에 완료되며, 채택된 결과만 재료 통계에 반영. 띠의 단추(「처리하러 가기」 · 「채택하러 가기」)로 해당 탭 이동. 「값 내기」 와 「점탄성」 은 선후 관계 없음(필요한 경로만 수행).

  • 「원본」 탭 「요약값」 표: 장비 출력값과 MatNexus 계산값, 그 차이를 나란히 표시.
  • 「다시 읽기」 메뉴: 「같은 형식으로 다시」 · 「형식을 골라 읽기」 · 「고정 해제 (자동)」, 곡선 · 채택이 아직 없는 경우에 한해 「시험 종류를 바로잡기 (이름도 바뀝니다)」.
  • 「편집」: 시험 조건 · 시험일시 · 시험자 · 장비 · 사업부 · 메모 수정, 「원본 파일 변경」 으로 원본 교체 후 다시 읽기.

03 / 처리처리와 채택

장비 출력은 변위 · 하중 같은 원시 채널이므로 물성 산출에는 변환 필요. 처리는 시험 상세 「처리」 탭에서 수행하고, 저장한 결과 중 하나를 「채택」 해야 해당 시험의 물성으로 인정.

한 건 처리: 미리보기 → 저장 → 채택

  1. 단계 선택. 왼쪽 순서도는 위에서 아래로 진행하며 켠 단계만 수행. 인장은 표준 단계, DMA · 레오미터 유동 · 굽힘 · 압축은 기본 단계가 배치된 상태로 열림(크리프 · 응력완화는 빈 목록에서 시작). 인장 목록이 비어 있으면 「표준 인장 처리 반영」, 빠진 표준 단계가 있으면 노란 상자의 「빠진 표준 단계 입력」 으로 보충.
  2. 「미리보기」: 저장 없이 계산만 수행. 처리가 잘못되면 오류 없이 그럴듯한 다른 곡선이 나오므로 저장 전 그림 확인 필요. 시편 치수가 부족하면 해당 단계에서 멈추고 누락 항목 표시.
  3. 「결과 저장」: 저장된 결과는 변경 불가, 단계를 고치면 새 결과로 저장. 저장 직후 단추가 「저장됨」 으로 잠김(같은 결과의 중복 저장 방지). 단계를 고치거나 다시 미리보기하면 잠금 해제.
  4. 「결과」 탭에서 「채택」: 채택된 결과만 요약값 표 · 통계 · 카드 · 내보내기에 반영. 취소는 「채택 거두기」. 채택된 결과는 삭제 불가(미채택 결과만 삭제 가능).

「결과」 탭의 표시

  • 결과 줄의 표지: 「채택됨」 · 「진응력 포함」(CAE 카드 생성 가능 여부의 판단 근거) · 레시피 이름 · 「옛 원본의 결과」(저장 후 원본 파일이 바뀐 결과, 삭제하지 않고 표시만).
  • 레시피 이름: 불러온 레시피를 그대로 돌린 결과에만 레시피 이름 기재. 불러온 뒤 단계를 고쳐 저장하면 「〈레시피 이름〉 (단계 고침)」 으로 기재되며 해당 레시피의 결과로 집계하지 않음.
  • 펼친 결과: 산출값, 수행 단계 목록(단계별 버전 · 메모), 결과 곡선 표시. 곡선의 x · y 축은 결과에 있는 열 중에서 선택.

공칭 응력-변형률 축에서는 진응력 단계가 잘라 낸 앞쪽(탄성 구간)까지 함께 표시되므로 채택 전 탄성계수 E 확인 가능. 워크벤치의 채택 검토대에서도 같은 그림 사용.

토우 보정이 필요한 경우

시편 물림 등으로 곡선 시작부가 처지는(토우) 경우의 증상과 조치.

  • 항복강도 미산출: 오프셋 선이 하중이 실리기 전 구간(토우 · 음수 하중)에서 곡선과 먼저 만나면 「오프셋 항복강도」 단계가 값을 내지 않고 멈춤. 0 이하의 항복강도는 산출하지 않으며 다음 교점으로 넘어가지도 않음(토우만큼 밀린 채 그럴듯하게 낮은 값이 나오는 것을 막기 위함). 조치: 「토우 보정」 단계를 「탄성계수」 · 「오프셋 항복강도」 앞에 배치.
  • 탄성계수 경고: 「탄성계수」 단계의 직선 적합 R² 가 0.995 미만이면 초기 토우 혼입 가능성 메모 표시. 같은 조치 권장.

레시피: 합의된 단계 묶음

한 건으로 맞춘 단계는 「레시피로 저장」 으로 이름을 붙여 보관(소속 부서가 있는 사용자 누구나). 다른 시험에서는 「레시피 불러오기」 로 재사용하며, 모든 부서의 레시피를 이름 · 단계 이름으로 검색 가능. 저장된 레시피는 「데이터 체계 › 레시피 목록」(화면 제목 「처리 레시피」)에서 조회하고 「레시피 종류」 로 거르기 가능. 줄의 연필 단추로 이름 · 설명 수정(단계는 유지), 권한 단추로 등록자 · 편집 부서 확인. 레시피를 수정 · 삭제해도 이미 저장된 결과는 불변.

여러 건 일괄 처리

  • 시험 목록: 줄 선택 후 「일괄 데이터 처리」. 시험 종류가 섞이면 실행 불가(레시피는 한 시험 종류 기준), 종류별로 나눠 실행.
  • 처리 탭: 「이 단계 그대로 여러 건에」. 같은 재료 · 같은 시험법의 다른 시험에 현재 단계 적용.
  • 워크벤치: 「시험 데이터 한번에 처리하기」 · 「계산된 시험 데이터 한번에 채택하기」(채택 검토대). 11 절 참조.

「N건에 같은 단계 적용」 창에서 「저장할 때 바로 채택」(창에서는 기본 켜짐, 워크벤치에서는 기본 꺼짐) 지정 후 「N건 미리보기」 → 「N건 저장」 순서로 진행. 미리보기는 채택에 영향 없음. 저장 후 「되돌리기」 로 만든 결과 삭제 및 채택 원상 복구 가능. 실패 건은 아무것도 저장되지 않고 목록 맨 위에 표시되므로, 원인 수정 후 해당 건만 다시 선택. 이전 결과와 값이 달라진 건에는 「값이 달라진 것」 표지.

DMA: 「점탄성」 탭

DMA 시험은 두 갈래로 처리하며 상호 선행 관계 없음. 곡선 하나에서 얻는 값(Tg · 선형구간 탄성률 등)은 처리 → 채택으로 통계에 반영하고, 점탄성 계수는 「점탄성」 탭에서 산출해 카드로 생성.

  1. ① 겹치기: 「기준 온도」 와 「방법」(「WLF」 · 「Arrhenius」 · 「장비 값」) 선택 후 온도 스윕을 마스터커브로 겹침. 파일에 장비가 만든 마스터커브가 있으면 「가져오기」 로 대체. 「이동인자」 표에서 맞춘 값과 관측값의 차이 확인. 마스터커브는 고른 기준 온도에서만 유효.
  2. ② Prony 계수 적합: 「적합」 실행 시 여러 항 수를 맞춰 보고 BIC 로 하나 선택(항 수를 늘리면 잔차는 항상 줄기 때문). 후보 표의 「이걸로」 로 변경 가능.
  3. ③ 이 계수로 물성 카드 생성: 시편 하나의 점탄성 카드 생성. 겹칠 때 맞춘 온도 이동(WLF C1 · C2 또는 Arrhenius Ea)과 맞춘 온도 범위도 카드에 기재. 여러 시편을 계수 한 벌로 맞출 때는 05 절의 글로벌 피팅 사용.

크리프 · 응력완화

「점탄성」 탭 없이 처리 단계로 시험별 값만 산출: 크리프는 「최소 크리프 속도」, 응력완화는 「완화 탄성률 E(t)」. 크리프 식(Norton · Garofalo)과 시간 영역 Prony 는 여러 시험을 묶는 글로벌 피팅에서 산출(05 절). 보고서의 최소 크리프 속도만 있는 크리프 시험은 「표로 시험 입력」 값으로도 묶음에 포함.

굽힘 · 압축

처리 로직이 정해지는 순서. ① 시험 종류가 단계 순서를 정함(굽힘 · 압축 각각의 기본 순서). ② 시편 규격이 치수를 넣음(@specimen_span 등, 실측값이 있으면 실측값). ③ 시편 규격의 「처리 기본값」 이 방법을 정함 — 탄성률 방법 · 구간, 하중 구간(사이클), 3점 · 4점. 처리 탭을 열면 기본 순서가 ③으로 채워지고 상단에 「시편 규격 〈이름〉 기준으로 채웠습니다 — …」 로 채운 항목 표시. 채운 값도 수정 가능하며 결과에는 실제로 돌린 옵션이 기록. 레시피를 불러오면 레시피가 우선. 규격은 「온톨로지 편집」 의 「표준 규격 가져오기」 로 먼저 등록(처리 기본값이 함께 등록, 08 절).

3점 · 4점. 「하중 스팬」 기본값은 @?specimen_load_span(있으면 쓰는 참조): 시편에 하중 스팬이 있으면 4점, 없으면 3점으로 계산. 4점 규격(D6272 · C1161 · 사내 4점)은 처리 기본값이 하중 스팬을 필수로 지정해 값이 없으면 처리 중단, 3점 전용 규격(ISO 178 · D790 · 사내 3점)은 비움으로 고정해 잘못 적힌 하중 스팬이 4점 계산으로 이어지지 않음.

  • 「굽힘 응력-변형률」: 3점 · 4점을 한 식으로 계산. 모멘트 팔 a = (L − Lᵢ)/2, σ = 3·F·a/(b·h²). 변형률은 스팬 가운데 처짐이면 12·h·δ/(3L² − 4a²), 하중점 처짐이면 3·h·δ/(a·(3L − 4a)). 「하중 스팬 Lᵢ」 를 비우면 3점(σ = 3FL/(2bh²), ε = 6hδ/L²), 4점이면 @specimen_load_span 입력. 처짐은 처짐계(deflection)가 있으면 그 값, 없으면 크로스헤드 변위. 4점 크로스헤드는 하중점 처짐으로 자동 계산.
  • 장비 컴플라이언스. 크로스헤드 변위에는 장비 자신의 처짐이 섞임 — 칩 · 모듈처럼 짧고 단단한 시편은 그 몫이 시편 처짐과 같은 자릿수라 E 가 작게 산출. 「장비 컴플라이언스 C」(m/N, 받침끼리 맞대고 누른 하중-변위 기울기의 역수) 입력 시 δ − C·F 로 보정.
  • 경고와 보정. 스팬/두께가 16 미만이면 전단 처짐 경고(보정 없음). 「큰 처짐 보정 (D790)」 은 처짐이 스팬의 10% 를 넘는 3점 시험에만 적용.
  • 「굽힘 탄성률 (등가 E)」: 직사각형 단면을 균질한 보로 본 탄성률. 굽힘 강성(하중/처짐)을 같은 구간에서 함께 산출. 「굽힘 강도」 는 최대 굽힘 응력 · 그때의 변형률 · 파단 응력과, 변형률 3.5% 에 닿은 곡선이면 ISO 178 규정 처짐 응력 σfC.
  • 「압축 응력-변형률」: 압축량을 양수로 산출(장비가 음수로 적으면 자동 반전). 변형은 압축계 변형률(strain)이 있으면 그 값, 없으면 크로스헤드 변위 ÷ 초기 높이. 접촉점은 하중이 문턱(기본 최대 하중의 0.5%)을 넘기 직전 하중이 거의 0 인 마지막 점이며 그 자리를 변형 0 으로 지정. 반복 하중은 하중 구간을 자동 분리하고 「쓸 하중 구간」 에서 선택(0 = 마지막, ISO 3386-1 · ISO 7743 은 4, ASTM D3574 C 는 3).
  • 「압축 지표 (규격 보고값)」: 10 · 20 · 25 · 40 · 50 · 65% 압축 응력(곡선이 닿은 것만), 압축 강도(10% 전 최대 응력, 없으면 10% 압축 응력 — 곡선 전체의 최대가 아님), 폼 지표(평탄 응력 = 20 ~ 30% 평균, 치밀화 변형률 = 30% 이후 평탄 응력의 1.3배에 닿는 변형률, 흡수 에너지 = 0 ~ 50% ∫σdε).

탄성률 방법. 같은 곡선에서도 방법마다 수 % 차이가 나므로 규격이 정한 방법을 선택. 「현」: 두 변형률의 응력을 잇는 기울기. 「회귀」: 두 변형률 사이 점의 최소제곱. 「할선」: 원점에서 구간 끝까지. 「접선」: 처음 직선 구간의 가장 가파른 기울기(토우 제외). 「응력 띠」: 최대 응력의 10 ~ 40% 사이 회귀(변형률이 아주 작은 칩 · 세라믹). 어느 방법이든 최대 응력까지의 오르는 구간만 사용.

  3. 「대표 곡선」: 「평균」 · 「중앙값」 · 「하한」 · 「상한」. 하한 · 상한은 방법까지 골라야 적용(기본 방법 없음).

    • 「공차 한계 (B 기준)」: 모집단의 90% 를 95% 신뢰로 덮는 선. 시편 3개부터, 시편이 적을수록 넓음
    • 「포락선 (점마다 최솟값)」 · 「포락선 (점마다 최댓값)」: 측정값 중 가장 끝. 서로 다른 시편의 점이 섞임
    • 「가장 낮은 시편」 · 「가장 높은 시편」: 시편 하나의 곡선 그대로(곡선 모양 보존)

  4. 「어느 식에 맞출까」: 「경화식 맞춰 보기」(초탄성 · 유변 카드는 「초탄성 식 맞춰 보기」 · 「유변 식 맞춰 보기」) 실행 시 여러 식을 같은 곡선에 맞춰 나란히 표시. 후보마다 상대 RMSE · R² · 최대 잔차 표시.

비교 화면의 「시험 구간 밖까지 연장」 에 해석에 필요한 변형률 입력. 그림의 세로선 오른쪽은 측정값이 아닌 식으로 만든 구간. 「식 없이 표만」 · 「고른 식과 혼합」 선택 가능. 「이 값으로 카드 생성」 → 「물성 카드 생성」 창에서 「초안으로 저장」 을 누르기 전까지 저장 없음.

RMSE 최소인 식이 정답은 아님. 측정 구간에서 거의 겹치는 식도 구간 밖에서는 크게 갈림. 해석이 쓸 변형률까지 연장한 모양을 그림으로 확인한 뒤 선택 권장.

「소성 표의 점 수 일치」: 기본 켜짐 · 50점. 처리 단계의 300점 표는 실측 잡음을 그대로 담으므로, 솔버로 나가는 표만 꺾이는 곳 위주로 점 수 축소. 몇 점에서 몇 점으로 줄였는지는 카드 근거와 덱 머리에 기록. 끄면 측정값 그대로 출력.

묶음 카드: 글로벌 피팅

여러 시편의 결과를 하나로 묶어야 산출되는 값의 카드. 묶음 카드 단추를 누르면 그 방법의 묶음 결과 목록이 열리고, 「글로벌 피팅」 → 「구할 값」 선택 → 대상 시편 2건 이상 선택 → 「시편 N건 적합」 → 결과마다 「생성」 으로 카드 생성. 묶음 결과는 「물성」 탭 요약표에도 「피팅」 으로 표시. 결과의 숫자는 수정 불가(고칠 수 있는 것은 메모뿐), 설정을 바꿔 다시 적합하면 새 결과 생성(이전 결과 유지).

묶음 카드의 탄성 칸. 탄성계수는 구성원 시험의 채택 결과 평균, 없으면 재료에 적어 둔 값. 묶음이 탄성계수를 직접 내는 경우(완화 Prony 의 순간 탄성률)는 그 값이 우선. 푸아송비 · 밀도는 어느 경우든 재료 · 시료에서 물려받으며, 카드 생성 창에서 직접 입력도 가능(비우면 물려받을 값을 창에 표시). 점탄성 카드의 탄성계수는 항상 순간 탄성률(점탄성 덱이 E 를 순간 값으로 읽기 때문).

DMA 전단 모드. 시험 조건 「변형 모드」 가 전단이면 측정한 G′ 를 E = 2(1+ν)G 로 환산해 카드에 기재(푸아송비 필요). 전단과 인장 · 굽힘 모드가 섞인 묶음은 카드 생성 불가.

점탄성 카드의 온도 이동

Prony 계수는 기준 온도의 값. 다른 온도에서 쓰기 위한 온도 이동 정보를 카드에 함께 기재: 이동 방법, WLF C1 · C2 또는 Arrhenius 활성화 에너지 Ea, 이동을 맞춘 가장 낮은 · 가장 높은 온도, 이동인자 최대 어긋남(자릿수). 맞춘 온도 범위 밖은 외삽.

  • 시편 하나의 카드: 「점탄성」 탭에서 겹칠 때 맞춘 상수 그대로.
  • 묶음 카드: 시편별 상수를 평균하지 않고 시편들의 관측 이동인자를 모아 다시 맞춤(C1 · C2 는 함께 움직이기 때문). 시편마다 방법이 다르거나 이동 정보가 없는 시편이 있으면 상수를 싣지 않고 경고(카드는 기준 온도에서만 유효).
  • 「장비 값」(장비가 준 이동인자): 식이 없으므로 온도 범위만 기재.
  • 덱에 반영되는 형식은 06 절.

재료 기본 정보 카드(시험 불필요)

「재료 기본 정보 카드」 를 누르면 「재료 기본 정보로 카드 생성」 창 표시. 시험 산출값은 넣지 않고 재료에 적어 둔 값과 밀도 · 푸아송비만 기재하며, 덱에는 「사람이 적은 값」 으로 근거와 함께 출력. 창 위쪽 「실릴 값」 에 값과 출처를 먼저 표시. 적어 둔 물성이 없으면 생성 불가(재료 「물성」 탭에서 먼저 입력 필요).

  • 탄성 · 열물성: 적어 둔 값이 있으면 자동 기재. 전단탄성계수 G 도 탄성 칸에 기재(덱은 E · ν 사용, G 가 E/2(1+ν) 와 5% 넘게 어긋나면 내보낼 때 경고).
  • 「함께 실을 항목란」: 적어 둔 값이 닿는 그 밖의 항목란(전기 · 전자기 물성, 광학 물성, 흡습, 참고 물성, 화면에서 만든 항목란 등) 선택. 선택하지 않으면 카드에 미기재. 적층 강성처럼 맞출 곡선이 없는 물성은 이 경로로만 카드에 기재 가능.
  • 「모델 파라미터」: 재료에 담아 둔 파라미터 벌(문헌 계수 등)을 인용. 선택하지 않아도 생성 가능.
  • 「소성 곡선 합성 — 실측 아님」: 적어 둔 항복강도 · 인장강도 · 연신율로 소성 표 합성. 카드 근거와 덱 머리에 「합성 소성 표 — 실측이 아니다」 기재, 값 등급 4. 합성할 수 없으면 「소성 곡선 합성 불가」 와 사유 표시.
  • 푸아송비 · 밀도: 비우면 재료 · 시료 값을 물려받음. 물려받을 값을 창에 표시.

이렇게 만든 카드는 목록에 「시험 없음 · 적어 둔 값」 으로 표시. 시험에서 만든 카드도 빈 칸을 적어 둔 값으로 채울 수 있으며 측정값이 없을 때만 기재, 덱에는 「사람이 적은 값」 으로 근거 문서와 함께 출력. 「참고 물성」(Tg · 융점 · 경도 등)은 카드에만 기재되고 덱에는 미출력.

카드 생성은 누구나 가능하며 초안도 덱으로 출력 가능(덱 머리에 「초안 — 아직 확정되지 않았습니다」 기재). 「확정」 단추는 재료의 「CAE 카드」 탭에만 있음. 자료 관리자가 아닌 사람에게는 같은 자리에 「확정 요청」 표시: 남길 말(선택)을 적어 보내면 자료 관리자(없으면 시스템 관리자)에게 알림 발송, 창 안에 알린 인원 표시. 카드 상태는 초안 유지, 카드에 「확정 요청됨」 표지와 요청 기록(누가 · 언제 · 남긴 말) 기재, 같은 카드는 하루 한 번. 확정되거나 사용 중지되면 요청한 사람에게 결과 알림 발송.

카드 코멘트: 카드 줄의 말풍선 단추 「코멘트 남기기」 로 검토 의견 · 확정하지 않는 사유 · 보완 요청 기재(카드에는 「반려」 상태가 없음). 카드를 볼 수 있는 사람 누구나, 확정 카드에도 가능하며 값은 불변. 남기면 카드를 만든 사람과 확정을 요청한 사람에게 알림 발송. 코멘트는 카드를 펼치면 표시되고, 남긴 사람과 자료 관리자만 삭제 가능. 서버가 남긴 기록(근거 시험 이동 · 확정 요청)은 삭제 불가. 카드에 「코멘트 N」 이 붙어 있으면 사람의 코멘트나 근거 시험의 이동 기록이 있다는 뜻이며, 노란색이면 근거 시험이 다른 두께로 옮겨졌다는 뜻(01 절).

「CAE 카드」 탭의 카드 목록은 종류 칩(「전체 N」 · 종류별 N)으로 거르기 가능.

「물성 카드」 메뉴는 재료를 거치지 않고 카드를 찾는 목록. 「카드 필터」 에서 상태 · 시험 종류 · 부서로 거르고, 여러 장을 선택해 「묶음 내보내기」 또는 「워크벤치 작업에 추가」 수행. 검색 칸 옆 「확정 요청됨」 단추로 확정 요청이 와 있는 초안만 보기(대기열이 아닌 거르기 조건, 확정 · 사용 중지되면 빠짐). 확정 전 검토 흐름은 워크벤치 「카드 확정 전 검토하기」(11 절).

짝 카드 (이방성 카드 내보내기)

이방성 카드에는 경화 곡선 · 탄성 미포함. 창의 「짝 카드와 합쳐 내기」 에서 같은 재료의 다른 카드를 선택하면 빈 자리를 그 카드에서 가져와 한 재료로 산출. 이방성 카드의 짝은 압연 방향(MD) 소성 카드 선택 필요. 이 카드의 값이 우선이고 짝 카드는 빈 자리만 보충하며, 가져온 내용은 덱에 기재. 카드를 합쳐 새로 만들지 않고 내보낼 때만 합침. 「짝 카드와 합쳐 내기」 는 이 카드로 못 내는 형식이 있고 같은 재료에 다른 카드가 있을 때만 표시.

추정 파단 변형률 기재

재료에 「파단 연신율」 A 를 선언 물성으로 기재(07 절)하면 카드의 소성 표 칸에 실리고, LS-DYNA · Radioss 덱 주석에 추정 파단 변형률 ln(1+A) 기재. 파단 칸 자체는 기본적으로 비워 둠. 맞는 값이 게이지 길이 · 요소 크기에 따라 달라 해석자의 판단이 필요하기 때문.

  • 창의 「추정 파단 변형률을 파단 칸에 넣기」(기본 꺼짐)를 켜면 LS-DYNA FAIL · Radioss Eps_p_max 칸에 그 값 기재, 그 변형률에서 요소 삭제 발생. 근거 주석은 유지.
  • 선택은 그 덱 한 벌에만 적용, 카드에 저장하지 않음.
  • 선택란은 켠 덱과 끈 덱이 실제로 다른 형식에서만 표시(서버가 둘 다 그려 판정).
  • 미리보기가 선택을 반영하기 전에는 「내려받기」 비활성. 미리 본 덱과 받은 덱의 불일치 방지 목적.

  • 기준: 솔버 결과의 σx(진응력)와 반력이 expected.csv 마지막 줄과 1% 이내면 카드가 솔버에 올바르게 입력된 것으로 판단. 명시 솔버(LS-DYNA · Radioss)는 1% 남짓 차이 가능, 운동에너지가 내부에너지의 5% 를 넘으면 종료 시간 연장 필요.
  • 초탄성 기대값: 카드의 푸아송비로 체적 항 (K/2)(J−1)² 을 넣은 압축성 단축 해(K 는 덱과 동일). 푸아송비가 없거나 0.5 이면 비압축 해석해. 비압축 해석해만 쓰면 ν = 0.49 카드가 λ = 2 에서 4.1% 낮게 나와, 맞는 덱을 틀린 것으로 판정하게 되기 때문(OpenRadioss 실측). 체적 항의 꼴이 솔버마다 조금 달라 0.2% 이내 차이는 정상.
  • Radioss 반력: 당기는 절점의 REACX 는 힘이 아닌 충격량(∫F dt)이고, 당기는 면 네 절점 중 한 절점의 몫. 반력 = (마지막 두 기록의 차 ÷ 시간 차) × 4. 그대로 읽으면 기대 반력의 0.3% 수준으로 보이고, 여러 기록에 걸쳐 나누면 힘이 오르는 중이라 낮게 산출.
  • 결과는 일치 여부와 관계없이 플랫폼 개발자에게 전달 요청(README 기재). 형식 수정 또는 「확인됨」 기재 목적.

「형식 점검」 (재료별 산출 가능 형식 확인)

「CAE 카드」 탭의 「형식 점검」 선택 시 「낼 수 있는 형식 점검」 창 표시. 확정 카드를 먼저 대어 보고 형식마다 「나옵니다」 여부를 표시하며, 안 나오는 형식은 빠진 값과 보충 경로 기재: 「…시험을 하면 생깁니다」 · 「이어진 문헌 재료에 채택할 값 N건」 · 「재료 기본 정보 카드로 적어 넣을 수 있습니다」. 판정 규칙은 내보내기와 동일. 실제 내려받기는 카드의 「내보내기」 에서 수행.

「해석용 물성 정의」 (코드 수정 없는 새 형식)

「데이터 체계 › 해석용 물성 정의」 에서 키워드 이름 · 차례 · 칸 폭을 정의로 저장. 새 해석 프로그램이나 부서별 덱 관례를 배포 없이 추가 가능. 생성은 누구나 가능.

  1. 「정의 생성」 → 「예제 덱에서 시작」: 보유한 덱 파일을 올리면 줄과 칸 폭을 읽어 초안 생성.
  2. 「미리보기에 쓸 카드」(최근 20장)를 골라 실제 카드로 확인. 저장은 하지 않음. 빈 칸이 있으면 「값이 비어 있는 칸이 있습니다」 경고.
  3. 「저장」: 그 정의가 카드의 내보내기 창에 표시.

「전부 내보내기」 · 「불러오기」 로 정의를 파일로 이동(개발 서버에서 만든 정의를 운영 서버로 옮길 때).

기본 제공 형식 · 정의판

같은 화면 아래 「기본 제공 형식」 은 코드로 만든 66 형식(중립 JSON 별도). 배포와 함께 제공되며 화면에서 수정 불가. 오류 발견 시 시스템 관리자가 사유를 기재해 「사용 중단」 처리: 내보내기 창 · BOM 혼합 덱 · 문헌 덱에서 제외되고, 그 형식을 고르려던 사용자에게 사유가 그대로 표시되며, 처리자와 사유는 변경 이력에 기록.

정의판: 기본 형식을 정의로 옮긴 비상용 사본(「… · 정의」, key 는 abaqus_def 처럼 뒤에 _def). 배포와 함께 꺼진 채 제공되며, 정의 목록에 「꺼짐」 · 「정의판 · 〈기본 형식 key〉」 배지 표시. 66 형식 중 62 형식에 정의판 동봉(ANSYS 의 Anand 점소성 · 크리프 Garofalo · 크리프 Norton 과 Zemax 는 정의판 없음). 기본 형식 오류 시 처리 순서:

  1. 「기본 제공 형식」 에서 해당 형식 「사용 중단」.
  2. 같은 줄의 「정의판 켜기」(또는 정의 목록의 전원 단추)로 정의판 활성화.
  3. 정의판을 열어 수정 후 사용.
  4. 수정된 기본 형식 배포 후 「다시 쓰기」, 정의판은 「정의판 끄기」 로 비활성화.

기본 형식이 살아 있는 상태에서 정의판을 켜면 내보내기 창에 같은 형식이 두 줄 표시되므로, 켜기 전 화면에서 확인 요청. 정의판 켜기 · 끄기는 자료 관리자 · 시스템 관리자만 가능하며 변경 이력에 기록.

칸이 한 칸 밀려도 해석 프로그램은 오류 미발생. 새 정의로 뽑은 덱은 보유한 예제 덱과 나란히 놓고 한 번 대조 필요. 탄소성 · 초탄성 정의판은 「검증 모델」 로 실행 확인 가능.

BOM 혼합 덱의 고무 재료

「곡선 합성 — 실측 아님, 덱에 합성 표지(고무는 곡선 대신 초탄성)」 을 켠 문헌 줄의 재료가 문헌 분류 「Rubber」(실리콘 · NBR · EPDM · 천연고무 등)이면, 탄소성 곡선 대신 그 솔버의 초탄성 형식으로 산출. 항복 = 인장강도로 지은 탄소성 곡선은 고무 거동과 맞지 않기 때문(곡선 합성이 거절하던 문헌 재료 40종이 전부 실리콘 · 고무 · 폼 · 테이프).

  • 문헌 초탄성 계수 벌이 있으면 그 벌 사용.
  • 벌이 없으면 탄성계수 E 로 Neo-Hookean C10 = E/6 생성(비압축 · 작은 변형 근사). 덱 각주에 「합성 초탄성 — 실측이 아니다」 기재. 큰 변형의 경화 · 연화는 반영 불가하므로, 고무 인장 · 이축 시험으로 맞춘 식이 있으면 그 식 사용 권장. 탄성계수도 없으면 건너뜀.
  • 푸아송비는 생성하지 않음. LS-DYNA · Radioss 는 푸아송비가 없으면 그 사유로 건너뜀.
  • 폼 · 점착 테이프는 분류가 달라 대상 아님. 덱 알림에 「〈부품명〉: 고무라 곡선 대신 초탄성 형식(…)으로 냈습니다」 기재.

  • 값 표: 물성 분야(기계 · 열 · 전기 …)별 묶음, 열 순서 「물성 · 값 · 등급 · 조건 · 출처」. 같은 물성의 후보가 여럿이면 대표값이 먼저 표시(「대표값 · 후보 N」 배지)되고, 밀린 후보에는 「대안」 배지와 사유 표시. 조건 칸은 후보끼리 다른 조건을 앞에 표시. 대표값에는 「측정법」 링크 부착.
  • 「원본에서 빠짐」 배지: 원본(MaterialTwin) 스냅샷을 다시 들일 때 빠진 재료 · 값에 표시. 삭제하지 않고 보존하되 대표값 · 값 검색 · 덱에는 미사용.
  • 「합성 곡선 — 실측이 아니다」: 항복강도 또는 인장강도가 있는 재료에만 표시. 「미리보기」 선택 시 BOM 혼합 덱의 「곡선 합성」 이 지을 것과 같은 소성 곡선(모델 · 곡선 그림 · 사용한 값과 근거) 표시. 실측 아님.
  • 「값 입력」: 카탈로그에 없는 값을 직접 입력. 출처(제목 · DOI · URL 중 하나) 없는 값은 미접수, 방법이 계산 · 추정이면 등급 4 고정. 직접 입력한 값에는 「직접 넣음 · 〈이름〉」 배지, 삭제는 입력자와 관리자만 가능.
  • 「사내 재료로 등록」: 이 문헌 재료를 참고해 사내 재료를 생성하고 문헌 연결까지 수행. 원본 이름 전체는 별칭에 저장되어 검색 가능.
  • 물성 정의문: 문헌 물성 정의 271종마다 「이 물성이 무엇인가」 를 설명하는 정의문 제공. 선언 물성 편집 창의 항목 아래에 표시되어, 이름이 비슷한 항목(항복응력 · 항복강도 등)을 뜻으로 구별하는 목적. 정의문 수정은 자료 관리자.

사내 재료와의 연결 · 값 반영

재료 상세 「물성」 탭의 「문헌 물성」 칸에서 「문헌 재료 연결」 로 이 재료에 해당하는 카탈로그 재료 지정(재료당 하나). 연결 전에는 등급 · 별칭이 같은 후보를 먼저 표시하고, 없으면 이름으로 검색. 연결 후 「반영」 · 「연결 해제」 사용 가능.

  • 「반영」(또는 문헌 재료 상세의 「사내 재료에 반영」): 값을 골라 사내 재료에 저장. 저장한 값은 복사본(스냅샷)이며 출처 · 등급이 함께 기재되어, 카탈로그가 갱신되어도 변하지 않음.
  • 값은 선언 물성으로 저장되고, 밀도 · 푸아송비는 재료 칸에 저장. 「물성 매핑」 으로 연결된 물성만 대상(08 절).
  • 이미 있는 항목은 「이미 있음 — 담으면 교체」 표시(기본 미선택). 같은 조건의 값이 여럿이면 중앙값으로 저장 가능.
  • 등급 유지: 카탈로그에서 담은 값은 출처가 「문헌」 이어도 그 문헌 값의 등급(1~4) 유지. 값 · 단위 · 조건 · 출처 · 근거 문서를 고쳐 저장하면 출처 기준 등급(문헌 3)으로 복귀. 카드 · 덱 근거 줄에 「문헌 카탈로그 N등급 값」 기재.

선언 물성 (기재해 두는 값)

열팽창계수 · 비열 · 열전도율처럼 인장시험으로 얻지 못하는 값의 기재 위치. 재료 상세 「물성」 탭의 「선언 물성 추가」 에서 항목을 고른 뒤, 편집 창에서 값 · 단위 · 출처 · 근거 문서 입력 후 「저장」(「취소」 시 폐기). 기재한 값은 요약표에 「선언」 배지로 표시되고, 연필 단추로 다시 편집. 출처와 근거 문서는 필수이며 출처는 다섯 가지(「모름」 없음, 대신 「추정」).

카드로 가는 자리

기재한 값은 잰 값이 없을 때만 카드에 기재(05 절). 기재한 값과 잰 값의 차이는 「물성 분석」 의 「사양 대비」 에서 확인. 일부 항목의 카드 내 위치:

  • 전단탄성계수 G: 카드 「탄성」 칸. 덱은 E · ν 를 사용하며, G 가 E/2(1+ν) 와 5% 넘게 다르면 덱 알림으로 경고(점탄성 · LVE 카드 제외).
  • 파단 연신율: 카드 소성 표 칸. LS-DYNA · Radioss 덱에 ln(1+A) 추정값 주석 기재, 파단 칸 기재는 내보내기 창에서 선택(06 절).
  • 참고 물성(유리전이온도 Tg · 융점 · 최대 사용온도 · 굽힘 · 압축 · 파괴인성 · 경도 · 절연 · 박리 · 점도 등): 기재한 값이 있으면 카드 생성 시 「참고 물성」 항목란 자동 부착. 카드에서만 표시되고 덱에는 미기재.

  • 표시 위치: 물성 요약 줄의 「등급 N」 과 「승인」 표시, 「물성 지도」 · 값으로 찾기 · 데이터 내보내기 CSV(quality_tier · approved_at)의 등급, 카드 근거 줄, 덱 근거 줄(「사람이 적은 값 (문헌 · 자료 관리자 승인)」).
  • 카드는 생성 시점의 승인 상태를 보존. 승인 후 생성한 카드부터 상향 등급 반영.

「물성 지도」 탭 (재료별 물성 현황)

재료 상세의 「물성 지도」 는 시험으로 잰 값 · 기재한 값 · 연결된 문헌 값을 물성마다 한 줄로 정리. 열은 물성 · 출처(시험 · 선언 · 문헌) · 등급 · 값 · 조건 · 어디서. 공용어(문헌 물성 이름)에 연결되지 않은 항목은 누락 없이 표 아래 별도 표시되며, 「온톨로지 편집」 의 물성 매핑에서 연결하면 표에 반영.

「측정법」

물성마다 어떤 기법 · 규격 · 장비로 측정하는지 보여 주는 읽기 전용 화면. 장비 카탈로그에 있는 장비와 실제 보유 장비를 구별하고, 「장비가 없는 물성」 을 따로 모아 표시.

「물성 분류」: 분야 ⊃ 물성군 ⊃ 물성

문헌 물성과 사내에서 만든 물성 전체를 분야 아래 물성군으로 묶는 화면. 바깥 시스템이 키로 연결하므로 분류 변경은 곧 연동 데이터 변경.

  • 조회: 상단에 물성 수 · 분류됨 · 미분류 · 분야 · 물성군 수 표시. 「이름 · 키 · 기호로 찾기」 로 검색. 물성군에 들지 않은 물성은 하단 「미분류」 에 키 앞머리별로 묶어 표시(분류가 아닌 임시 묶음).
  • 편집(자료 관리자): 「분야 추가」 · 「물성군 추가」 · 이름과 설명 수정. 물성 여러 개를 체크한 뒤 하단 줄에서 물성군을 골라 「넣기」 또는 「군에서 빼기」. 물성은 한 물성군에만 소속되며, 다른 군에 넣으면 이동.
  • 키: 비워 두면 pf-0001 · pg-0001 형식으로 자동 생성. 생성 후 변경 불가.
  • 「밀어 넣기」: 엑셀의 분야 · 물성군 · 물성 세 열을 복사해 붙여넣기 → 「미리 보기」 → 「넣기」. 없는 분야 · 물성군은 생성, 물성은 지정한 군으로 이동, 기재하지 않은 항목은 유지. 오류 줄이 하나라도 있으면 전체 미반영. 물성은 키 · 이름 · 별칭 중 정확히 하나에 일치해야 함(유사 항목 자동 선택 없음). 미리 보기 상단에 새로 생기는 분야 · 물성군과 키 앞머리와 다른 분야로 가는 물성 표시(이름 한 글자 차이로 새 분야가 생기는 사고 방지 목적). 「지금 분류 불러오기」 로 현재 분류를 받아 엑셀에서 수정 후 재입력 가능.
  • 삭제 없음: 분야 · 물성군은 「폐기」 만 가능. 바깥 시스템에는 「쓰지 않음」 으로 남고, 「폐기한 것도 보기」 에서 「되살리기」 가능.

사내 물성 항목과 물성 매핑

물성 하나에 세 이름 공존: 문헌 키 · 사내 물성 항목 · 시험 측정값. 「온톨로지 편집」 에서 「사내 물성 항목」 축을 선택하면 「물성 매핑」 표에서 셋의 연결 상태를 한눈에 확인 가능.

사내 물성 항목 생성 시 「차원」 · 「기호」 · 「붙는 곳」(재료 / 시료)을 함께 입력. 「붙는 곳」 기준: Grade 가 같으면 같은 값(탄성계수 · 열물성)은 재료, 로트마다 다른 값(항복강도 · 인장강도 등 밀시트 값)은 시료, 미입력 시 재료. 선택 입력 칸: 「우리가 재는 값」(같은 물성을 처리 결과가 내는 경우 그 키, 입력 시 선언 값과 측정값을 나란히 표시) · 「시험 척도」(HV · HB · HRC 처럼 단위 대신 척도를 쓰는 물성, 척도 간 환산 없음) · 「값이 변하는 조건」(온도 · 주파수 · 파장, 미입력 시 온도).

  • 연결: 이름 · 별칭 · 기호가 같고 차원이 맞는 문헌 물성은 「이을 만한 것」 으로 제안, 「연결」 한 번으로 연결. 관계 종류는 「같은 것」 · 「더 좁은 것」 · 「관련」.
  • 미연결 항목은 조용히 누락: 요약 칸 「안 이어진 사내 항목」 이 0 이 아니면 우선 확인 필요. 해당 항목의 값은 값 검색 · 문헌 반영 · 문헌 덱에서 빠지고, 물성 지도에서는 표 아래 「안 이어진 것」 으로 밀림. 이름이 비슷하다는 이유만으로 연결하지 않는 원칙(비열 자리에 열전도율이 들어가도 숫자는 그럴듯해 보이기 때문).
  • 새 문헌 키: 「문헌 물성 추가」 로 생성, 생성 후 변경 불가. 잘못 만든 키는 삭제 대신 「폐기」 하고 대체 키 지정.
  • 「사전 다운로드」: 다른 시스템이 MatNexus 키에 자체 항목을 연결할 때 쓰는 파일. 키마다 정의문 포함.
  • 정의문: 문헌 물성마다 무엇이며 어떤 기준으로 잰 값인지 한두 문장 기재(예: 항복강도: 0.2 % 소성 변형이 생기는 응력, ISO 6892). 「항복응력」(페이스트가 흐르기 시작하는 응력)과 「항복강도」 처럼 이름이 비슷한 물성을 뜻으로 구별하는 근거. 사내 물성 항목은 「같은 것」 으로 연결된 문헌 키의 정의문을 함께 표시(선언 물성 창 · 항목 선택), 물성 이름으로 찾는 AI 도구에도 같은 글 제공. 자료 관리자 · 시스템 관리자가 연필 단추로 수정, 수정한 정의문은 배포 시에도 유지.

「해소 못 한 물성 이름」: 사람이나 AI 가 「UTS」 처럼 사전에 없는 말로 물성을 찾다 실패한 이름의 누적 목록. 해당 물성을 지정하면 별칭으로 등록되어 이후 그 이름으로 검색 가능. 서버가 의미 기반으로 추정한 후보를 「이것 아닐까」 로 표시하나 자동 연결은 없음. 물성 이름이 아니면 「무시」.

「카드 항목란」: 카드가 담는 칸

코드로 등록된 내장 항목란 17종: 「탄성」 · 「열물성」 · 「전기 · 전자기 물성」 · 「광학 물성」 · 「흡습」 · 「경화식」 · 「초탄성」 · 「소성 표」 · 「속도별 소성 표」 · 「온도별 소성 표」 · 「점탄성」 · 「선형탄성구간(LVE) 탄성률」 · 「유변」 · 「S-N 곡선」 · 「이방성 (r값)」 · 「모델 파라미터」 · 「참고 물성」. 「참고 물성」(Tg · 융점 · 경도 등)은 카드에만 기록되고 덱에는 미반영, 재료에 적어 둔 값이 있으면 카드 생성 시 자동 첨부. 시스템 관리자는 「항목란 만들기」 로 칸 묶음 추가 가능.

  • 칸마다 물성 키와 단위 입력. 칸 단위와 해당 물성 단위의 차원이 같아야 저장 가능(차원이 다르면 단위계 변환 시 값이 조용히 틀어지기 때문).
  • 세 방향(MD · DD · TD) 값을 함께 써야 나오는 값이면 「값이 여러 방향을 함께 써서 나옵니다」 선택. 미선택 시 그 묶음으로 카드 생성 시 「방향이 섞여 있습니다」 로 차단.
  • 카드가 사용 중인 항목란은 삭제 불가, 「끄기」 만 가능. 기존 카드의 값은 유지.

「지식 그래프」

「구조」 탭: 재료 · 시험 · 카드 · 문헌 같은 종류와 그 사이 관계를 표시, 선 굵기는 실제 연결 수. 「탐색」 탭: 항목 하나를 골라 주변 관계를 펼쳐 조회. 잘린 자리에는 「+N」 표시, 그 자리에서 추가로 펼침. 전체를 한 번에 그리는 단추는 의도적으로 미제공. 노드는 종류별 색으로 구분(구조 · 탐색 그림 공통), 「탐색」 에서는 「색」 기준을 「부서별 (재료·시험·장비)」 · 「상태별」 · 「무리별」 로 변경 가능. AI(MCP)가 따라가는 관계 지도와 같은 정의이므로 AI 가 답한 경로를 눈으로 확인 가능.

  • 타인이 내 자료를 수정하면 「내 활동 › 내 자료 변경 이력」 에 수정자 · 시각 · 근거 기록.

읽기 전용 토큰

「내 활동 › 내 정보」 의 「액세스 토큰」 발급 시 「읽기 전용」 선택 가능. 읽기 전용 토큰은 발급자의 계정 권한과 관계없이 조회만 가능하며, 변경 요청은 서버가 거절. 바깥 시스템이 목록을 읽어 가는 연동 용도. 토큰 목록에 「읽기 전용」 배지 표시. 발급 절차는 10절 참조.

부서 관리자는 수정 권한이 아님. 부서 관리자의 담당: 부서 멤버 관리, 장비 커넥터와 수집함, 측정 의뢰 알림, 부서 변경 이력 조회. 이 직책이 자료나 정의의 수정 권한을 부여하지는 않음.

업무 이관은 권한이 아니라 역할. 측정 의뢰의 상태 이동은 의뢰한 쪽 · 받는 쪽이, 수집함 파일의 시편 연결은 해당 커넥터 부서의 관리자가 수행.

10 / AIAI(MCP)로 쓰기

Claude 등 AI 도구가 MatNexus 에 직접 조회 · 작업 요청 가능(MCP 도구 98개). AI 는 토큰 발급자의 계정 권한으로 동작: 화면에서 볼 수 있는 것만 조회, 수정할 수 있는 것만 수정.

연결 절차

  1. 「내 활동 › 내 정보」 의 「액세스 토큰」 에 용도(예: 내 노트북 Claude Code) 입력, 「만료」 선택(「30일」 · 「90일」 · 「1년」 · 「만료 없음」, 기본 90일), 조회만 맡길 경우 「읽기 전용」 선택 후 「발급」.
  2. 「액세스 토큰이 발급되었습니다」 창의 값은 재표시 불가. 그 자리에서 복사.
  3. 같은 화면 「AI 도구에 등록하기」 에서 사용 도구(Claude Code · Claude Desktop · Codex CLI · Gemini CLI)를 선택하면 방금 발급한 토큰이 채워진 설정 표시. 복사 후 각 도구 설정에 붙여넣기. Claude Code 외 세 도구는 Node.js 필요.

토큰 목록에 발급일 · 마지막 사용 · 만료일 표시. 붙여 넣은 토큰은 AI 도구 · 장비 설정 파일에 평문으로 남으므로 짧은 만료 권장, 사용자 변경 · PC 이동 시 즉시 「폐기」 필요. 폐기 시 그 토큰을 쓰던 연결은 즉시 끊김. 읽기 전용 토큰으로는 어떤 변경도 불가. 장비 커넥터 화면에서 발급하는 토큰의 기본값은 「만료 없음」.

HWAX 포털 연결이 설정된 서버에서는 「AI 도구에 등록하기」 아래에 「HWAX 포털에서 쓰기」 안내 표시. 포털의 Claude 는 MatNexus 토큰 등록 없이 포털 공용 게이트웨이로 연결되고, 계정 명의의 읽기 전용 토큰을 자동 수령. 이 경로의 쓰기 도구는 미리보기까지만 가능.

AI 미수행 작업

  • 삭제: 카드 · 처리 결과 · 시험 · 재료 삭제, 기준정보 병합 도구 없음. 되돌릴 길이 없는 일이므로 사람이 화면에서 수행.
  • 선언 물성 승인 · 수집함 승인 · 계산식 저장: 도구 없음. 사람이 화면에서 수행.
  • 등록 중 새 기준정보 값: 재료 · 시료 · 시편 생성 시 온톨로지에 없는 Grade · 제조사 등은 생성하지 않고 유사 값을 후보로 제시. 새 값은 사람에게 유사 값을 보인 뒤 별도로 생성.
  • 물성 연결 · 카드 항목란 · 문헌 물성 키 저장은 시스템 관리자 토큰에서만 가능(화면과 같은 권한).

쓰기 작업은 미리보기가 기본. AI 가 변경 내용을 먼저 제시하고, 사람이 「그대로」 라고 확인한 뒤 저장. AI 가 저장한 내용은 변경 이력에 「AI(MCP) 경유」 로 기록되며, 내 토큰으로 한 작업은 「내 자료 변경 이력」 에도 표시.

AI 가 카드 상태 · 채택을 바꾸면 자료 관리자에게 알림. 확정 · 사용 중지 · 초안으로 복원 · 처리 결과 채택이 대상이며 토큰 소유자에게도 같은 알림 발송(채택은 한 번의 요청에 알림 한 건). 화면에서 한 작업은 알림 없음.

단위 미지정 시 mm · N · tonne 기준 응답. SI 값을 괄호에 병기, 단위 환산은 AI 가 직접 계산하지 않고 서버에 위임.

11 / 그 밖에워크벤치 · 의뢰 · 공지 · 기록

「워크벤치」: 업무 단위 일괄 작업

시험 1건 · 재료 1건에 해당하는 작업은 해당 화면에서, 여러 건을 한 번에 진행하는 작업은 워크벤치에서 수행. 왼쪽에 업무 8종을 묶음 4종(「시험 데이터」 · 「물성 카드」 · 「해석 덱」 · 「장비 · 형식」)으로 나누어 배치하고, 오른쪽 「계속」 열에 진행 중인 작업 표시(「우리 부서」 · 「모든 부서」 로 범위 전환). 업무 카드에 단계 목록과 배지 표시: 「전용 화면」 은 워크벤치 안에서 끝나는 업무, 「안내」 는 해당 화면으로 이동해 수행하는 업무. 빈도 배지(「매일」 · 「자주」 · 「프로젝트마다」 · 「이따금」) 순으로 묶음 안 정렬. 작업 이름 입력 후 「시작」 시 상단에 단계가 가로로, 하단에 「바구니」 표시.

묶음업무형태빈도단계
시험 데이터「시험 데이터 한번에 등록하기」전용 화면매일파일 올리기 → 올린 것 담기 → 읽혔나 보기. 완료 후 「시험 데이터 한번에 처리하기」 로 이어 하기
시험 데이터「시험 데이터 한번에 처리하기」전용 화면매일처리할 시험 담기 → 읽혔나 보기 → 한 번에 처리(미리보기 전/후 · 저장 · 되돌리기) → 한 번에 채택
시험 데이터「계산된 시험 데이터 한번에 채택하기」전용 화면자주채택할 시험 담기 → 견주어 채택(채택 검토대)
물성 카드「물성 카드 하나 만들기」전용 화면자주재료 고르기 → 무엇이 나오나(준비도) → 카드 만들기(CAE 카드 패널: 탄소성 · 점탄성 · 열 · 재료 기본 정보)
물성 카드「카드 확정 전 검토하기」안내이따금초안 담기(확정 요청 온 카드부터) → 근거 보기(확정 요청 · 표본 수 · 경고 · 코멘트) → 확정하거나 사유 남기기. 확정은 자료 관리자가 재료 상세 「CAE 카드」 탭에서 수행, 확정하지 않을 카드는 카드 줄의 「코멘트 남기기」 로 사유 기재(만든 사람 · 요청한 사람에게 알림, 카드 상태에 「반려」 없음)
해석 덱「부품표(BOM)로 여러 카드를 한 덱에」전용 화면프로젝트마다부품표로 덱 만들기(붙여넣기 · 매칭 확인 · 한 파일 내보내기를 한 화면에서 수행)
해석 덱「여러 카드를 한 묶음으로 내보내기」안내프로젝트마다무엇에 쓰나 → 무엇이 있나 → 카드 담기 → 묶음 내보내기(manifest · 체크섬 포함, 마지막 단계만 워크벤치 안에서 수행)
장비 · 형식「새 장비 파일 연결」안내이따금예제 파일 → 표 선택 → 열 매핑 → 한 벌 올려 확인

시험 담기 단계: 그 자리에 시험 목록 표시. 검색 · 재료 · 시험 종류 · 처리 상태로 좁혀 「고른 N건 담기」. 초기 필터는 업무별 지정(처리하기는 「처리 전」, 채택하기는 「결과 있음 · 채택 전」). 시험 · 재료 · 카드 목록의 「워크벤치에 추가」 로 담은 것도 같은 바구니에 합산.

채택 검토대: 여러 시험의 처리 결과를 한 화면에서 비교해 일괄 채택하는 전용 화면.

  • 왼쪽 표: 시험마다 「고른 결과」(생성 시각 · 레시피 · 단계 수 · 옛 원본 여부)와 핵심 값(인장이면 탄성계수 · 항복강도 · 인장강도), 「중앙값과 차이」 표시. 같은 재료 · 시험 종류 · 방향의 시험끼리(반복 시편끼리) 비교하며, 문턱(기본 10%)을 넘는 시험은 색 표시 후 맨 위로 정렬.
  • 오른쪽 위 「겹쳐 보기」: 보고 있는 시험과 같은 묶음의 고른 결과를 한 그림에 겹쳐 표시(보고 있는 시험은 굵은 선, 문턱을 넘은 시험은 주황). 오른쪽 아래 「한 건 자세히」: 결과 탭과 같은 그림(자르기 전 공칭 곡선 · E 선 · 오프셋 선 · 항복점)과 「지금 채택 → 고른 결과」 의 값 차이 표시. 「이 시험 열기」 로 해당 시험의 결과 탭 이동.
  • 초기 선택은 채택 전 시험만. 이미 채택한 시험은 다른 결과를 고를 때만 「바꿈」 으로 포함. 수정 권한이 없는 시험(타 부서 자료)은 선택 불가, 문의 대상 표시.
  • 「고른 N건 채택」 선택 시 새로 채택 · 바꿈 · 문턱 초과 건수를 확인 창에 표시. 채택 후 「되돌리기」 로 이전 채택 상태 복원 가능(결과는 삭제되지 않음). 채택은 언제나 사람이 수행.

마지막 단계의 「이 작업을 끝내고 「…」 로 이어 하기」 선택 시 담은 것을 그대로 다음 업무로 인계(등록 → 처리). 작업을 이어서 진행할 수 있는 사람은 그 부서 사람 · 작업 시작자 · 자료 관리자, 그 밖에는 조회만 가능. 예전 이름으로 시작한 작업(「오늘 들어온 것 처리하기」 · 「DMA 한 벌로 점탄성 계수 내기」 · 「해석에 쓸 물성 준비」)은 현재 업무로 열리며, 담긴 것과 진행 상태는 유지.

「측정 의뢰」: 「이 시료의 이 물성을 재 달라」

누가 무엇을 왜 측정 요청했고 어디까지 진행됐는지를 번호 붙은 기록으로 관리. 재료 조회 중 빈 물성을 확인하면 재료 상세의 「측정 의뢰」 단추로 바로 의뢰 가능.

  1. 의뢰: 「새 의뢰」 에서 시료 선택, 미등록 재료는 내용을 글로 기재. 항목마다 시험 종류(미정이면 「미정」 으로 두고 물성 이름만) · 조건 · 방향 · 수량 · 받을 것 입력 후 받는 부서 선택. 「임시 저장」 은 본인만 보는 「작성 중」, 「의뢰」 는 「접수 대기」 로 전환되며 받는 부서 관리자에게 알림 발송.
  2. 접수 · 시험: 받는 부서가 「접수」 후 항목별로 시험 연결. 항목의 단추: 「붙이기」(같은 시료 · 같은 종류의 기존 시험 연결) · 「시험 등록」(시료 · 종류 · 조건이 채워진 등록 창, 등록 즉시 연결) · 「시편 만들기」(항목의 방향 · 수량대로 시편 일괄 생성) · 「여러 파일 한꺼번에」(시료 · 종류 · 조건이 채워진 일괄 등록 화면, 올린 시험은 그 항목에 연결). 시험이 연결되면 「접수」 는 자동으로 「시험 중」 으로 전환, 결과 채택에 따라 진행률 상승.
  3. 결과 전달: 「결과 전달」 은 항목마다 채택된 결과가 1건 이상 필요. 의뢰자가 확인 후 「확인하고 완료」 로 종료, 부족하면 「시험 중」 으로 되돌림.

의뢰 상세: 연결된 시험이 있으면 머리에 「이 의뢰의 시험 목록」 링크 표시(시험 목록에서 거르기 · 일괄 처리 가능). 받을 것이 카드 항목란이면 항목에 그 시험으로 만든 카드의 링크와 상태 표시, 받을 항목란이 든 카드가 아직 없으면 그 사실 표시.

상태: 「작성 중」 · 「접수 대기」 · 「접수」 · 「시험 중」 · 「보류」 · 「결과 전달」 · 「완료」 · 「반려」. 접수 · 보류 · 결과 전달 · 반려로 전환 시 사유 기재 필수. 목록 범위: 「우리 부서」 · 「내가 낸 것」 · 「우리 부서가 받은 것」 · 「모든 부서」, 타 부서 의뢰는 조회만 가능. 기한이 3일 이내로 다가왔거나 지난 의뢰는 하루 한 번 받는 쪽에 알림. 홈 「남은 일」 에 「받은 의뢰 접수 대기」 · 「받은 의뢰 시험 중」 · 「의뢰 기한 임박」 · 「낸 의뢰 진행 중」 건수 표시.

「공지 · VOC」

  • 공지: 시스템 관리자가 작성. 사이드바 「공지 · VOC」 옆에 안 읽은 공지 수 표시, 「안 읽은 것만」 으로 거르기, 「모두 읽음」 으로 일괄 읽음 처리. 「내용 전체 복사」 로 게시판 공지를 최근 것부터 글 하나(번호 · 제목 · 작성자 · 날짜 · 본문)로 모아 복사, 다른 문서 · 메신저 · AI 에 붙여넣는 용도. 찾기나 「안 읽은 것만」 으로 걸러 둔 상태면 단추가 「찾은 N건 복사」 로 바뀌고 걸러진 공지만 복사. 배포와 함께 게시된 안내도 같은 게시판에 누적.
  • VOC: 앱 불편 · 요청 제보 창구. 「의견 등록」 에 파일 첨부 가능(파일당 25 MB). 「등록」 → 「접수」 → 「처리 중」 → 「해결」 → 「종료」 순 진행, 해결된 건은 제보자가 재개 가능.

「가이드」: 핸드북 수정 절차

사이드바 「공통 › 가이드」(화면 제목 「물성 핸드북」). 핸드북은 누구나 수정 제안 가능하나 검토 없이 본문이 바뀌는 경로는 없음. 절마다 「편집」 → 수정 내용과 사유를 한 줄 기재 → 「초안 전송」. 검토자(자료 관리자 · 시스템 관리자)에게 「검토 대기」 로 누적, 「승인」 시 초안이 본문이 되고 판 번호 상승. 검토자는 본인 글을 「저장 (바로 반영)」 으로 즉시 게시 가능. 「저장소가 정본인 문서」 표시가 붙은 문서는 승인한 수정이 이력에 남되, 저장소 쪽이 갱신되면 배포 시 본문 변경 가능. 문서 분류: 「앱 사용」 · 「시편 규격」 · 「시험 방법」 · 「물성 계산」 · 「측정 범위」 · 「장비 사용」 · 「용어」.

기록: 변경 이력과 휴지통

화면대상표시 내용
「내 활동 › 내 자료 변경 이력」전원내가 등록한 자료에 다른 사람이 한 작업(수정 · 삭제 · 확정 · 이관). 내 이름으로 AI 가 한 작업도 포함
「내 부서 › 변경 이력」부서 관리자 · 시스템 관리자관리하는 부서의 기록. 「행위」 와 「경로」(「전부」 · 「AI(MCP) 경유」 · 「화면에서」)로 거르기
「내 활동 › 휴지통」전원내가 되살릴 수 있는 것(내가 등록했거나 편집을 받은 부서의 것)만 표시, 「복원」 가능. 영구 삭제는 시스템 관리자만

「알림」 화면 하단 「어떤 알림을 받을까」 에서 알림 종류별 켜기 · 끄기. 끈 알림은 본인에게만 미발송. 자료 관리자(없으면 시스템 관리자)에게는 「확정 · 승인 요청」(카드 확정 요청 · 선언 값 승인 요청)과 「AI 가 확정 · 채택」 알림 추가. 「확정 요청 결과 · 카드 코멘트」 는 누구나 받는 알림으로, 확정을 요청한 카드가 확정 · 사용 중지되거나 내가 만들거나 요청한 카드에 코멘트가 달렸을 때 발송.

데이터 내보내기: 다른 플랫폼 이관용

시스템 관리자가 「관리 › 서버」 의 「서버 정보」 탭에서 「데이터 내보내기」 수행. 「곡선 포함」 · 「문헌 카탈로그 포함」 선택, 수신처 메모 기재 후 「지금 뽑기」 를 누르면 재료부터 카드까지의 CSV 묶음과 곡선 파일 생성. 숫자는 전부 SI, 열 이름에 단위 기재. 파일은 화면 다운로드가 아닌 서버 폴더에서 수령.

전달 전 확인 사항 두 가지. 파일에 부서 구분이 없어 전 부서 데이터가 포함되므로 다른 부서의 동의 필요. 문헌 값은 사내 소유가 아니라는 점도 확인 필요. 추출자 · 시각 · 내용은 변경 이력에 기록.
