01 / 계층재료에서 시험까지

재료 물성은 「재료 → 시료 → 시편 → 시험」 네 층 구조. 층을 나눈 이유는 층마다 그 층에만 붙는 값이 있기 때문: 규격은 재료, 로트는 시료, 방향 · 실측 치수는 시편, 조건 · 곡선은 시험에 귀속.

용어정의구별 · 유의점
재료규격 하나에 대응하는 단위. Family · Category · Grade · Details · 스펙 두께로 정의. 공칭 밀도 · 푸아송비 · 선언 물성이 재료에 귀속.두께가 다르면 별개 재료: 0.45t 와 1.0t 는 따로 구매 · 관리하는 자재이므로, 섞으면 편차 통계가 오염됨. 재료명은 Grade_Details_두께 형식으로 자동 생성(「SECC_MDOI_1.0」).
Family · Category · Grade · Details재료를 지칭하는 네 칸. Family → Category → Grade 는 상하 관계(Metal → Steel → SECC). Details 는 같은 Grade 를 구분할 때(개발 A안 · B안 등) 사용, 비어 있으면 「-」 입력.「물성 분석」 에서는 Family 를 「재료군」, Category 를 「분류」 로 표기. 세 칸은 기준정보 값이므로 새 값 등록은 자료 관리자 권한(06).
스펙 두께재료의 규격 두께. 재료명의 한 칸.계산용 두께가 아님. 응력은 시편 · 시험의 실측 두께로 계산(1.0t 판의 실측값은 0.98 등).
시료입고된 실물 한 단위(코일 · 판 하나). 로트 · 제조사 · 생산일, 해당 로트의 실측 밀도, 밀시트 값이 시료에 귀속. 시료명은 재료명 뒤에 일련번호(「__01」)를 붙인 형식.로트 번호는 이름에 미포함: 로트를 나중에 확인해도 이름 불변. 한 로트에서 시료 여러 개 등록 가능.
시편시료에서 잘라 낸 조각. 방향 · 시편 규격 · 실측 치수를 보유.하중을 응력으로 환산하는 단면적은 시편 치수에서 산출. 방향은 절단 시 정해지므로 재료가 아닌 시편의 속성.
방향MD · TD · DD. 방향이 없는 재료(수지 등)는 NA. 시편명의 한 칸.통계 · 카드는 방향별로 별도 산출: MD 와 TD 를 한 통계로 합치면 산포가 아니라 이질 데이터의 혼합. 예외는 세 방향을 함께 써야 나오는 값(r̄ · Hill48)뿐(04).
시편 규격시편의 절단 규격(ASTM E8 subsize · JIS 5호 등). 기준정보 「시편 규격」 의 값이며 「시편 분류」 의 하위 항목. 규격이 치수 칸(게이지 길이 · 폭 · 직경 등)을 결정.시험 조건이 아님. 비워 둔 치수 칸은 규격의 공칭값을 물려받아 적용하고, 시편에 기재하는 치수는 실제 측정값만 해당.
시험시편 하나를 한 시험 종류로 1회 측정한 기록. 조건 · 원본 파일 · 곡선 · 요약값 · 처리 결과가 시험에 귀속. 「카탈로그 › 시험」(화면 제목 「시험 데이터」).시편과 동일 개념이 아님: 한 시편으로 여러 번 측정 가능(DMA 주파수 스윕 + 온도 스윕). 따라서 치수도 시험마다 기재되며, 이 시험의 측정값 → 시편 기재값 → 규격 공칭값 순으로 적용.
시험 종류측정하는 시험의 정의: 채널 · 조건 칸 · 이름 약어(「TEN」 등). 「데이터 체계 › 시험 정의」 에서 생성(화면 제목 「시험종류 정의」). 기본 제공 6종: 인장시험(TEN) · DMA 스윕(DMA) · 레오미터 유동(RHE) · 피로(FAT) · 크리프(CRP) · 응력완화(SRX).코드가 아닌 데이터이므로 배포 없이 추가 가능. 키는 전사 공통 1개: 두 부서가 같은 DMA 를 수행하면 시험 종류 하나를 공유.
크리프 · 응력완화기본 제공 시험 종류 중 시간 영역 시험 둘. 크리프(CRP): 일정 하중을 가한 상태에서 시간–변형률 측정, 조건 「가한 응력」 · 「시험 온도」 필수, 처리 단계 「최소 크리프 속도」 로 정상상태 크리프 속도 산출. 응력완화(SRX): 변형률을 유지한 상태에서 시간–응력 측정, 처리 단계 「완화 탄성률 E(t)」 로 완화 탄성률 산출.장비 파일은 현재 「MatNexus 표준 CSV」(1행 열 이름, 2행 단위) 형식만 자동 판독, 그 밖의 파일은 이 형식으로 변환하거나 형식 정의에서 열 연결 필요. 크리프는 보고서의 최소 크리프 속도만 있어도 「표로 시험 입력」 가능. 여러 시험의 묶음으로 크리프는 Norton · Garofalo 식, 응력완화는 시간 영역 Prony(점탄성 카드, 시험 2건 이상) 산출(02).
채널곡선의 열 하나(변위 · 하중 · 온도 등). 차원과 저장 단위를 보유.인장 장비가 주는 것은 응력–변형률이 아닌 변위 · 하중. 응력 · 변형률은 처리 단계가 생성. 같은 이름의 채널은 전사에서 같은 차원 · 단위 필요.
조건 · 표준 조건조건은 시험마다 기재하는 값(온도 · 변형률속도 · 주파수 등). 표준 조건은 조건 칸이 어느 공통 조건에 해당하는지의 지정: 온도 · 변형률속도 · 주파수 · 상대습도 · 압력 · 속도 · 예하중 · 노화 시간.부서마다 칸 이름이 temp · temperature 로 달라도 표준 조건이 같으면 검색 시 한 조건으로 취급. 미지정 시 이름 · 단위로 추정해 연결하며, 연결되지 않은 칸은 저장은 되나 조건 검색에서 제외. DMA 의 「변형 모드」 조건은 저장 탄성률이 E′ 인지 G′ 인지를 결정(전단이면 카드가 E = 2(1+ν)G 로 환산).
원본 · 곡선원본은 업로드한 장비 파일 그 자체. 곡선은 원본을 판독해 채널별로 SI 로 환산한 데이터.원본은 삭제하지 않음: 교체해도 이전 파일이 이력에 남음. 원본을 교체해도 기존 처리 결과는 자동 재계산 없음.
요약값시험 1회의 대표 수치(항복강도 · 최대하중 · n값 등). 시험 상세 「원본」 탭에 「장비」 · 「MatNexus」 두 열로 병기.장비가 계산해 파일에 넣은 값과 이 앱의 계산값은 혼용하지 않음. 차이가 크면 대개 탄성 구간 설정 차이가 원인. 앱 쪽 값은 채택된 처리 결과에서 산출.
표로 들어온 시험곡선 없이 값만 입력된 시험(「표로 시험 입력」). 피로는 채널이 없어 이 방식으로만 입력(「응력 진폭」 필수), 크리프는 최소 크리프 속도만으로 입력 가능.불완전한 시험이 아님: 통계 · 카드의 근거로 사용 가능, 곡선 재처리만 불가.
고유 번호 M · S · P · T재료 M-000082 · 시료 S-000041 · 시편 P-000187 · 시험 T-000203. 목록의 「번호」 열과 제목 옆에 표시, 클릭 시 복사.이름(「SECC_MDOI_1.0__01__MD_01__TEN_01」)과 별개: 이름은 Grade 수정이나 다른 두께로의 이동 시 함께 바뀌지만 번호는 한 번 부여되면 불변이며, 삭제된 번호도 재사용 안 함. 메신저 · 보고서 · 시편 라벨에는 번호 사용 권장. 「T-203」 · 「t203」 처럼 줄여 입력해도 검색 가능.

두께의 세 위치

스펙 두께(재료, 이름의 한 칸) · 시편 두께(시편에 기재한 실측값) · 시험이 잰 두께(장비 파일에 포함된 값). 응력 계산에는 뒤의 둘을 사용. 시편 목록 「치수」 열에서 「기준 두께와 5% · 10% · 20% 이상 차이」 를 선택하면 스펙 두께와 크게 다른 시편이 표시되며, 재료를 잘못 고른 경우 「다른 두께로 옮기기」 로 정정(이름은 변경, 번호는 유지).

02 / 처리곡선이 물성이 되기까지

장비 파일은 장비 파일 정의로 판독, 처리 단계를 거쳐 처리 결과가 되고, 그중 1건을 채택해야 해당 시험의 물성으로 인정. 결과는 여러 건 누적 가능하나 통계 · 카드는 채택된 1건만 사용.

용어정의구별 · 유의점
장비 파일 정의장비가 출력한 파일의 판독 규칙. 인코딩 · 표 · 단위는 자동 판독, 「이 열이 무엇인가」 만 사람이 지정해 저장. 「데이터 체계 › 장비 파일 정의」(화면 제목 「형식 프로파일」).새 장비 연결에 배포 불필요. 자동 선택 대상은 내 부서의 정의와 부서 없이 등록된 정의뿐: 다른 부서의 정의는 시험 상세 「다시 읽기 › 형식을 골라 읽기」 에서 직접 선택.
처리 단계곡선에 계산 한 가지를 적용하는 단위 작업. 공통(정렬 · 구간 자르기 · 재샘플 · 평활 등) · 인장(공칭 응력-변형률 · 토우 보정 · 항복 강하 정리 · 탄성계수 · 오프셋 항복강도 · 진응력·진소성변형률 등) · DMA(tan δ · 유리전이온도 등) · 크리프(「최소 크리프 속도」) · 응력완화(「완화 탄성률 E(t)」) · 인장 확장(「가공경화지수 n」 · 「항복비」 · 「소성 변형비 r」).단계 이름이 곧 물성 이름인 경우가 많음(「오프셋 항복강도」 단계가 항복강도를 산출). 「관리 › 계산식」 에서 작성한 식도 단계로 등록. 유리전이온도는 정의 4종 중 선택(tan δ 피크 · 손실 탄성률 피크 · 저장 탄성률 낙폭 지점 · 저장 탄성률 온셋(접선 교점, ASTM E1640)), 정의에 따라 값이 수 °C 차이.
처리 레시피실행할 단계와 순서 · 옵션을 저장한 것. 시험 종류별로 별도 관리. 「데이터 체계 › 레시피 목록」(화면 제목 「처리 레시피」).레시피는 수정 가능. 기존 결과는 실행 당시의 단계를 통째로 보존하므로, 레시피를 수정 · 삭제해도 기존 결과 불변. 레시피 없이 화면에서 즉석 구성한 단계로도 실행 가능.
처리 결과1회 실행의 결과 한 벌: 곡선 · 값 · 단계별 근거. 시험 상세 「결과」 탭. 결과마다 사용한 레시피 이름 표시, 단계를 수정해 실행한 경우 「(단계 고침)」 표시.수정 불가: 재실행 시 새 결과가 추가로 누적. 여러 건이 있어도 통계 · 카드는 채택된 1건만 사용. 저장 직후 저장 단추는 「저장됨」 으로 잠김(단계 수정 · 재실행 시 해제).
채택처리 결과 중 1건을 「이 시험의 물성」 으로 지정하는 행위. 채택된 값이 요약값 표에 표시되고 통계 · 카드의 입력이 됨. 「채택 거두기」 로 취소.저장 ≠ 채택이며, 최신 결과가 자동으로 대표가 되지도 않음. 미채택 시험은 통계에서 제외되고 제외 건수가 화면에 표시. 여러 시험을 한 화면에서 견주어 채택하는 자리는 워크벤치의 채택 검토대(07). 문헌 값을 재료에 담는 「반영」(05)과 별개.
계산식시스템 관리자가 화면에서 작성하는 식. 세 종류: 「곡선에 맞추는 식」(경화식 · 점도식) · 「값에서 값을 내는 식」(항복비 = 항복강도 ÷ 인장강도) · 「곡선에서 열을 내는 식」. 「관리 › 계산식」.곡선에 맞추는 식은 카드 생성 시 식 후보로, 나머지 둘은 레시피의 단계로 사용. 식 수정 시 판 번호 상승, 기존 결과는 이전 판 유지. 사용 중인 식은 삭제 불가(끄기만 가능). 정렬 · 구간 탐색 같은 알고리즘은 이 방식으로 추가 불가.
식(적합식)곡선에 맞추는 모델 11종. 금속 경화(Voce · Swift · Hockett-Sherby · Ghosh) · 초탄성(Neo-Hookean · Mooney-Rivlin · Yeoh · Ogden 1항) · Johnson-Cook 준정적 항 · 유변(Cross · Carreau).카드 생성의 「어느 식에 맞출까」 단계에서 여러 식을 나란히 적합해 보고 하나를 선택. 적합도(잔차 · R²)가 계수와 함께 카드에 기록.
글로벌 피팅여러 시편의 데이터를 한 번에 적합해 값 하나를 산출하는 작업. 7종: Prony 글로벌 피팅(점탄성 마스터커브) · 속도별 소성 곡선 · 온도별 소성 곡선 · S-N 곡선(Basquin) · 이방성(세 방향 r값) · 크리프 식(Norton · Garofalo) · 완화 Prony(시간 영역).일부 화면 · 안내에서는 「묶음」 으로 표기. 결과는 재료에 귀속(로트가 달라도 묶음)되며 수정 불가. 선택한 시험과 실제 사용된 시험이 별도 기록. 「물성」 탭 표에 「피팅」 배지로 표시. 다른 두께로 옮겨진 시험이 포함된 기존 결과로는 카드 신규 생성 불가. 크리프 식 결과는 카드의 「모델 파라미터」 항목란, 완화 Prony 결과는 점탄성 카드로 연결.

카드 탭이 빈 경우

대개 미채택이 원인. 화면 안내도 동일: 「적합할 곡선이 없습니다. 시험 상세의 처리 탭에서 돌려 보고 저장한 뒤 채택하면, 그 곡선이 여기의 입력이 됩니다.」 여러 시험에 같은 단계를 적용할 때 「저장할 때 바로 채택」 을 켜면 저장과 동시에 채택(처리 창에서는 기본 켜짐, 워크벤치에서는 채택 검토대에서 견주어 보도록 기본 꺼짐). 미리보기는 채택에 영향 없음.

03 / 통계통계와 대표 곡선

시편 하나의 값은 그 시편의 값일 뿐임. 「이 재료의 항복강도」 를 말하려면 여러 시편의 산포 확인이 필요하며, 카드는 그 산포 속에서 선택한 대표 곡선으로 생성.

용어정의구별 · 유의점
반복 시편 통계재료 상세 「물성」 탭의 통계. 채택된 결과만 모아 n · 평균 · 중앙값 · 표준편차 · CV · 95% 신뢰구간 · 이상치 산출.묶음 단위는 재료 + 시험 종류 + 방향. 시료(로트) 단위로는 나누지 않음: 나누면 표본이 2~3개로 줄어 통계 성립 불가.
평균 · 중앙값둘 다 산출.둘의 차이가 크면 그 자체가 신호: 이상치 하나가 평균을 끌어당겼을 가능성.
표준편차 · CV표본 표준편차(n−1)와 변동계수(표준편차 ÷ 평균). CV 가 크면 값 옆에 경고 표시.방향을 섞어 나온 큰 CV 는 산포가 아님. 방향별 분리 여부를 먼저 확인.
95% 신뢰구간평균이 존재할 법한 구간. 시편이 적으면 t 분포를 적용해 넓게 산출.개별 시편이 들어갈 범위가 아님: 그에 가까운 것은 아래 「공차 한계」.
이상치 후보중앙값 기준 점수(수정 z 점수)로 멀리 떨어진 값에 붙는 표시.표시만 하며 자동 제외 없음. 시편이 2개이면 판정하지 않음(어느 쪽이 이상한지 판단 불가).
구간 짧음측정 구간이 나머지 시편의 절반 미만인 시편(조기 종료 등)에 붙는 표시.역시 자동 제외 없음. 포함한 채로 두면 대표 곡선이 그 시편의 끝점까지만 생성: 카드 생성의 「쓸 시험」 에서 「표시된 N건 빼기」 로 제외 후 재적합.
평균 곡선 · 산포곡선을 격자점마다 통계 처리해 만든 평균 · 중앙값 곡선과 점별 산포.공통 구간까지만 산출: 짧은 시편을 빼 가며 끝까지 그리면 뒤로 갈수록 n 이 줄어드는데, 그 사실이 그래프에 드러나지 않기 때문.
대표 곡선카드 생성 시 식 적합과 소성 표 추출에 쓰는 곡선 하나. 카드 생성 3단계 「대표 곡선」 에서 평균(기본) · 중앙값 · 하한 · 상한 중 선택.곡선(소성 표 · 식)에만 적용: 탄성계수 · 푸아송비 · 밀도는 평균값 또는 물려받은 값 그대로. 시편마다 구간이 다르면 공통 구간의 균등 격자로 맞춰 생성. 생성 기준이 카드 근거와 이름에 기록.
하한 · 상한강도 평가처럼 보수적으로 볼 때는 하한, 충돌 에너지 · 성형 하중처럼 크게 볼 때는 상한. 방법까지 선택해야 성립: 「평균 ± kσ」(k = 1 · 2 · 3) · 「공차 한계 (B 기준)」 · 「포락선」 · 「가장 낮은 시편」/「가장 높은 시편」.공차 한계는 모집단의 90% 를 95% 신뢰도로 포함하는 선이므로 시편이 적을수록 넓음(3개 이상 필요). 포락선은 점마다 극값을 취하므로 서로 다른 시편의 점이 섞이고, 가장 낮은 시편은 한 시편의 곡선 형상을 그대로 유지. k 는 기본값 없음. 시편 1개로는 상 · 하한 생성 불가.
사양 대비「물성 분석」 의 탭. 재료에 기재한 값(선언 물성)과 시험 측정값의 차이를 큰 순서로 표시.온도가 여러 점 기재된 경우 상온에 가장 가까운 점과 비교.

04 / 카드카드와 덱

카드는 해석에 넣을 물성 한 벌을 근거와 함께 저장한 것, 덱은 그 카드를 해석 프로그램이 읽는 텍스트로 기록한 파일. 카드는 한 번 생성해 두고, 덱은 필요할 때마다 형식 · 단위계를 선택해 새로 산출.

용어정의구별 · 유의점
물성 카드재료 하나의 물성 한 벌. 재료 상세 「CAE 카드」 탭과 「카탈로그 › 물성 카드」 목록이 같은 카드를 표시. 카드 1장 = 방향 1개.카드는 파일이 아님: 파일(덱)은 내보낼 때 생성. 시험 없이 기재값만으로 만든 카드는 시험 종류 · 방향이 빈칸: 측정값으로 오인되지 않도록 의도적으로 비움.
카드 종류「재료 기본 정보 카드」 · 「탄소성 카드」 · 「초탄성 카드」 · 「유변 카드」 · 「선형탄성구간(LVE) 카드」 · 「점탄성 카드」 · 「속도 의존 카드」 등. 「CAE 카드」 탭 「새 카드 생성」 줄의 단추 하나가 한 종류. 그 밖의 글로벌 피팅 방법은 「〈방법 이름〉 카드」 단추로 표시.해당 재료에 입력이 있는 단추만 표시. 탄소성 카드에서 초탄성 식을 고르면 그 카드는 「초탄성」 으로 분류. 점탄성 카드는 시편 하나의 Prony 적합 또는 글로벌 피팅 결과로, 속도 의존 카드는 글로벌 피팅 결과로 생성. 점탄성 카드는 온도 이동(WLF C1 · C2 또는 Arrhenius Ea)과 적합한 온도 범위를 함께 수록.
재료 기본 정보 카드시험 없이 재료 기재값(선언 물성)과 밀도 · 푸아송비만으로 만드는 카드. 생성 창 「재료 기본 정보로 카드 생성」 에서 「실릴 값」 을 확인하고, 탄성 · 열물성 외에 기재값이 닿는 다른 항목란은 「함께 실을 항목란」 에서 선택.시험 유래 값은 하나도 미포함. 선형탄성구간(LVE) 카드 생성 시에는 「재료 기본 정보 함께 포함」 으로 함께 수록 가능.
카드 항목란(블록)카드가 담는 칸의 묶음. 내장 항목란 17종: 「탄성」 · 「열물성」 · 「전기 · 전자기 물성」 · 「광학 물성」 · 「흡습」 · 「경화식」 · 「초탄성」 · 「소성 표」 · 「속도별 소성 표」 · 「온도별 소성 표」 · 「점탄성」 · 「선형탄성구간(LVE) 탄성률」 · 「유변」 · 「S-N 곡선」 · 「이방성 (r값)」 · 「모델 파라미터」 · 「참고 물성」. 새 항목란은 시스템 관리자가 「관리 › 카드 항목란」 에서 생성.화면에 따라 「블록」 으로도 표기(계산식의 「넣을 블록」). 내장 항목란은 코드가 등록하므로 화면에서 수정 불가. 카드가 사용 중인 항목란은 삭제 불가, 끄기만 가능. 칸이 가리키는 물성 키와 칸 단위의 차원이 같아야 저장 가능.
참고 물성해석 입력은 아니지만 재료 선정 · 검토 시 카드에서 함께 볼 값을 담는 항목란(유리전이온도 Tg · 융점 · 최대 사용온도 · 굽힘강도 · 경도 등). 재료에 해당 기재값이 있으면 카드 생성 시 자동 포함.카드에만 표시되고 덱에는 미포함. 카드 종류 판정에도 영향 없음. 굽힘탄성률은 인장 탄성계수와 다른 값이므로 덱의 E 로 사용 불가.
「여러 방향을 함께 써서 나옵니다」카드 항목란 설정의 체크 칸. 세 방향(MD · DD · TD)을 합쳐야 나오는 값(r̄ · Δr · Hill48)을 담는 항목란에 설정.미설정 시 그 결과로 카드를 만들면 「방향이 섞여 있습니다」 로 차단. 설정된 항목란이 든 카드는 방향이 빈칸.
초안 · 확정 · 사용 중지카드의 세 상태. 생성 시 「초안」, 자료 관리자가 승격하면 「확정」, 향후 사용하지 않을 카드는 「사용 중지」.확정 카드는 값 · 이름 수정 불가: 그 값으로 해석이 수행되었을 가능성 때문. 수정이 필요하면 사용 중지 후 신규 생성. 사용 중지는 삭제가 아니므로 내보내기는 계속 가능. 「초안으로 복원」 시 확정 절차 재수행 필요. 자료 관리자가 아닌 사람은 초안의 「확정 요청」 으로 자료 관리자에게 알림 발송(카드 상태는 초안 유지, 하루 한 번). 다른 시스템이 가져가는 대상은 확정 카드. 워크벤치 「카드 확정 전 검토하기」 의 「확정 또는 반려」 단계의 반려는 확정 보류, 즉 초안 유지를 의미(「반려」 라는 카드 상태는 없음).
카드 근거카드가 보유한 출처 정보: 사용 시험 · 표본 수 · 적합 구간 · 대표 곡선 기준 · 합성 여부 · 선언 값의 승인 상태.카드는 생성 시점의 값을 복사해 보관: 이후 재료의 밀도를 수정해도 확정 카드는 불변. 무엇을 어디서 가져왔는지가 근거에 함께 기록. 글로벌 피팅 결과가 탄성 칸을 산출해도 비어 있는 푸아송비 · 밀도는 재료에서 물려받음.
코멘트카드에 붙는 메모. 근거 시험이 다른 두께의 재료로 옮겨지면 서버가 자동 등록(카드 목록 · 탭에 「코멘트」 표시).카드 값은 불변. 해당 카드의 사용 중지 여부는 사람이 판단하며, 확정 카드는 자료 관리자가 정리. 「확정 요청」 기록도 카드에 남지만 코멘트 수에는 미포함, 초안에 「확정 요청됨」 표지로 구별.
덱카드를 해석 프로그램이 읽는 텍스트로 기록한 파일(.k · .inp · .rad 등). 카드의 「내보내기」 로 여는 「내보내기 — 〈카드 이름〉」 창에서 「덱의 단위계」 를 먼저 선택하고, 「툴」 · 「솔버 카드」 열에서 형식 선택, 「칸 배치 — 카드의 어느 값이 덱의 어디로 가나」 표와 덱 미리보기 확인 후 「내려받기」.덱 머리 주석에 값별 등급(「값 등급(1 좋음 ~ 4 계산·추정 — 문헌과 같은 척도)」)과 합성 · 점 수 축소 같은 사실 기재: 덱만 받은 사람도 파일 안에서 근거 확인 가능. 선택한 카드로 낼 수 없는 형식은 접힌 「이 카드로는 못 내는 형식 N개」 에 사유와 함께 표시. 파단 연신율은 LS-DYNA · Radioss 덱에 주석으로만 기재되며, 파단 칸 입력은 「추정 파단 변형률을 파단 칸에 넣기」(기본 꺼짐) 선택 시에만 수행.
형식덱을 쓰는 양식 하나 = 해석 프로그램 × 물성 모델(「LS-DYNA (탄소성)」 · 「ANSYS (선형)」 · 「Abaqus (점탄성)」 등). 구조 해석 프로그램 6종(LS-DYNA · Abaqus · Radioss · ANSYS · Nastran · OptiStruct)과 전자 · 광학 도구용 형식(AEDT · CST · Flotherm · Zemax · CODE V · n·k 표), 별도로 중립 JSON.이름의 괄호 앞이 해석 프로그램. 전자 · 광학 형식은 단위계 선택과 무관하게 항상 SI. 장비 파일을 읽는 「형식 프로파일」(02)과는 별개 용어.
기본 제공 형식 · 사용 중단앱에 내장된 형식 66종(중립 JSON 별도): LS-DYNA 11 · Abaqus 10 · ANSYS 13 · Radioss 9 · Nastran 8 · OptiStruct 9 · 전자 · 광학 6. 화면에서 수정 불가. 오류 발견 시 시스템 관리자가 「해석용 물성 정의」 화면 하단 「기본 제공 형식」 에서 「사용 중단」 처리.중단된 형식은 내보내기 메뉴 · 내려받기 · BOM 덱 · 문헌 덱에서 제외되고, 중단 주체 · 시각 · 사유가 변경 이력에 기록. 수정판 배포 후 「다시 쓰기」 로 복귀. 그 사이에는 「정의판 켜기」 로 정의판을 대신 사용 가능. 카드의 「사용 중지」 와 별개 용어.
정의판기본 제공 형식마다 그 내용을 해석용 물성 정의로 옮겨 둔 비상용 사본. 평소에는 꺼진 상태이며 이름 끝에 「· 정의」 가 붙음(예: 「Abaqus (탄소성) · 정의」).기본 형식을 「사용 중단」 한 줄에서 「정의판 켜기」 로 대체 사용, 정의 목록에서 수정 가능. 원래 형식을 「다시 쓰기」 할 때는 「정의판 끄기」 필요(그대로 두면 내보내기 메뉴에 같은 형식이 두 줄로 표시). 켜기 · 끄기는 고칠 권한이 있는 사람(자료 관리자 등)이 수행.
검증 모델내보내기 창의 「검증 모델」 단추로 받는 ZIP. 이 카드의 재료 덱을 1요소 인장 모델에 넣고 기대 응답(expected.csv)과 README 를 함께 수록. 탄소성 · 초탄성 형식(구조 해석 프로그램 6종 × 2 = 12종)에서 제공, 단위계는 항상 mm · N · tonne.칸이 한 칸 밀린 덱도 솔버는 오류 없이 실행하므로, 실제 실행 결과로 덱을 확인하는 목적. 솔버 결과 σx 가 expected.csv 마지막 줄과 1% 이내면 정상. 초탄성 기대값은 카드의 푸아송비로 압축성을 반영한 해. Radioss 반력 REACX 는 충격량이자 네 절점 중 한 절점의 몫이므로 (마지막 두 기록의 차 ÷ 시간 차) × 4 로 환산해 비교.
해석용 물성 정의코드 없이 정의로 추가하는 형식: 키워드 이름 · 줄 순서 · 칸 폭 · 필요한 항목란. 「데이터 체계 › 해석용 물성 정의」.새 해석 프로그램이나 사업부의 덱 관례를 배포 없이 추가. 정의는 기록 방식까지만 담당: 계산이 필요하면 새 물성(항목란 · 계산)의 영역. AI 도구에 예제 덱을 주면 초안을 작성하고 실제 카드로 덱을 그려 보인 뒤 확인을 거쳐 저장.
단위계덱 · JSON 에 기재될 수치의 단위 묶음. 기본 「mm · N · tonne (MPa)」, 그 밖에 「SI (kg · m · s · Pa)」 와 사용자 정의 계(질량 · 길이 · 시간 선택).앱은 항상 SI 로 저장하고 내보낼 때만 환산. 파일 이름에 단위계 표기(「_mm_n_tonne」). 단위계가 섞인 덱은 오류 없이 1000배 틀린 결과를 산출.
낼 수 있는 형식 · 형식 점검「CAE 카드」 탭의 「형식 점검」 단추(창 제목 「낼 수 있는 형식 점검」). 이 재료로 현재 산출 가능한 형식, 불가하면 부족한 항목과 보충 경로(「인장시험을 하면 생깁니다」 · 「이어진 문헌 재료에 채택할 값 3건」 · 「재료 기본 정보 카드로 적어 넣을 수 있습니다」)를 형식별 한 줄로 표시.판정 규칙은 내보내기와 동일: 「나옵니다」 로 표시되면 실제 산출 가능. 점검 전용이며 실제 내려받기는 카드의 「내보내기」 에서 수행. 안내에 따라 「준비도」 로도 표기.
짝 카드이방성 (r값) 카드를 내보낼 때 함께 고르는 같은 재료의 소성 카드(내보내기 창 「짝 카드와 합쳐 내기」).이방성 카드 단독으로는 Hill48 형식 산출 불가: 경화 곡선 · 탄성은 짝 카드에 있음. 두 카드가 한 재료로 출력.
소성 표(진소성변형률, 진응력) 점의 표. 해석 프로그램에 넘기는 곡선.카드 저장 시 기본 50점(꺾이는 구간에 조밀하게)으로 축소. 처리 단계의 300점은 통계 · 적합 입력이므로 그대로 보존, 축소 전후 점 수가 카드 근거와 덱 머리에 기록.
합성 소성 표곡선이 없는 재료에서 기재값(항복강도 · 인장강도 · 연신율)으로 생성한 소성 표. 「재료 기본 정보로 카드 생성」 창에서 「소성 곡선 합성 — 실측 아님」 선택 시에만 생성.실측이 아님: 카드 근거와 덱 각주에 「합성 — 실측이 아니다」 가 반드시 기재되고 등급은 4. 근거 값이 부족하면 생성하지 않고 사유 표시.
문헌 덱 · BOM 혼합 덱문헌 덱은 부품표의 재료 이름들을 문헌 재료와 짝지어 한 파일로 내는 덱(문헌 물성 화면 「문헌 덱 생성」). BOM 혼합 덱은 부품마다 사내 확정 카드를 우선 찾고, 없는 부품은 문헌 물성으로 보충(워크벤치 「부품표(BOM)로 여러 카드를 한 덱에」).문헌 재료에는 곡선이 없어 문헌 덱 범위는 탄성 · 열 · 전기 · 광학 · 흡습 · 초탄성 계수 · Cowper-Symonds(곡선은 「곡선 합성」 선택 시에만). 유전율 · 굴절률처럼 주파수 · 파장에 따라 변하는 값은 해당 축의 표로 기재. 탄성 · 열 · 전기 · 광학 값은 물성 매핑을 거친 것만 실리며, 매핑 없는 값은 덱 머리에 이름만 기재. BOM 혼합 덱에서 「곡선 합성 — 실측 아님, 덱에 합성 표지(고무는 곡선 대신 초탄성)」 를 켠 고무 분류 재료는 곡선 대신 해당 솔버의 초탄성 형식으로 산출: 문헌 초탄성 계수가 없으면 탄성계수 E 로 Neo-Hookean(C10 = E/6)을 생성하고 「합성 초탄성 — 실측이 아니다」 기재, 푸아송비는 생성하지 않음.

05 / 출처물성의 출처

같은 탄성계수라도 출처는 세 가지: 시험 측정값, 문서를 보고 사람이 기재한 값(선언 물성), 문헌 값. 앱은 셋을 섞지 않고 값마다 출처와 등급을 부여. 재료 상세 「물성 지도」 탭에서 셋을 「시험」 · 「선언」 · 「문헌」 으로 나란히 표시.

용어정의구별 · 유의점
잰 값시험을 처리 · 채택한 결과에서 나온 값. 「물성」 탭 표에서 「통계」(시편별 측정값의 통계) · 「피팅」(글로벌 피팅 결과) 배지로 표시.카드에서는 측정값 우선: 기재값은 측정값이 없는 칸만 채움.
선언 물성시험으로 얻지 않는 값을 문서를 근거로 사람이 기재한 것(열팽창계수 · 비열 · 열전도율 · 밀시트 값 등). 「물성」 탭 표의 「선언」 배지. 화면에서 「적어 둔 값」 으로도 표기.출처 선택 필수: 「문헌」 · 「규격」 · 「제품 데이터시트」 · 「밀시트(성적서)」 · 「추정」(「모름」 없음). 근거 문서 기재도 필수. 「온도 추가」 로 온도별 여러 점 기재 가능, 유전율 · 유전손실처럼 주파수에 따라 변하는 항목은 「주파수 추가」, 굴절률은 「파장 추가」(사내 물성 항목의 「값이 변하는 조건」 기준). 선팽창계수는 「할선 기준 온도 θ₀」 선택 입력 가능(덱의 ZERO · REFT · TREF 로 출력). 덱에는 「사람이 적은 값」 으로 근거 문서와 함께 출력.
승인 대기 값승인하면 등급이 오르는 선언 값을 모은 목록(「카탈로그 › 승인 대기 값」). 재료 · 층 · 항목 · 값 · 출처 · 근거 문서 · 등급을 한 줄에 표시.조회는 누구나, 승인은 자료 관리자가 줄의 「승인」 으로 수행(직후 「되돌리기」 가능). 근거를 더 확인하려면 재료 이름으로 해당 화면 이동. 배정 · 마감 기능은 없음. 값을 고칠 수 있는 사람은 재료 「물성」 탭의 「승인 요청」 으로 자료 관리자에게 알림 발송 가능. 수집함의 「승인 대기」(07)와 별개.
재료에 적는 값 · 시료에 적는 값Grade 가 같으면 같은 값(탄성계수 · 푸아송비 · 열물성 · 공칭 밀도)은 재료에, 로트마다 다른 값(밀시트의 항복강도 · 인장강도, 로트 실측 밀도)은 시료에 기재. 항목별 기재 위치는 사내 물성 항목의 「붙는 곳」 이 결정.밀시트는 「이 로트가 규격에 맞다」 는 증명서: 재료에 기재하면 첫 로트의 값이 그 Grade 전체의 값이 됨. 카드의 밀도는 시료 실측 → 재료 공칭 순으로 적용, 시료마다 다르면 자동 선택 없이 직접 입력 요구.
문헌 물성문헌 · 데이터시트에서 수집한 물성값 카탈로그(「카탈로그 › 문헌 물성」). 반영문헌 값을 사내 재료의 선언 물성으로 복사해 담는 행위(「반영」 · 「사내 재료에 반영」). 형식 점검 등에서는 「채택」 으로도 표기.복사본(스냅샷): 카탈로그가 다시 이관되어도 담은 값은 바뀌지 않고, 출처 · 등급이 근거로 함께 기록. 등급은 원래 문헌 값의 등급을 유지(값을 수정하면 출처 기준인 3으로 복귀). 사내 물성 항목에 매핑된 물성만 반영 가능. 시험 결과의 「채택」(02)과 별개.
물성 키문헌 물성 하나의 고정 식별자. 「mechanical.youngs_modulus」 처럼 분야.이름 형식이며, MatNexus 에서 만든 키는 「local.」 로 시작. 키마다 그 물성의 의미를 기술한 정의문이 붙음(271종).화면의 물성 이름과 별개. 한 번 만들면 불변: 다른 시스템이 이 키로 연결하기 때문. 잘못 만든 키는 삭제하지 않고 「폐기」 하며 대체 키 지정. 폐기된 키에는 새 값 등록 불가. 정의문 수정은 자료 관리자 권한.
물성 분류물성 목록의 분류 체계: 분야 ⊃ 물성군 ⊃ 물성(「공통 › 물성 분류」). 문헌 · 사내에서 만든 물성 전부가 대상이며, 바깥 시스템(Standard Platform)이 이 분류 그대로 물성 목록을 읽어 감.조회는 누구나, 편집은 자료 관리자. 물성 하나는 물성군 하나에만 소속. 「밀어 넣기」 로 엑셀 세 열(분야 · 물성군 · 물성)을 붙여 넣어 일괄 반영(미리보기 후 반영, 오류가 한 줄이라도 있으면 전체 미반영). 분야 · 물성군은 삭제 없이 「폐기」 만 가능(「폐기한 것도 보기」 에서 복원). 물성 키의 앞머리(mechanical. 등)와는 별개의 분류.
사내 물성 항목재료 · 시료에 값을 기재할 때 고르는 물성 이름(「탄성계수」 · 「항복강도」 등). 기준정보의 한 축이며, 「관리 › 온톨로지 편집」 의 「사내 물성 항목」 축에서 추가. 항목마다 차원 · 기호 · 붙는 곳(재료/시료)을 보유.물성 키와 별개: 물성 키는 문헌 쪽 이름, 사내 물성 항목은 사내 기재용 이름. 둘은 물성 매핑으로 연결. 예전 이름은 「물성 항목」.
물성 매핑사내 물성 항목을 물성 키에 연결하는 표. 「관리 › 온톨로지 편집」 의 「물성 매핑」(줄마다 「사내 항목 연결」). AI 쪽 안내에서는 「물성 연결」 로 표기.연결된 것만 사용: 기재값의 카드 칸 채우기, 값으로 찾기, 문헌 값 반영, 문헌 덱이 모두 이 연결을 거침. 미연결 시 오류 없이 조용히 누락. 차원이 다르면 연결 불가, 경도처럼 눈금(HV · HB · HRC)이 있는 항목은 눈금을 선택해 연결.
물성의 세 이름같은 물성의 세 가지 이름: 문헌 키(mechanical.yield_strength) · 사내 물성 항목(「항복강도」) · 시험 측정값(「오프셋 항복강도」 단계의 산출값).「물성 매핑」 표 한 줄에서 셋의 연결 여부 확인 가능. 「안 이어진 사내 항목」 이 0 이 아니면 우선 확인 필요: 해당 항목의 값은 검색에서 조용히 누락.
별칭 · 해소 못 한 물성 이름별칭은 물성 하나를 부르는 다른 이름(「yield strength」 · 「Rp0.2」 · 「σy」). 사전에 없는 말로 검색해 결과가 없으면 그 말이 「해소 못 한 물성 이름」 에 누적.시스템 관리자가 해당 물성을 지정하면 별칭으로 등록되어 이후 그 말로 검색 가능. AI 는 후보를 누적할 뿐 사전 수정 불가.
모델 파라미터여러 값이 한 벌이어야 의미가 있는 값(Anand 9개 · Prony 항 · Ogden 계수 · 크리프 Norton · Garofalo 계수). 「N벌」 로 세며, 재료의 「물성」 탭 표에 「문헌 묶음」 으로 표시.하나만 떼어 쓰면 모델에서 사용 불가: 그래서 한 벌 단위로 보관. 단위는 항마다 별도 기재. 카드는 벌을 소유하지 않고 인용(「모델 파라미터」 항목란).

06 / 권한기준정보와 권한

조회는 로그인한 사용자 전원에게 개방(모든 부서의 자료 · 정의 조회 가능). 수정 권한은 부서가 아닌 사람 기준: 해당 자료의 등록자, 편집을 받은 부서의 멤버, 자료 관리자, 시스템 관리자. 생성은 누구나 가능.

용어정의구별 · 유의점
기준정보등록 시 목록에서 고르는 값: 제조사 · Grade · 시편 규격 · 장비 · 사업부 · 사내 물성 항목 등. 축(제조사) · 값(포스코) · 별칭(「포스코(주)」 → 포스코)으로 구성.자유 입력 문자가 아니라 값을 가리키는 방식이므로, 값 이름을 한 번 수정하면 사용처 전체에 반영: Grade 수정 시 재료 · 시료 · 시편 · 시험 이름이 함께 변경.
온톨로지 조회 · 온톨로지 편집기준정보 조회 화면(「공통 › 온톨로지 조회」, 전원)과 편집 화면(「관리 › 온톨로지 편집」, 시스템 관리자). 편집 화면에서 오타 수정, 미사용 값 감추기, 물성 매핑 연결 수행.예전 메뉴 이름은 「기준정보」 · 「기준정보 편집」: 기능은 동일하며 화면 안의 개념 이름은 지금도 기준정보. 감춘 값은 목록에서만 빠지고, 이미 그 값을 쓰는 자료는 유지.
새 값을 세우는 축Family · Category · Grade · 제조사 · 거래처. 기존 값 선택은 누구나, 새 값 등록은 자료 관리자만 가능. 나머지 축은 누구나 새 값 추가 가능.오타로 재료가 둘로 갈리는 사고(SECC / SECC강판) 방지 목적. 화면은 「새로 추가」 대신 유사 값과 요청할 자료 관리자 이름을 표시. AI 로 재료 · 시료 · 시편 생성 시에도 목록에 없는 값이면 생성하지 않고 후보만 제시.
부서계정이 소속된 조직. 「관리 › 부서 정보」(화면 제목 「부서 관리」)가 전사 부서 목록, 「내 부서」 메뉴는 내가 속한 부서의 업무(부서 멤버 · 변경 이력).부서는 조회 범위를 제한하지 않음. 부서 단위로 켜던 「열람 제한」 도 폐지.
소속자료를 등록한 부서(재료 상세의 「소속」).권한이 아님: 어느 팀 자료인지 표시하는 칸. 수정 권한은 등록자 · 편집 부서가 결정.
사업부시험을 낸 사업부를 기록하는 기준정보 이름표.부서와 별개: 한 부서 계정으로 여러 사업부의 시험을 올리는 경우가 있어 별도 기록. 「물성 분석」 의 사업부별 보기가 이 값을 사용.
등록자해당 자료를 등록한 사람. 수정 권한의 첫 번째 근거.층마다 별도: 남의 재료 아래 시료 추가는 누구나 가능하며, 추가한 사람이 그 시료의 등록자. 「권한」 의 「등록자 넘기기」 로 이전.
편집 부서등록자 외에 해당 자료를 고칠 수 있도록 지정한 부서 1개(「편집을 받은 부서」). 자료 화면의 「권한」 에서 선택.소속과 다른 칸: 소속은 어느 팀 자료인지, 편집 부서는 누가 고치는지를 표시. 등록자가 언제든 변경 · 해제 가능. 자료 머리의 한 줄(「등록자 … · 편집 부서 …」)이 현재 수정 가능한 사람을 표시.
자료 관리자부서와 무관하게 모든 자료를 고칠 수 있는 역할. 카드 확정 · 확정 카드 정리 · 새 기준정보 값 등록 · 선언 물성 승인 · 핸드북 승인 · 정의판 켜기와 끄기 · 물성 분류 편집 · 정의문 편집 담당. 확정 · 승인 요청과 AI 가 한 확정 · 채택의 알림 수신. 시스템 관리자가 「관리 › 계정」(화면 제목 「계정 관리」)에서 지정.계정 · 서버 관리 권한 없음. 수정이 막히면 화면이 문의 대상을 이름으로 표시: 등록자 · 편집 부서 · 자료 관리자.
시스템 관리자계정 · 부서의 생성과 삭제, 「관리」 메뉴(사용 현황 · 계정 · 부서 정보 · 온톨로지 편집 · 계산식 · 카드 항목란 · 서버) 사용 권한 보유. 「사용 현황」 열람과 기본 제공 형식의 「사용 중단」 은 시스템 관리자 전용.1명뿐이면 그 계정이 잠겼을 때 복구가 어려우므로 화면이 2명 이상 지정을 권고.
부서 관리자부서 안의 역할: 부서 멤버 관리 · 장비 커넥터와 수집함 처리(「연결 정보」 탭 조회 포함) · 측정 의뢰 알림 · 자기 부서의 변경 이력 조회.자료 · 정의의 수정 권한은 부여하지 않음. 화면이나 안내에 「확정은 부서 관리자가」 라는 문구가 남아 있는 경우에도 현재는 자료 관리자의 업무.
검토자핸드북(「공통 › 가이드」, 화면 제목 「물성 핸드북」)의 초안을 승인해 본문으로 반영하는 사람. 현재 자료 관리자 · 시스템 관리자.누구나 절을 수정해 초안 제출 가능, 승인된 것만 본문에 반영. 검토자는 자기 수정을 바로 반영.
읽기 전용조회는 가능하나 수정 권한이 없는 자료에 붙는 표시. 옆에 사유 표시.단추를 눌러 거부되기 전에 미리 알리기 위한 표시. 액세스 토큰의 「읽기 전용」(07)과 별개.
「전역」폐지된 용어. 예전에는 부서를 가리지 않는 재료 · 정의를 「전역」 으로 지칭.현재는 정의(시험 종류 · 장비 파일 정의 · 레시피 · 해석용 물성 정의)의 키가 전사 공통 1개이고, 사람에게 보이는 것은 이름. 중복되던 키에는 꼬리가 추가됨(표시 이름은 유지).

07 / 연결장비 · AI · 기록

장비 PC, AI 도구, 다른 시스템이 MatNexus 에 들어오고 나가는 경로와 그 흔적이 남는 위치.

용어정의구별 · 유의점
보유 장비보유 설비 한 대 한 대의 기록: 위치 · 교정 이력. 「데이터 체계 › 보유 장비」.「측정법」 의 장비 카탈로그와 별개: 그쪽은 시장의 장비, 이쪽은 보유 장비.
장비 커넥터장비 PC 의 수집 에이전트(MatPylon)가 보낸 파일의 진행 상태를 보는 화면. 탭은 「전체」 · 「커넥터」 · 「수집함」 · 「실패」 · 「연결 정보」.에이전트는 시편을 생성하지 않음: 파일 이름에서 추출한 힌트로 서버가 후보를 좁히고, 하나로 정해지지 않으면 사람이 연결. 같은 파일이 다시 와도 중복 등록 없음. 「연결 정보」 탭(서버 주소 · 토큰 등 자격 증명)은 부서 관리자 · 시스템 관리자만 조회. 이 화면에서 발급하는 토큰의 기본 만료는 「만료 없음」.
수집함시편을 정하지 못한 파일의 대기 장소. 후보가 하나면 「승인 대기」 상태가 되고, 「승인 — 시험으로 등록」 시 시험으로 등록. 후보가 없거나 여럿이면 사람이 시편을 골라 연결.공지 · 변경 이력 등에서는 「수신함」 으로도 표기. 처리(승인 · 연결)는 해당 커넥터 부서의 부서 관리자 · 시스템 관리자가 수행. 파일이 「의뢰 #12 ①번 항목」 을 가리켜도 의뢰에 자동 연결하지 않음: 연결은 의뢰 상세의 항목에서 사람이 수행. 「카탈로그 › 승인 대기 값」(05)과 별개.
측정 의뢰「이 시료의 이 물성을 측정해 달라」 는 요청을 번호가 붙은 기록으로 관리하는 화면(「카탈로그 › 측정 의뢰」). 상태는 「작성 중」 → 「접수 대기」 → 「접수」 → 「시험 중」 → 「결과 전달」 → 「완료」, 곁가지로 「보류」 · 「반려」.받는 부서가 의뢰 상세의 항목에서 시험을 연결하면(「붙이기」 · 「시험 등록」) 「접수」 가 자동으로 「시험 중」 으로 전환되고, 결과가 채택되면 진행률 상승. 항목별 「시편 만들기」(방향 · 수량대로 생성) · 「여러 파일 한꺼번에」(올린 시험은 그 의뢰에 연결) 제공, 「이 의뢰의 시험 목록」 으로 연결된 시험 일괄 조회. 「결과 전달」 은 항목마다 채택된 결과가 1건 이상 필요. 작성 중인 의뢰는 작성자만 조회. 홈 「남은 일」 에 「받은 의뢰 시험 중」 · 「의뢰 기한 임박」 표시.
워크벤치 · 바구니여러 대상에 걸친 작업을 업무 단위로 진행하는 작업대(「내 활동 › 워크벤치」). 업무 8종을 묶음 4개(시험 데이터 · 물성 카드 · 해석 덱 · 장비 · 형식)로 구성: 「시험 데이터 한번에 등록하기」 · 「시험 데이터 한번에 처리하기」 · 「계산된 시험 데이터 한번에 채택하기」 · 「물성 카드 하나 만들기」 · 「카드 확정 전 검토하기」 · 「부품표(BOM)로 여러 카드를 한 덱에」 · 「여러 카드를 한 묶음으로 내보내기」 · 「새 장비 파일 연결」. 전용 화면이 있는 업무는 그 자리에서 완료, 나머지는 단계별 안내. 담은 시험 · 재료 · 카드가 바구니에 모임.시험 하나 · 재료 하나에 관한 작업은 해당 화면에 그대로 있음. 목록에서 「고른 N건 담기」 · 「워크벤치에 추가」 로 바구니에 담음. 바구니는 브라우저가 아닌 서버에 저장. 「계속」 열에서 진행 중인 작업 확인(「우리 부서」 · 「모든 부서」), 「이 작업을 끝내고 … 로 이어 하기」 로 다음 업무 연결. 채택 · 확정은 워크벤치가 대신하지 않고 사람이 수행.
채택 검토대워크벤치 업무 「계산된 시험 데이터 한번에 채택하기」(및 「시험 데이터 한번에 처리하기」 의 「한 번에 채택」 단계)의 전용 화면. 여러 시험의 처리 결과를 한 화면에서 견주어 한 번에 채택. 같은 재료 · 시험 종류 · 방향끼리 비교하며 「중앙값과 차이」 가 문턱(기본 10%)을 넘는 시험을 강조, 「겹쳐 보기」 로 곡선 중첩, 「한 건 자세히」 로 처리 전후 곡선 확인.채택은 사람이 「고른 N건 채택」 으로 수행. 누르기 전에 바뀌는 내용(새로 채택 · 「바꿈」 등)을 집계해 표시. 잘못 채택한 경우 「되돌리기」 로 이전 채택 복원(채택은 결과를 지우지 않음). 「이 시험 열기」 로 해당 시험의 결과 탭 이동.
AI(MCP)AI 도구가 MatNexus 를 사용하는 경로. 재료 검색부터 카드 · 덱 · 해석용 물성 정의 작성, 사내 물성 입력, 처리 결과 · 결과 곡선 조회, 레시피 이름 수정, 물성 분류 조회 · 밀어 넣기까지 가능. 「내 정보」 의 「AI 도구에 등록하기」(Claude Code · Claude Desktop · Codex CLI · Gemini CLI)에서 연결.권한은 토큰 소유자의 것: 화면에서 못 하는 일은 AI 로도 불가(물성 연결 · 카드 항목란 · 문헌 물성 키 저장은 시스템 관리자 토큰 필요). 카드 확정 · 처리 결과 채택 · 의뢰 제출 · 시험 파일 업로드 · 새 기준정보 값 생성도 미리보기 확인 후 수행(권한은 토큰 소유자의 것). AI 가 카드 상태 · 채택을 바꾸면 자료 관리자에게 알림. 삭제 · 선언 물성 승인 · 수집함 승인은 수행하지 않음(사람의 몫). 단위 미지정 시 mm · N · tonne 으로 답하고 SI 값을 괄호에 병기.
미리보기저장 전에 결과를 먼저 보여 주는 단계. AI 의 저장 도구는 전부 미리보기가 기본이며, 계산식 · 여러 시험에 같은 단계 적용 · 다른 두께로 옮기기에도 있음.미리보기는 저장 · 채택에 영향 없음. AI 가 그려 보인 덱은 보유한 예제 덱과 나란히 비교해 확인 필요: 칸이 한 칸 밀려도 해석 프로그램은 오류를 내지 않기 때문.
액세스 토큰화면 밖에서 접속할 때 쓰는 열쇠. 「내 정보 › 액세스 토큰」 에서 발급. 수집 에이전트 · AI 도구 · 직접 작성한 스크립트가 모두 이 토큰으로 접속. 발급 시 만료(「30일」 · 「90일」 · 「1년」 · 「만료 없음」, 기본 90일)와 「읽기 전용」 여부 선택.토큰이 곧 그 계정의 자격: AI 용 토큰을 따로 받을 필요 없음(용도별로 이름을 나눠 두면 개별 폐기 가능). 평문은 발급 직후 1회만 표시, 분실 시 재발급. AI 도구 · 장비 설정 파일에 평문으로 남으므로 만료를 짧게 두고 사람 · PC 변경 시 즉시 폐기 권장. 장비 커넥터 화면에서 발급할 때는 기본 「만료 없음」.
읽기 전용 토큰발급 시 「읽기 전용」 을 선택한 액세스 토큰. 조회(GET)만 허용.바깥 시스템(Standard Platform 등)이 물성 목록을 정기적으로 읽어 갈 때 사용. 이 토큰으로는 자료 수정 · 새 토큰 발급 등 어떤 변경도 불가. 고칠 권한이 없는 자료의 「읽기 전용」 표시(06)와 별개.
「AI(MCP) 경유」변경 이력에서 AI 가 대신 수행한 일에 붙는 표시. 「전부」 · 「AI(MCP) 경유」 · 「화면에서」 로 필터.권한은 항상 사람의 것이므로 「누가」 만으로는 사람이 한 일과 AI 가 한 일이 구별되지 않음: 이 표시로 구별.
변경 이력누가 · 언제 · 무엇을 바꿨는지의 기록(「내 부서 › 변경 이력」). 수정 · 삭제 불가, 바뀐 칸만 표시.모든 편집이 기록되지는 않음: 삭제 · 카드 확정과 사용 중지 · 등록자와 편집 부서 변경 · 남의 자료 수정 · 기본 형식 사용 중단 · 해석용 물성 정의 켜기와 끄기 · 선언 물성 승인과 승인 풀림 · 물성 분류 변경처럼 추적이 필요한 일과, AI(MCP)가 수행한 쓰기가 기록 대상.
내 자료 변경 이력내가 등록한 자료에 다른 사람이 한 일: 누가 · 언제 · 어떤 근거(자료 관리자 · 편집을 받은 부서)로 수정했는지(「내 활동 › 내 자료 변경 이력」).내가 직접 한 일은 미표시, 내 이름으로 AI 가 한 일은 표시.
휴지통삭제한 항목이 이동하는 장소(「내 활동 › 휴지통」). 삭제 시 기록이 남으므로 복원 가능.내가 복원할 수 있는 항목(내가 등록했거나 편집을 받은 부서의 것)만 표시. 「영구 삭제」 는 되돌릴 수 없음.
사용 현황앱 사용량 집계 화면(「관리 › 사용 현황」). 기간 7일 · 30일 · 90일 · 1년, 사람 · 기능 · AI(MCP) 도구 호출 · 가입 현황과 부서별 표 · 사람별 활동 표시.사람별 사용량이 드러나므로 시스템 관리자만 열람. 사람별 활동 전체는 「사람별 전부 CSV」 로 내려받기.
내보내기 셋카드의 「내보내기」(덱 · 중립 JSON, 해석용) · 재료와 문헌의 「JSON 내보내기」(단위계를 골라 받는 값 묶음) · 「서버 › 데이터 내보내기」(시스템 관리자가 다른 플랫폼에 넘길 CSV 묶음).앞의 둘은 단위계 선택(기본 mm · N · tonne), 데이터 내보내기는 SI. 데이터 내보내기에는 모든 부서의 자료와 문헌 값이 함께 포함: 넘기기 전에 다른 부서의 동의와 문헌 값의 이용 조건 확인 필요.
