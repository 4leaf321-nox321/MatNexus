# 압축 (고무 · 폼 · 플라스틱 · 금속)

하중-변위(또는 압축계 변형률)에서 압축 응력 · 변형률 · 탄성률과 규격 보고값을 낸다(2026-10-16).
시험 종류(`compression`) · 시편 분류(「압축」) · 규격 카탈로그는 중심이 든다.

## 쓰는 법

### 1. 시편 규격

「표준 규격 가져오기」 의 압축 규격 — 초기 높이와 하중 면(원통 직경 또는 직육면체 가로 x 세로)
이 단면적 식과 함께 온다.

    ISO 7743 A      직경 29 · 높이 12.5        고무, 4번째 하중 구간
    ASTM D575       직경 28.6 · 높이 12.5      고무
    ISO 3386-1      100 x 100 x 50             연질 폼, CV40, 4번째
    ASTM D3574 C    50 x 50 x 25 이상           연질 폼, 25 · 50 · 65%, 3번째
    ISO 844 · D1621 경질 폼                     10% 전 최대 또는 10% 응력
    ISO 604         50 x 10 x 4 (탄성률)        플라스틱, 현 0.05 ~ 0.25%
    ASTM D695       12.7 x 12.7 x 25.4 (강도)   L = 2W
    ASTM E9         원통, L/D 2 · 3 · 8 · 10    금속
    D6641 · D3410   복합재 — 변형률은 스트레인 게이지로

### 2. 처리

    compression.engineering   압축 응력 · 변형률(양수), 부호 자동, 접촉점, 하중 구간 선택
    compression.toe_compensation  토우 보정 — 인장의 계산(`tensile.toe_compensation`)을 압축 열로
    compression.modulus       탄성률 — 기본 할선 10%(고무 · 폼), 플라스틱은 현
    compression.indices       10 · 20 · 25 · 40 · 50 · 65% 응력, 압축 강도, 폼 지표

**시편 규격의 처리 기본값**이 방법을 덮는다(ADR 0062) — ISO 7743 · ISO 3386-1 은 4번째 하중 구간,
ISO 604 는 현 0.05 ~ 0.25%, D695 · E9 · 경질 폼은 접선, D6641 · D3410 은 변형률 채널 + 현 0.1 ~ 0.3%.

## 아는 함정

- **압축량을 양수로 쓴다.** 대표 곡선 · 통계가 오름차순 변형률을 전제한다. 초탄성 적합은 식을
  이 축에 뒤집어 건다(`σc(εc) = -P(-εc)`, `matcore.fitting.hyperelastic.compression`) — 열을 따로
  옮기지 않는다.
- **접촉점은 문턱을 넘은 점이 아니다.** 문턱(기본 최대 하중의 0.5%)을 넘기 직전 하중이 거의 0
  인 마지막 점이다. 문턱 점을 0 으로 두면 깨끗한 곡선에서도 변형률이 밀려 할선 E 가 커진다
  (시험을 쓰다 실측 — 30% 에서 0.298).
- **압축 강도는 곡선 전체의 최대가 아니다.** 경질 폼은 치밀화 뒤 응력이 항복 봉우리보다 크다 —
  10% 전의 봉우리를 본다. 사보타주로 확인.
- **곡선이 닿은 변형률만 낸다.** 50% 까지 누른 시험에서 65% 응력을 지어내지 않는다.
- **단계는 키로만 거른다.** 굽힘과 같은 사정(`SAME_SHAPE_AS_TENSILE`).
- **장비 파일 형식은 실파일 없이 적었다.** Zwick `Standardkraft` · `Standardweg` · `Dehnung`,
  Instron `Compressive extension` · `Compressive load` · `Strain 1`.

## 기록

- 2026-10-16 처음 — 부호 · 접촉점 · 사이클(Mullins), 지표, 폼 지표(ISO 13314 식).
  초탄성 · 폼 덱으로 가는 카드는 아직 없다.
- 2026-10-20 사용자 보고(v1.285.0 「압축 시험을 처리할 단계가 없다 · 폼 / 초탄성을 해석 카드로
  내보낼 경로가 없다」)에 남은 것을 채웠다.
  - **토우 보정**은 인장의 것을 그대로 — 열 이름만 압축의 것(`toe_params` · `toe_compensation_on`).
    처리 엔진이 열 칸의 기본값을 채우지 않아, 기본 열을 채워 부르는 손잡이를 등록한다.
  - **초탄성 압축 모드** — `<식>_compression`(Neo-Hookean · Mooney-Rivlin · Yeoh · Ogden). 식은 인장과
    같고 축만 압축 열이다. 블록 mode 「단축 압축」, 카드 근거 「단축 압축 하나로 맞춘 계수」, 덱은 식의
    이름(`model`)으로 옮긴다. 시험: 압축 곡선 → 초탄성 카드 → 근거까지(`test_bend_compress_api`).
  - **폼 카드** — 묶음 `compression.foam`(시편 곡선을 가장 짧은 끝까지 보간해 평균, 공칭 그대로),
    블록 `foam_curve`, 덱 `dyna_foam`(LS-DYNA *MAT_LOW_DENSITY_FOAM 057). 응력이 내려가는 곡선(경질
    폼의 항복 봉우리)은 내보내지 않는다 — 파쇄형 폼이 맞다. HU · DAMP 는 LS-DYNA 기본값이라 그렇다고
    덱에 적는다.
  - 사보타주: 부호 안 뒤집기 · 식 이름 안 남기기 · 가장 긴 끝까지 평균 · 내려가도 내보내기 — 넷 다
    시험이 물었다.
  - 남은 것: 경질 폼의 *MAT_CRUSHABLE_FOAM(063 — 체적 변형률 대 항복 응력), Abaqus *HYPERFOAM ·
    *CRUSHABLE FOAM, 반복 압축의 HU(이력)를 시험에서 정하기.
- 2026-10-20 검토에서 고친 것 둘.
  - **「쓸 하중 구간」 -1 = 전부** — 하중 구간이 여럿이면 하나만 남겨, 뒤에 둔 반복 시험 단계
    (`cyclic.*`)가 「사이클을 찾지 못했습니다」 로 멈췄다(원인과 다른 안내). 반복 압축의 사이클
    분석을 하려면 -1 로 둔다 — 그때 탄성률 · 지표는 전체 곡선에서 읽힌다고 적는다.
  - **압축으로 맞춘 초탄성 카드가 Abaqus 로 안 나가던 것** — 중심의 Abaqus 초탄성 렌더러만 식 이름
    (`model`) 대신 `family`(`neo_hookean_compression`)를 읽었다. 시험이 이제 카드가 고를 수 있다고 한
    형식을 전부 내본다(`test_bend_compress_api`).
