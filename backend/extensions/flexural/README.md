# 굽힘 (3점 · 4점)

하중-처짐에서 굽힘 응력 · 변형률 · 탄성률(등가 E) · 강도를 내고, 시편 여럿을 묶어 **등가 E 카드**
를 만든다. 칩 · 모듈처럼 인장 시편을 못 만드는 것의 E 를 내는 길이다(2026-10-16).

시험 종류(`flexural`) · 시편 분류(「굽힘」) · 규격 카탈로그는 중심이 든다 — 확장은 DB 를 모른다.

## 쓰는 법

### 1. 시편 규격을 고른다

「온톨로지 편집 › 표준 규격 가져오기」 에서 굽힘 규격을 가져온다. 규격이 스팬 · 폭 · 두께
(4점은 하중 스팬)의 칸과, 정해진 치수가 있으면 그 값을 함께 준다.

    ISO 178        80 x 10 x 4, 스팬 64 (16h)
    ASTM D790      127 x 12.7 x 3.2, 스팬 50.8 (16:1, 32 · 40 · 60 선택)
    ASTM D7264     13 x 4, 스팬 128 (32:1), 4점은 Lᵢ = L/2
    ASTM C1161 B   4 x 3 x 45, 스팬 40 · 하중 스팬 20
    사내 3점 · 4점  치수 없음 — 시편마다 잰다

### 2. 처리

    flexural.engineering   스팬 · 폭 · 두께 → 굽힘 응력 · 변형률(잰 배치를 결과에 남긴다)
    flexural.toe_compensation  토우 보정 — 인장의 계산을 굽힘 열로(D790 부록 A1)
    flexural.modulus       탄성률(등가 E) — 현 · 회귀 · 할선 · 접선 · 응력 띠
    flexural.strength      강도 · 파단 · σfC(변형률 3.5%)

화면은 이 순서를 깔아 둔다(`STARTERS.flexural`). 하중 스팬 기본은 `@?specimen_load_span` —
**있으면 쓰는** 참조라 시편에 하중 스팬이 있으면 4점, 없으면 3점이다. 그리고 **시편 규격의 처리
기본값**이 방법을 덮는다(ADR 0062) — D790 은 접선, ISO 178 · 14125 는 현 0.05 ~ 0.25%, D7264 는 현
0.1 ~ 0.3%, C1161 · 사내는 응력 띠. 4점 규격은 하중 스팬을 `@` 로 걸어 없으면 멈추고, 3점 전용 규격은
비움으로 고정한다.

### 3. 묶어 카드로

`flexural.equivalent` 가 시편 둘 이상의 굽힘 탄성률을 평균 내고, 카드는 **탄성 블록의 E** 와
참고 물성(굽힘 탄성률 · 강도)을 든다. 곡선 없이 보고서만 있는 시험은 「표로 시험 입력」 의
`flexural_modulus` 열로 들어온다.

## 식

모멘트 팔 a = (L - Lᵢ)/2 로 3점과 4점을 한 식으로 쓴다(3점은 a = L/2).

    σ = 3·F·a / (b·h²)
    ε = 12·h·δ / (3L² - 4a²)          가운데 처짐
    ε = 3·h·δ / (a·(3L - 4a))         하중점 처짐(4점 크로스헤드)

D6272 의 4.70 · 4.36 계수(Lᵢ = L/3 · L/2)가 이 식에서 나온다 — 시험이 문다.

## 아는 함정

- **크로스헤드에는 장비 처짐이 섞인다.** 칩처럼 짧고 단단하면 시편 처짐과 같은 자릿수라 E 가
  크게 작아진다. 처짐계를 쓰거나 「장비 컴플라이언스 C」 를 준다(δ - C·F).
- **스팬/두께 16 미만은 전단 처짐이 섞인다.** 보정하지 않고 말만 한다 — G 를 모른다.
- **큰 처짐 보정은 D790 3점 식만 있다.** 4점에 켜면 안 했다고 적는다.
- **등가 E 는 인장 E 가 아니다.** 적층 · 이방성이면 다르다. 카드 근거에 그렇게 적는다.
- **단계는 키로만 거른다.** 하중 · 변위는 인장도 같아서, 채널로 거르면 인장 시험 목록에 굽힘
  단계가 뜬다(`tests/architecture/test_applies_to.py` 의 `SAME_SHAPE_AS_TENSILE`). 부서가 굽힘
  종류를 따로 만들면 이 단계가 안 보인다.
- **장비 파일 형식은 실파일 없이 적었다.** Zwick 은 `Deflection` · `Durchbiegung` · `Standard
  travel`, Instron 은 `Flexure extension` · `Flexure load` · `Deflection` 으로 읽는다. 실파일이
  오면 `tests/unit/test_bend_compress_files.py` 에 더한다.

  (`matcore/slopes.py`), 등가 E 묶음 · 카드. 사보타주: 가운데 · 하중점 계수를 바꾸면

- 2026-10-20 **토우 보정**(인장의 계산을 굽힘 열로)과 **구조 강성 블록**(`structural_stiffness`,

  보 단면)는 모델마다 달라 JSON 으로 옮긴다. EI(N·m²)는 단위표에 그 차원이 없어 싣지 않았다 —
  단위계 환산이 그 차원을 알아야 한다(중심에 요청할 일).
- 2026-10-20 검토 — 구조 강성 블록의 시편 수가 **강성이 있는 시편 수**가 아니었다(묶음의 시편 수 =
  굽힘 탄성률이 있는 시편 수라, 다섯 중 둘만 평균해도 「5」). `flexural_stiffness_count` 를 따로 센다.
