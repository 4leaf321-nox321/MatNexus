# 응력완화 확장 (`relaxation`)

응력완화 곡선 → 완화 탄성률 E(t)(처리 `relaxation.modulus`), 여러 시험 → 시간 영역 Prony(묶음
`relaxation.prony`) → 점탄성 카드. 계산과 근거는 `prony_time.py` 문서에 있다.

## 기록

- 2026-10-12 처음 — τ 를 자릿수마다 못 박고 Eᵢ 만 비음수 최소제곱으로. 카드의 탄성계수는 순간 탄성률.
- 2026-11-14 VOC 52(ADR 0081) — 가장 짧은 τ 를 `10^⌊log t_min⌋` 에서 **첫 측정 시각**으로. 첫 측정이
  0.95 s 냐 1.0 s 냐로 E₀ 가 539배 뛰었다. 외삽 배수 `instantaneous_ratio`(E₀ / E(t_min)) · 잰 시간 범위를
  카드에 두고, 1.5 를 넘으면 경고. 덱 머리말은 중심이 적는다. 시험 온도가 비면 중심(파싱)이 거의 일정한
  온도 채널의 중앙값으로 채운다. 묶음 버전 2. 사보타주: 옛 격자면 `test_ext_relaxation.py` 의 「뛰지
  않는다」 가 문다. 남은 것: DMA 마스터커브로 짧은 시간을 메우는 결합(설계 먼저).
- 2026-11-15 VOC 52 — **온도가 2 K 넘게 섞이면 묶지 않는다**(전에는 경고만 달고 카드까지). 옮기지 않은 채
  한데 맞추면 20 · 40 · 60 °C 묶음이 40 °C 로 적히고 그 온도의 참값과 1.72배 틀렸다(합성 실측, 상대 RMSE
  37 %). DMA 묶음(0.5 K)과 같은 방향. 이미 만든 묶음 결과 · 카드는 그대로이고, 같은 선택으로 다시 묶으면
  그때부터 거절된다. 묶음 버전 3.
