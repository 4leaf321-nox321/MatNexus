# 응력완화 확장 (`relaxation`)

응력완화 곡선 → 완화 탄성률 E(t)(처리 `relaxation.modulus`), 여러 시험 → 시간 영역 Prony(묶음
`relaxation.prony`) → 점탄성 카드. 계산과 근거는 `prony_time.py` 문서에 있다.

## 기록

- 2026-10-12 처음 — τ 를 자릿수마다 못 박고 Eᵢ 만 비음수 최소제곱으로. 카드의 탄성계수는 순간 탄성률.
- 2026-11-14 VOC 52(ADR 0081) — 가장 짧은 τ 를 `10^⌊log t_min⌋` 에서 **첫 측정 시각**으로. 첫 측정이
  0.95 s 냐 1.0 s 냐로 E₀ 가 539배 뛰었다. 외삽 배수 `instantaneous_ratio`(E₀ / E(t_min)) · 잰 시간 범위를
  카드에 두고, 1.5 를 넘으면 경고. 덱 머리말은 중심이 적는다. 시험 온도가 비면 중심(파싱)이 거의 일정한
  온도 채널의 중앙값으로 채운다. 묶음 버전 2. 사보타주: 옛 격자면 `test_ext_relaxation.py` 의 「뛰지
  않는다」 가 문다. 남은 것: DMA 마스터커브로 짧은 시간을 메우는 결합(설계 먼저).
- 2026-11-15 VOC 52 — **온도가 2 K 넘게 섞이면 묶지 않는다**(전에는 경고만 달고 카드까지). 옮기지 않은 채
  한데 맞추면 20 · 40 · 60 °C 묶음이 40 °C 로 적히고 그 온도의 참값과 1.72배 틀렸다(합성 실측, 상대 RMSE
  37 %). DMA 묶음(0.5 K)과 같은 방향. 이미 만든 묶음 결과 · 카드는 그대로이고, 같은 선택으로 다시 묶으면
  그때부터 거절된다. 묶음 버전 3.
- 2026-11-15 VOC 52(ADR 0087 1단계) — **응력완화 + DMA 마스터커브 잇기**(`relaxation.dma_coupled`,
  `coupling.py`). 한 온도의 응력완화 + 대표 마스터커브 하나. 마스터커브를 이동 상수로 응력완화 온도로 옮기고
  (맞춘 온도 범위 밖이면 막음), DMA Prony 는 완화시간을 자릿수마다 못 박아 다시 맞춰 시간 영역으로 바꾼다.
  겹친 구간의 비(응력완화 ÷ DMA) 중앙값이 5 % 넘으면 경고, 25 % 넘거나 겹친 점이 셋 미만이면 막음(잠정).
  짧은 끝 ~ DMA 창 끝의 1/10 의 DMA 곡선과 응력완화 점을 같은 무게로 모아 한 벌로 맞춘다(완화시간 상한 24).
  선형 구간: 재료의 `lve_strain_limit`(중심이 `material_scalars` 로 모음)과 유지 변형률을 견주고, 없으면 경고.
  중심의 일반 장치 셋을 썼다 — 구성원 규칙 `by_test_type` · `from: master_curve` · `material_scalars`, 카드의
  `card_test_type`. 합성 재료(E₀ 3 GPa)에서 응력완화만 0.2 GPa 대 이어서 ±5 %. 사보타주: 이동 방향을 뒤집으면
  넷 · 막는 선을 끄면 하나가 문다. 두 쪽 같은 무게는 끄면 DMA 쪽 잔차가 1.69 → 1.85 % 로만 변해 시험을 두지
  않았다(설계 선택). 남은 것: 전단 마스터커브(ν 로 E 로), 여러 온도 함께 옮기기, 실재료 쌍으로 선 다시 정하기.
- 2026-11-15 전반 점검 — **변형률 · 응력 열의 빈 칸**. 변형률 열에 NaN 하나면 평균이 NaN 이 되고
  `strain <= 0` 검사를 통과해 유지 변형률 · E(t) 가 전부 NaN 으로 저장됐다. 빈 칸은 평균에서 빼고 몇
  개였는지 노트로 남긴다. 열이 통째로 비었거나 첫 응력이 비면 멈춘다.
- 2026-11-15 ADR 0087 후속 — **전단(G′) 마스터커브도 잇는다**(`relaxation.dma_coupled` 판 2, 전에는 막음).
  저장 · 손실 탄성률에 2(1+ν) 를 곱해 E′ · E″ 로 옮긴 뒤 같은 길(`matcore.viscoelastic.youngs_from_shear`,
  -1 < ν ≤ 0.5). ν 는 묶음 옵션 `poisson_ratio` → 재료의 푸아송비 → 둘 다 없으면 막는다(`dma.to_shear` ·
  DMA 온도별 카드와 같은 규칙 — 지어내지 않는다). 재료의 칸은 중심의 새 일반 장치 `material_fields`
  (재료의 기본 칸 `poisson_ratio` · `density` 를 구성원 값에 싣는다)로 받는다. 전단 판정도 중심이 카드와
  같은 근거로 넓혔다 — 측정 채널이 G′ 이거나 변형 모드가 전단 계열. 쓴 ν 는 값 `dma_poisson_ratio`, 출처는
  상세 `dma_poisson_source`(option · material), 무엇을 잰 것인지는 상세 `dma_modulus_basis` → 카드
  `modulus_basis`. 경고: 변환과 ν · 출처, 카드의 ν 를 같게 두라는 말(덱이 카드의 ν 로 G 를 다시 만든다),
  ν ≥ 0.45 면 고무 쪽 오차(ν 의 시간 의존 · K 의 민감도). 인장 마스터커브에 준 ν 는 「안 썼다」 고 말한다.
  합성: G′ = E′/2(1+ν) 로 넣으면 E₀ · 겹친 구간 비가 인장으로 넣은 것과 1e-6 안에서 같다. 사보타주: 배수를
  안 곱하면 다섯 · 옵션과 재료 순서를 뒤집으면 하나 · 변형 모드 판정을 빼면 하나 · `material_fields` 를
  안 실으면 하나가 문다.
