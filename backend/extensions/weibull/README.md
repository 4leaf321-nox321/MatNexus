# 와이블 강도 분포

시편 여럿의 파단 하중 · 강도를 2모수 와이블로 맞춰 카드 블록에 싣는다(2026-10-20).

| 무엇 | 하는 일 |
| --- | --- |
| 묶음 `weibull.strength` | 고른 값 하나(최대 하중 · 파단 하중 · 박리 강도 · 인장 · 굽힘 · 압축 강도) → 형상 m · 척도 x₀ · 하위 5 % · 중앙값 |
| 블록 `strength_distribution` | 분포 · 맞춘 값 · 형상 m(`mechanical.weibull_modulus`) · 시편 수, 행에 척도 · 분위수(**행이 자기 단위를 든다**) |

## 정한 것

- **적합은 중심의 분포 모듈 그대로다**(`matcore.distributions` 의 와이블 — 위치 0 고정, 최대우도).
  두 벌로 두면 한쪽만 고쳐진다.
- **곡선이 없어도 된다** — 구성원 규칙이 `measured_or_stated` 라, 시편마다 파단 하중을 「표로 시험
  입력」 으로 넣으면 그 요약값으로 맞춘다(열 이름 `max_force (N)` · `break_force (N)` 등).
- **5 개 미만이면 안 맞추고, 10 개 미만이면 경고한다** — 형상 계수가 시편 수에 크게 흔들린다(ASTM
  C1239 는 30 개 이상을 권한다).
- 척도 · 분위수는 맞춘 값에 따라 N · Pa · N/m 이라 블록 값이 아니라 **행**에 단위(`si_unit`)와 함께
  싣는다 — 경화식 행과 같은 칸이라 단위계를 바꾸면 함께 옮겨지고(강도는 mm 계에서 MPa) 화면도 그
  단위로 적는다. 덱으로 갈 값은 아니다(JSON).

## 남은 것

- **형상 · 척도만 있는 외부 자료**: 형상은 기본 물성 항목 「와이블 계수」(문헌 키
  `mechanical.weibull_modulus` 에 씨앗으로 이어짐)로 재료에 적고, 「재료 기본 정보 카드」 의 「함께
  실을 항목란」 에서 「강도 분포」 를 고르면 형상 칸에 앉는다(`tests/api/test_weibull_api.py`). 척도는
  맞춘 값마다 단위가 달라(N · Pa · N/m) 문헌 키 하나로 못 두었다 — 행으로만 싣는다.
- 확률지 그림(와이블 플롯) — 통계 화면의 분포 표는 수만 보인다.

## 기록

- 2026-10-20 처음 — 사용자 보고(곡선 없이 파단 하중과 와이블만 있는 외부 자료를 담을 블록이
  없었다). 사보타주: 하위 5 % 를 10 % 로 — `test_ext_weibull.py` 가 물었다.
- 2026-10-20 검토에서 고친 것. **값이 모두 같으면 맞추지 않는다** — 흩어짐이 0 이라 m 이 무한대로
  가서, 50 다섯 개에 m = 5e6 이 경고 없이 나왔다(표로 적은 값이 반올림된 경우). 거의 같아 m 이 100 을
  넘으면 경고한다. 무한대 값은 빼고 센다(scipy 가 ValueError 로 터졌다). 행의 단위 칸을 `unit` 에서
  `si_unit` 으로 — `unit` 이던 때는 단위계 환산이 그 값을 SI 로 남겨, MPa 계라고 적힌 JSON 에 Pa
  숫자가 나갔다.
