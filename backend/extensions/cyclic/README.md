# 반복(사이클) 시험 공용 단계

반복 인장 · 반복 압축 · 반복 굽힘이 함께 쓰는 처리 단계(2026-10-20).

| 단계 | 하는 일 | 남기는 값 |
| --- | --- | --- |
| `cyclic.cycles` | 사이클 분리 — 점마다 사이클 번호 · 하중(+1)/제하(-1) 가지 | `cycle_count`, 열 `cycle` · `cycle_branch` |
| `cyclic.unloading_modulus` | 제하 가지 윗부분(꼭짓점에서 응력 폭의 50 %)의 기울기 | 첫 · 마지막 · 평균, 마지막/첫 비, 사이클마다(`_c1` …) |
| `cyclic.residual_strain` | 제하가 응력 0 을 지나는 변형률 | 첫 · 마지막 · 평균 · 최대, 사이클마다 |
| `cyclic.hysteresis` | 고리 넓이 ∮σ dε(J/m³) · 하중 에너지에 대한 비 | 첫 · 마지막 · 평균 · 합, 사이클마다 |

## 정한 것

- **시험 종류를 따로 두지 않는다.** 반복 인장은 하중이 오르내리는 인장 시험이다. 앞 단계(인장 ·
  압축 · 굽힘의 응력-변형률)가 만든 열을 찾아 쓴다 — 인장 공칭(`strain_engineering`) · 압축
  (`compressive_strain`, 양수) · 굽힘(`flexural_strain`) 차례. 하중 채널이 있는 시험이면 단계 목록에
  선다(`requires_channels`) — 부서가 「반복 인장」 종류를 따로 만들어도 그대로 쓴다.
- **사이클은 응력(하중)이 뒤집히는 곳으로 나눈다** — 변형률로 나누면 안 된다. 금속의 탄성 제하는
  변형률을 0.05 % 쯤만 되돌려 전체 폭(수 %)에 비하면 잡음과 구별이 안 된다(처음 설계를 수치 예로
  대 보다 드러났다). 잡음을 세지 않도록 전체 응력 폭의 5 %(`min_amplitude`)보다 크게 돌아가야
  뒤집힘으로 보고, **변형률도 함께 줄어야** 제하로 본다 — 네킹 · 파단처럼 변형률은 늘며 응력만
  떨어지는 것은 제하가 아니다(단조 시험에서 사이클이 생기지 않는다). 사이클 k = 골(또는 시작) →
  꼭짓점 → 다음 골. 제하 없이 끝난 마지막 하중은 사이클로 안 센다.
- **사이클마다의 값은 100 개까지**(앞 50 · 뒤 50) — 넘으면 요약(첫 · 마지막 · 평균)만 믿을 만하다.
- **잔류 변형률은 응력 0 까지 제하했을 때의 값이다.** 0 까지 안 내린 사이클은 제하 끝의 변형률을
  쓰고 그렇다고 말한다(실제보다 크다).

## 남은 것

- 압축 처리(`compression.engineering`)는 사이클 하나를 골라 자른다 — 반복 압축을 이 단계로 보려면
  그 단계의 「쓸 하중 구간」 을 쓰지 말고(전체를 두고) 응력-변형률만 내는 길이 필요하다. 지금은
  압축 단계가 늘 한 구간을 고른다.
- 사이클 번호를 x 축으로 한 그래프(제하 탄성률 · 잔류 변형률 대 사이클)는 처리 결과의 값 목록으로만
  보인다.
