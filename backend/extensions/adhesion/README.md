# 박리 · 이탈력

테이프 박리 · 배터리 PTT(당김) · SIM 트레이 삽입/인출 — 하중-변위 곡선에서 값을 내고, 해석용
응집 영역 블록까지(2026-10-20).

| 무엇 | 하는 일 |
| --- | --- |
| 처리 `adhesion.peel` | 최대 하중(N) · 그 변위, 안정 구간 평균 하중(N) · 변동계수, 박리 강도(N/m, 폭이 있을 때), 파단 에너지(J, 곡선 아래 넓이), 접착 에너지(J/m², 박리 각도가 있을 때) |
| 묶음 `adhesion.summary` | 시편 여럿의 평균 · 변동계수 → 응집 영역 블록(파괴 에너지) + 참고 물성(박리 강도) |
| 블록 `cohesive_zone` | 파괴 에너지 G_c(N/m = J/m²) · 최대 견인력 T_max(Pa, 재료에 적어 둔 값) · 모드 · 시편 수 |

시험 종류 `adhesion`(박리 · 이탈력)은 중심(`app/modules/tests/definitions.py`)이 든다 — 채널
하중 · 변위(필수) · 시간, 조건 온도 · 시험 속도 · 박리 각도.

## 정한 것

- **안정 구간은 변위 폭의 비율(기본 25 ~ 75 %)이다.** 처음(당겨 세우는 구간)과 끝(떨어지는
  구간)을 뺀다. 점이 5 개 미만이면 평균을 내지 않고 말한다(점이 18 개인 Zwick 예제 파일이 그랬다
  — 넓혀 부르면 된다).
- **박리 강도는 폭이 있을 때만** — 이탈 · 삽입은 폭이 없다. 지어내지 않는다.
- **접착 에너지 = 박리 강도 × (1 - cos θ)** — 팔이 늘어나지 않는다(탄성 팔)는 가정. 90° 면 박리
  강도와 같고, 180° 면 두 배다.
- **최대 견인력은 박리 시험이 주지 않는다** — 팔의 굽힘과 섞여 곡선에서 바로 읽히지 않는다. 블록
  칸은 두고 재료에 적어 둔 값이 채운다(빈 칸 채우기, `shared/declared_slots`). 그 문헌 키
  (`interface.cohesive_strength`)에 이어진 **기본 항목은 없다** — 부서가 사내 항목을 만들어 문헌
  물성의 「사내 항목 연결」 로 이어 두어야 실린다.
- 블록의 파괴 에너지는 N/m 로 싣는다 — 덱 단위계(`DECLARED`)에 J/m² 가 없고, 차원은 같다.
- 단계는 키로만 거른다 — 하중 · 변위는 인장과 같은 모양이다(`SAME_SHAPE_AS_TENSILE`).

## 남은 것

- 덱 형식(LS-DYNA *MAT_COHESIVE_MIXED_MODE 138 · Abaqus *COHESIVE) — 법선 · 접선 강성과 모드 II
  값이 필요한데 박리 시험은 그것을 주지 않는다.
- 박리 분류의 시편 칸(폭 · 접착 길이) — 지금은 규격 없는 시편의 옛 칸(폭)을 쓴다.

## 기록

- 2026-10-20 처음 — 사용자 보고(이탈력 처리 단계 · 응집 영역 블록이 없었다). 사보타주: 박리 각도식
  빼기 — `test_ext_adhesion.py` 가 물었다.
- 2026-10-20 검토에서 고친 것 둘. **박리 각도는 라디안이다** — 화면은 도로 받아 옮기지만 API · MCP 로
  90 을 넣으면 1 - cos(90 rad) = 1.45 배가 오류 없이 나왔다. π 를 넘으면 멈추고 도라면 몇 rad 인지
  말한다. **누르는 쪽을 음수로 적는 장비**(SIM 트레이 삽입 등)는 최대 하중이 0 근처, 박리 강도가 음수로
  나왔다 — 압축 단계처럼 부호를 뒤집고 그렇다고 적는다.
