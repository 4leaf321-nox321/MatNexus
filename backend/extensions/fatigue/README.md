# 피로 (S-N)

표로 넣은 피로 시험(시편마다 응력 진폭 · 파단 수명 · 런아웃 · 응력비)을 묶어 Basquin
`S = A·N^b`(진폭)를 맞추고(`sn.py`), 카드 블록 `sn_curve` 에 담아 덱으로 낸다(`card.py`).

## 덱

| 형식 | 키워드 | 우리 곡선에서 옮기는 것 |
| --- | --- | --- |
| LS-DYNA (피로 S-N) | `*MAT_ADD_FATIGUE` (LCID=-3) | 식 그대로, **SNTYPE=1(진폭)** 을 늘 적는다 |
| OptiStruct (피로 S-N) | `MATFAT` | SRI1 = **2A**(범위 절편), B1 = B2 = b, UNIT · LENUNIT |
| Nastran (피로 S-N) | `MATFTG` | SRI1 = **2A**, b1 = b2 = b, 시험 R → RR |

**셋 다 범위와 진폭이 갈리는 자리다.** LS-DYNA 는 SNTYPE 기본이 범위, MATFAT · MATFTG 의 SRI1 은
범위 절편(1 회)이다. 진폭 A 를 범위 자리에 그대로 두면 같은 응력에서 수명이 2^(1/b) 배
(b=-0.1 이면 1/1024)로 줄어 — 보수 쪽이라 덱이 멀쩡해 보인다. 시험(`test_ext_solver_decks.py`)이
세 자리를 따로 지킨다.

둘째 기울기는 첫째와 같게 둔다 — 한 직선이고 피로 한도를 지어 넣지 않는다(LS-DYNA 덱과 같다).
NC1 · Nc1 에는 시험이 끝난 수명을 적는다(두 기울기가 같아 곡선은 안 바뀐다).

## 인장강도 · 항복강도 (2026-10-08)

MATFAT · MATFTG 는 STATIC 줄의 인장강도가 필수다(평균응력 · 표면 보정). 피로 시험은 그 값을 안
주므로 `sn_curve` 에 칸 둘(`tensile_strength` · `yield_strength`)을 물성 키와 함께 두었다 — **카드를
저장할 때 재료에 적어 둔 값이 빈 칸을 채운다**(`app/shared/declared_slots`). 기본 항목 「인장강도 ·
항복강도」 는 씨앗 연결로 그 키에 이어져 있다.

- 재료에 적을 수 있는 것은 **공칭값**(문헌 · 규격 · 제품 데이터시트)이다. 밀시트 값은 로트의 값이라
  시료에 붙고, 빈 칸 채우기는 재료 값만 읽는다 — 밀시트 인장강도는 이 칸에 안 온다.
- 이 칸이 생기기 전에 만든 S-N 카드에는 칸이 없다(카드는 스냅샷) — 다시 만든다.
- 인장강도가 없으면 두 형식은 목록에서 막힌다. 지어 넣지 않는다.

## Nastran 에서 조심할 것 (Embedded Fatigue User's Guide)

- 응력은 **모델 단위**로 적고(CNVRT 기본 1), 피로 모듈은 MPa 로 바꿔 읽는다 — 모델이 MPa 가 아니면
  `DTI,UNITS,1,<단위>` 가 모델에 하나 있어야 한다. 모델 전체 설정이라 재료 조각에 안 넣고 덱
  주석 · 알림으로 말한다.
- 허용 범위를 먼저 본다: UTS 100~4000 MPa(금속 피로만), YS 50~3000 MPa(밖이면 빼고 말한다),
  SRI1 1~25000 MPa, b1 은 -1 ~ -0.02, b2 는 -0.5 초과.

## 회귀 방향 (2026-10-08 고침)

**수명을 응력에 회귀한다**(ASTM E739 — 수명이 종속변수다): log N 을 log S 에 맞추고 Basquin 꼴로
뒤집는다. 전에는 반대(log S 를 log N 에)라 수명의 흩어짐이 회귀변수에 들어가 기울기가 완만해졌다
(합성 시험: 참 b=-0.100 → -0.092, 10⁷ 강도 +4.4%). `log_scatter` 도 이제 수명의 흩어짐(log N 잔차의
표준편차, 자릿수)이다 — 전에는 log S 잔차라 약 |b| 배 작았다. 이미 만든 묶음 · 카드는 그대로다(다시 묶는다).

## 수명선도 그래프 (2026-10-22)

`sn_curve` 블록이 그래프 선언(`BlockPlot`)을 든다 — x 파단 수명 · y 응력 진폭(log-log), 런아웃은 빈 점,
선은 Basquin A · b. 카드 화면은 블록 이름을 모르고 이 선언대로 그린다(`CardBlocks`). 카드의 점과 계수만
쓰므로 이미 만든 카드에도 그려진다. 선은 파단 점이 있는 수명 범위만 그린다(외삽 없음). v1.285.0 보고:
S-N 카드를 만들었는데 피팅 계수로 그래프를 볼 수 없었다.

표 입력 시험(`imported`)도 묶음 후보에 선다 — 재료 화면이 「완료(parsed)」 만 불러와 26건이 0건이던
것(같은 보고). 서버는 처음부터 받았다.

## 2구간 S-N (VOC 61, 2026-11-14 · ADR 0075)

「꺾이는(bilinear) S-N 을 카드에」 — HyperLife 의 Slope-intercept 2-segment(SRI1 · b1 · Nc1 · b2 · SE)와 같은 꼴.
한 직선은 그대로 두고 묶음 「S-N 곡선 (2구간)」(`fatigue.sn_bilinear`, `bilinear.py`)과 블록 `sn_bilinear` 를 따로 세웠다.

- **꺾임은 전수 탐색**: 꺾임 log S 를 정하면 `log N = y_k + c1·max(x-x_k,0) + c2·min(x-x_k,0)` 이 선형이라 한 번에
  풀린다. 꺾임 위 · 아래에 파단점이 `min_segment_points`(기본 3)개씩 드는 응력 범위 전체를 400칸으로 훑고, 가장
  좋은 칸 둘레를 다듬는다. 같은 점이면 늘 같은 답 — VOC 의 로컬 검증(첫 값 ±0.25 자릿수)의 국소 탐색 한계가 없다.
  수명을 응력에 회귀(E739), 런아웃은 뺀다.
- **판정**: 2구간은 늘 조금은 낫다(계수가 많다). 한 직선과 견준 F 검정(2 · n-4)과 ΔBIC 가 둘 다 2구간 쪽이 아니면
  「2구간 근거 약함 — 한 직선 권장」 경고, `bilinear_supported = 0`. 막지 않는다(사용자 결정). 덱 알림에도 따라간다.
- **블록을 가른 까닭**: 정의판 셋(`*_fatigue_def`)이 `sn_curve.basquin_a · b` 를 읽는다 — 같은 블록이면 2구간
  카드에서 둘째 기울기를 버리고 한 직선 덱을 조용히 낸다. 블록이 다르면 한 직선 형식은 2구간 카드를 「모자란
  블록」 으로 거절하고, 2구간 형식은 한 직선 카드를 거절한다.
- **덱**:
  - LS-DYNA — **S-N 구간 카드**(R13 매뉴얼 *MAT_ADD_FATIGUE Card 2a `Ai Bi STHRESi`, 4 · 5 · 6칸, 「This only applies
    to the case where LCID < 0」). 1구간 LCID=-3 A1 · b1, STHRES1 = 꺾임 응력, 구간 카드 A2 · b2 · STHRES2 = 0
    (둘째 기울기가 이어짐), SNTYPE=1. R11 은 구간 카드를 LCID -1 · -2 에만 열었는데 LCID=-1(N·S^b = a)로 쓰면
    a = A^(-1/b) 가 MPa 에서도 10^49 를 넘어(b2 = -0.05) 단정밀도가 못 읽는다 — 그래서 LCID=-3 + 「R13 이상」.
    곡선(LCID>0, LTYPE=1 log-log)도 되지만 `*DEFINE_CURVE` 의 축(N · S)이 매뉴얼에 안 적혀 있어 쓰지 않았다.
  - MATFAT · MATFTG — SN 줄 `SRI1 = 2·A1 · B1 · NC1 = 꺾임 수명 · B2`. 한 직선과 같은 카드 조립(`_matfat` ·
    `_matftg`)을 쓴다 — 한 직선 덱의 글자는 그대로다(기존 시험 그대로 통과). SE 는 비운다(한 직선과 같다).
  - 셋 다 **코드판만**(정의판 짝 없음) — 정의판은 이어짐 검사와 「근거 약함」 알림을 못 한다. 파일 이름
    꼬리는 `_fatigue2seg`(한 직선 `_fatigue` 와 안 겹치게).
- **그래프**: 블록 선언의 선에 `knee` · `exponent2` 를 더했다(중심 `PowerLine`) — 카드와 묶음 결과 화면이 같은 선언으로
  꺾인 선을 그리고, 묶음 결과는 계수 키가 결과에 있는 블록의 그래프를 고른다(점 키만 보면 2구간 결과에 한 직선
  그래프가 잡혔다).
- 실측 · 검증: 합성 2구간(A1 1000 MPa · b1 -0.1 · Nc1 1e5 · b2 -0.05)을 1e-5 안에서 되찾는다, 꺾임이 범위 양 끝에
  있어도 찾는다, 직선 데이터는 「근거 약함」. 사보타주 아홉(범위 절편 2·A1 · 구간 카드 칸 · 꺾임 응력 단위 · 탐색
  범위 앞/뒤 30 % · 판정 · 그래프 고르기 · 꺾인 선) 전부 시험이 물었다. **VOC 담당의 시험 데이터 · 로컬 결과로
  견주는 회귀 시험은 받는 대로 더한다.**
