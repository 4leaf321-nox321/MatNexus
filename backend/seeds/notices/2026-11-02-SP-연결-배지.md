# SP 코어 온톨로지와 연결된 기준정보 · 물성에 「SP」 배지 표시

■ 「SP」 배지
- 「온톨로지 조회」 · 「온톨로지 편집」 의 값과 「물성 분류」 의 분야 · 물성군 · 물성 중 Standard Platform(SP) 코어 온톨로지 객체와 연결된 항목 옆에 「SP」 표시. 연결이 여럿이면 「SP 2」 처럼 수 표시.
- 배지 선택 시 SP 쪽 종류 · 이름 · key · 속성 · 관계와 연결한 사람 · 시각 · 메모 표시.
- 붉은 배지는 SP 에서 삭제 · 병합된 객체와의 연결로 재확인 필요. 병합된 경우 병합 대상 key 표시.
- 연결은 같은 대상이라는 기록이며 MatNexus 의 값 · 이름은 변경 없음.
- 연결 · 해제는 기존과 같이 자료 관리자가 AI(MCP) 도구(link_sp_core · unlink_sp_core)로 수행. 화면에는 조회만 제공.

■ 운영 영향
- 마이그레이션 없음.
- 씨앗 데이터: 공지 하나 · 앱 안 가이드(사용 설명서 「SP」 배지 문단).
