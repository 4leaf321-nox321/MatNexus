# 레오미터 전단 마스터커브 · 박리 이탈력 · 와이블 강도 분포

■ 레오미터 진동(전단 G′ · G″)
- 채널이 shear_storage_modulus · shear_loss_modulus 인 시험 종류로 마스터커브 · Prony · 점탄성 카드 생성 가능.
- 카드에는 E = 2(1+ν)G 로 한 번 환산해 기재(푸아송비 필요). 점탄성 블록 「잰 탄성률」 에 무엇을 잰 값인지 표시.
- 진폭 스윕의 「선형점탄성 탄성률」 단계도 G′ 열 자동 선택.

■ 온도 램프 파일(Hitachi DMA 7100 등)
- 「장비 파일 정의」 ③ 「온도 램프 나누기 — 구간 폭 (K)」 입력 시 구간마다 주파수별 평균을 등온 곡선으로 생성.

■ 박리 · 이탈력
- 기본 시험 종류 「박리 · 이탈력」 추가. 처리 단계: 최대 하중 · 안정 구간 평균 · 박리 강도(N/m) · 파단 에너지 · 접착 에너지.
- 묶음 카드 「응집 영역」(파괴 에너지 G_c · 최대 견인력 T_max) 블록.
- 「와이블 강도 분포」 묶음과 기본 물성 항목 「와이블 계수」. 「표로 시험 입력」 의 파단 하중만으로도 적합 가능.

■ 굽힘 · 압축 · 반복 시험
- 굽힘 · 압축 「토우 보정」, 압축 곡선으로 맞춘 초탄성 카드, 폼 카드(LS-DYNA 저밀도 폼), 구조 강성 블록.
- 반복 시험 공용 단계(사이클 분리 · 제하 탄성률 · 잔류 변형률 · 히스테리시스 에너지). 압축 「쓸 하중 구간」 -1 = 전부.
- 계산식에 시편 치수 · 시험 조건을 변수로 사용 가능.

■ 시험 올리기 · 지우기
- 시험 등록 · 일괄 등록에서 읽을 형식 선택 가능. 자동이 여럿 중에 고른 경우 시험 경고에 후보 기록.
- 단계 이름이 부호만 다른(-40도 · 40도) 파일이 「읽는 중」 에서 멈추던 현상 수정.
- 시험이 있는 시료 통째로 삭제, 시편 · 시험 골라 한꺼번에 삭제(실패한 시험 포함).
- 휴지통 되살리기는 함께 지운 것만 복원.

■ 그 밖에
- 곡선 그림 영역 확대(끌어서 사각형) · 시험 상세에서 확대 · 이동.
- 경도 눈금 IRHD 로 문헌 물성 생성.
- AI(MCP): 시험 다시 읽기(형식 고정 · 해제), 올리기 미리보기에 고를 수 있는 형식 표시.

■ 운영 영향
- 마이그레이션 없음.
- 씨앗 데이터: 시험 종류 「박리 · 이탈력」, 물성 항목 「와이블 계수」 와 문헌 키 연결, 앱 안 가이드(플랫폼 사용 안내) 개정.
- 배포 시 MCP 서비스 함께 재시작.
