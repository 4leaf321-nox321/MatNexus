# 운영 안내 — 멈춘 서버를 감시가 다시 띄웁니다 (v1.247)

■ 감시 작업 `MatNexus-Watchdog`
서비스로 도는 서버는 1분마다 `/api/health` 를 보고, 잇달아 세 번 답이 없으면 `MatNexus` 서비스를 다시 띄웁니다. 전에는 DB 연결이 잠깐 끊긴 뒤 서버가 떠 있는 채로 답을 안 하면 사람이 알아채고 재기동해야 했습니다(2026-09-10 실측). DB 에 못 닿는 것(503)은 재시작하지 않습니다 — DB 가 돌아오면 서버가 스스로 재연결합니다. 배포가 알아서 붙이고 갱신합니다.

■ 끊긴 DB 연결을 1분 안에 알아챕니다
질의 도중 망이 끊기면 그 요청이 십수 분 매달리던 것을 TCP keepalive 로 1분 안에 오류로 바꿔 새 연결을 맺습니다.
