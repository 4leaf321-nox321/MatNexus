# 바뀐 것 — 메뉴 이름 「온톨로지」 · 연동 단위 안내 정정 (v1.258.1)

■ 메뉴 이름이 바뀌었습니다
- 「기준정보」 → **「온톨로지 조회」** (공통) — 등록할 때 고르는 값의 목록을 봅니다.
- 「기준정보 편집」 → **「온톨로지 편집」** (관리) — 오타를 고치고, 안 쓰는 값을 감추고, 물성 매핑을 잇습니다.
하는 일은 그대로입니다. 화면 안내(「…에서 먼저 만드세요」)도 새 이름을 가리킵니다. 시험 상세의 「파일 형식을 새로 만드세요」 안내는 이제 실제 자리인 「장비 파일 정의」 를 가리킵니다.

■ 해석 연동 — 필드마다 무엇이 바뀌었나(v1.258 안내를 고쳐 적습니다)
**숫자만 읽지 말고 함께 오는 단위 칸을 읽으세요 — 밀도는 반드시 `density_unit` 을 읽으세요.** 단위 칸으로 환산해 온 스크립트는 그대로 맞습니다.
- 재료·시료 `density` — tonne/mm³ → **kg/m³** (숫자가 10¹² 배 커집니다: 7.85e-9 → 7850). 단위 칸 `density_unit`
- 재료 `spec_thickness`(규격 두께) — mm → **m** (1000배 작아집니다: 1.0 → 0.001). 단위 칸 `spec_thickness_unit`
- 시편 `thickness`·`width`·`gauge_length` — 넣은 단위(대개 mm) → **m** (1000배 작아집니다). 단위 칸 `length_unit`
v1.258 공지에서 규격 두께가 전에 mm 였다는 것이 빠져 있었습니다.
