# 처리 값 오류 수정 — 시험 조건 환산 · 항복 강하 자르기 · 파일 실측 치수 · 진응력

■ 시험 조건
- 형식 프로파일이 조건 칸 일부를 채우는 파일에서, 업로드 시 입력한 다른 조건이 한 번 더 환산되던 오류 수정(예: 25 °C → 571.3 K, 10 mm/min → 6만분의 1).
- 이미 저장된 시험 중 해당 가능성이 있는 건은 관리자 진단 스크립트로 확인(아래 운영 영향).

■ 항복 강하 정리
- 하강 문턱을 최대 응력 기준으로 판정. 이전에는 그 시점까지의 최댓값 기준이라 탄성 구간 잡음 하나로 「연화 시작에서 자르기」 가 걸려 곡선 대부분이 버려지고, 그 곡선의 인장강도가 실패 표시 없이 저장되는 사례 발생.
- 봉우리 위치는 「다시 넘는 변형률」(기본 0.002) 안에 그 봉우리를 다시 넘지 않는 하강으로만 결정. 연강의 항복점 현상(뤼더스 평탄부)은 그대로 검출.
- 「연화 시작에서 자르기」 는 남길 봉우리가 최대 응력의 절반 미만이면 자르지 않고 실패로 표시. 「그대로 두고 재기만」 으로 하강을 먼저 확인 가능.
- 곡선 첫 점이 음수인 경우 처리 오류(500)가 나던 것 수정.
- 단계 버전 2. 같은 레시피로 다시 처리하면 결과가 달라질 수 있음.

■ 시편 치수
- 시험 파일 헤더의 실측 폭 · 두께가 처리에 쓰이지 않던 경우 수정: 단면 모양을 정하지 않은 시편 규격에서도 폭 · 두께 칸 표시 및 파일 값 반영.
- 시편 치수를 쓰는 처리 단계의 노트에 사용한 치수와 출처 기록(예: 「쓴 시편 치수: 폭 12.47 mm(이 시험 파일) · 두께 1 mm(규격 공칭)」).
- 단위가 없는 등 읽을 수 없는 파일 치수는 시험에 넣지 않고 읽기 경고로 표시.
- 유럽식 표기(쉼표 소수) Zwick 파일의 시편 치수 읽기 지원.

■ 진응력 · 일괄 처리
- 「진응력·진소성변형률」 단계에 이미 진응력인 열(장비가 계산한 true_stress 등)을 응력 열로 지정하면 거절. 이전에는 진응력 변환이 두 번 적용됨.
- 일괄 처리의 「바로 채택」 도 개별 채택과 같은 채택 가능 검사 적용.

■ 운영 영향
- 마이그레이션 없음.
- 씨앗 데이터: 공지 하나 · 앱 안 가이드(사용 설명서 시편 치수 절).
- 배포 후 관리자 실행 권장: scripts/backfill_run_dimensions.py(세어 보기) → --apply 로 옛 시험에 파일 실측 치수 반영. 단면적이 바뀌는 시험 중 채택 결과가 있는 건은 scripts/reprocess_adopted.py 로 재처리.
- 조건 이중 환산 확인: scripts/find_double_converted_conditions.py(읽기 전용, 값 수정 없음).
