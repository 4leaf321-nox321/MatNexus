# BOM 고무는 초탄성으로 · 검증 모델 기대값 고침

■ 부품표(BOM) 덱 — 고무는 곡선 대신 초탄성
- 「곡선 합성」 을 켠 문헌 줄의 재료가 고무 분류면, 탄소성 곡선 대신 그 솔버의 **초탄성 형식**으로 냅니다. 전에는 이 고무들이 곡선 합성에서 전부 거절됐습니다.
- 문헌에 초탄성 계수가 있으면 그것을, 없으면 탄성계수에서 Neo-Hookean(C10 = E/6)을 만들고 덱 각주에 「합성 초탄성 — 실측이 아니다」 를 적습니다.
- 푸아송비는 지어내지 않습니다 — LS-DYNA · Radioss 처럼 푸아송비가 있어야 하는 형식은 없는 재료를 그 까닭과 함께 건너뜁니다.

■ 검증 모델 — 기대값을 고쳤습니다
- OpenRadioss 로 검증 모델을 실제로 돌려 봤습니다. 덱은 맞았고, 함께 드리는 기대값 쪽이 둘 틀렸습니다.
- **고무**: 기대값이 완전 비압축 해였습니다. 푸아송비 0.49 고무는 늘림 2 에서 4% 남짓 낮게 나와 맞는 덱이 틀려 보였습니다. 이제 카드의 푸아송비로 계산합니다(OpenRadioss 와 0.2% 안쪽).
- **Radioss 반력**: README 가 견주라던 REACX 는 힘이 아니라 충격량이고 네 절점 중 하나의 몫입니다. 마지막 두 기록의 차를 시간 차로 나눠 4 를 곱하는 법을 README 에 적었습니다.
