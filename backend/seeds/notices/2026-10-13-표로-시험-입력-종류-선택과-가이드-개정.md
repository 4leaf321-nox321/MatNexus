# 표로 시험 입력의 시험 종류 선택 · 앱 안 가이드 개정

■ 「표로 시험 입력」 — 피로 · 크리프 입력 가능
- 재료 상세 「시료·시편」 탭 「표로 시험 입력」 창 상단에 **「시험 종류」** 선택 추가(기본 인장시험). 기존에는 인장시험으로 고정되어 피로 시험과 보고서의 최소 크리프 속도를 화면에서 입력할 수 없었음.
- 종류 선택 시 「요약값 열」 이 그 종류의 필수 조건과 묶음이 읽는 열로 자동 구성.
  - 피로: 응력 진폭 (MPa), cycles_to_failure, runout, 응력비 R, 주파수 (Hz), 시험 온도 (°C). 런아웃은 runout 에 1.
  - 크리프: 가한 응력 (MPa), 시험 온도 (°C), min_creep_rate (1/s).
- 요약값은 열 이름이 곧 저장 이름이므로 cycles_to_failure · min_creep_rate 등의 이름 변경 시 「S-N 곡선」 · 「크리프 식」 묶음에서 제외됨.

■ 카드 생성 화면 정정
- 응력완화 묶음의 「생성」 이 DMA 용 창(마스터커브 설명)으로 열리던 문제 수정. 이제 응력완화 묶음 전용 카드 창으로 열림(순간 탄성률 E₀ 가 탄성 칸).
- DMA 묶음의 점탄성 카드 창: 묶음이 다시 맞춘 온도 이동(WLF · Arrhenius) 수록 여부와 이동 방법 표시.
- 카드 「정보」 창의 낡은 설명(점탄성 카드 「기준 온도 하나」 등) 정정.

■ 앱 안 가이드 개정
- 공통 › 가이드의 「MatNexus 사용 안내」 · 「이 앱이 쓰는 말」 을 현재 기능 기준으로 개정: 워크벤치 업무 8종, 내보내기 창 · 지원 형식 66종 · 검증 모델, 크리프 · 응력완화 시험, 선언 물성 승인, 물성 분류, 사용 현황, 토큰 만료 선택(30 · 90 · 365일 · 없음, 기본 90일) · 「읽기 전용」 등.
- 문체를 명사형으로 정리하고 절 제목을 명사형으로 변경(절 주소는 그대로). 운영에서 직접 고친 절은 덮어쓰지 않음.
