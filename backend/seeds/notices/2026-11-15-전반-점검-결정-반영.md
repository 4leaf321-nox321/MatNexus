# 시험 온도별 통계 분리 · 낡은 결과 경고 등 — 전반 점검 결정 반영

■ 시험 온도별로 통계 · 카드 분리
- 같은 재료 · 시험 종류 · 방향이라도 시험 온도가 다르면(±2 K 밖) 통계 · 대표 곡선 · 카드를 따로 산출. 시험 온도 미기재는 별도 묶음.
- 물성 탭 · CAE 카드 탭에 온도 표시. 카드 이름 기본값에 온도 기재(예: 「인장시험 MD · 80 °C」).
- 온도가 하나뿐인 재료는 기존과 동일.

■ 카드
- 시험 카드: 시험으로 잰 탄성계수가 있으면 재료에 기재한 온도별 탄성계수 표를 싣지 않음 — 솔버 형식마다 다른 탄성계수가 쓰이던 문제 정정.
- 묶음 카드: 묶을 때 쓴 처리 결과를 기록, 이후 채택이 바뀌었으면 카드 근거에 경고.
- 이방성 카드: 짝 카드의 탄성계수 사용(세 방향 평균이 쓰이던 문제 정정).
- 피로 강도: 잰 수명 범위 밖의 값에 「외삽」 경고.
- 속도 의존 카드를 단일 곡선 형식으로 내보낼 때 「가장 느린 속도 곡선만 실음」 안내.

■ 처리 결과
- 「낡은 결과」: 원본 교체 또는 시편 치수 수정 후 다시 처리하지 않은 채택 결과는 통계 · 카드에 경고, 채택 시 확인 필요.
- 묶음(글로벌 피팅)에 쓰인 처리 결과는 삭제 불가.
- 장비 파일의 수치 표가 중간에 끊긴 경우(천 단위 쉼표, #DIV/0! 등) 「N행에서 끊김」 경고.
- 장비 파일의 이름 없는 앞 열이 변형률 등 채널을 가로채던 문제, 표 입력 조건 열의 단위 검사 누락 정정.
- 수동 이동인자: 기준 온도 외 모든 온도에 입력 필요.

■ 문헌 · 휴지통 · 공지
- 문헌 대표값이 상온이 아니면 덱 각주에 온도 기재. 글로 적힌 온도(°F 포함)도 반영.
- 직접 만든 문헌 정의의 단위(MPa 등)를 사내 물성으로 옮길 때 SI 환산.
- 문헌 모델 파라미터: 출처 문헌 재료가 다른 벌은 따로 저장.
- 휴지통: 보존기간이 지나 파일이 정리된 시험은 되살리기 전 안내.
- 관리자가 삭제한 공지 초안이 다음 배포에 다시 생기던 문제 정정.

■ AI 연결(MCP)
- 시험 온도별 묶음 반영 — 온도가 여럿이면 AI 가 어느 온도인지 확인.
- 이름이 정확히 같지 않으면 쓰기 전에 대상 확인(재료 · 시험 · 카드).
- 재료의 밀도 · 푸아송비 출처 · 등급 표시.

■ 운영 영향
- 마이그레이션 2건(공지 씨앗 키 기록, 모델 파라미터 저장 열쇠) — 배포가 자동 적용.
- 씨앗 데이터: 공지 하나 · 내보내기 형식 정의(단일 곡선 형식 여섯).
- AI 연결(MCP) 의존성 고정 — 배포 시 MCP 가상환경 재설치(mcp 2.1.1).
- 이미 저장된 통계 · 카드 · 처리 결과는 그대로 — 다시 처리 · 다시 생성 시 새 규칙 적용.
