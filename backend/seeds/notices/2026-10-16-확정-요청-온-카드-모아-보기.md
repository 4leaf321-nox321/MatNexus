# 확정 요청 온 카드 모아 보기 — 워크벤치 검토 정리

■ 확정 요청 온 카드 모아 보기
- 「물성 카드」 목록 검색 칸 옆 「확정 요청됨」 단추로 확정 요청이 와 있는 초안만 표시.
- 홈 「남은 일」 에 「확정 요청 N」 표시, 선택 시 해당 목록으로 이동.
- 대기열이 아닌 거르기 조건: 카드가 확정되거나 사용 중지되면 목록에서 빠짐.

■ 워크벤치 「카드 확정 전 검토하기」
- 「초안 담기」 단계가 확정 요청 온 카드 목록으로 안내.
- 「근거 보기」 단계에서 확정 요청 온 카드 수를 먼저 표시. 확정 요청은 코멘트 수에 미포함.
- 마지막 단계 이름을 「확정하거나 사유 남기기」 로 변경. 확정하지 않을 카드는 카드 줄의 「코멘트 남기기」 로 사유 기재(카드 상태에 「반려」 없음).

■ AI(MCP)
- 「확정 요청 온 카드」 조회 가능.
- 단위 환산 시 같은 단위의 숫자 여럿을 한 번에 처리.

■ 운영 영향
- 마이그레이션 없음. 앱 안 가이드(플랫폼 사용 안내 · 용어집) 개정.
- 배포 시 MCP 서비스 함께 재시작.
