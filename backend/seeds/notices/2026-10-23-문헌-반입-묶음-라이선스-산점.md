# 문헌 반입 묶음 · 출처 라이선스 · S-N 산점

■ 출처 라이선스
- 문헌 값 · 곡선 입력의 출처에 라이선스(예: CC-BY-4.0)와 귀속 문구 입력 가능.
- 상업 이용 불가(NC) 라이선스는 입력 거절. 같은 출처에 다른 라이선스가 이미 있으면 거절, 빈 라이선스는 채움.
- 문헌 재료 상세 「출처」 탭에 라이선스 열 추가(마우스를 올리면 귀속 문구 표시).

■ 산점(S-N · ε-N)
- 「곡선 입력」 에서 「산점」 을 켜면 같은 축 값이 여럿인 점을 입력 가능. 줄 끝 칸에 1 을 적으면 런아웃(멈춘 점).
- 그래프에 파단 점과 빈 점(런아웃)으로 표시, 수명 축은 로그-로그.
- 산점의 점은 그 물성의 대표값으로 쓰지 않음(값 검색 · 물성 지도에는 표시).

■ 외부 공개 데이터 반입 묶음(자료 관리자)
- 라이선스가 확인된 공개 데이터를 묶음 파일 하나로 한 번에 반입. 미리보기가 기본이며 적용은 전부 되거나 전부 안 됨.
- 같은 묶음을 다시 들여도 중복 없음. 묶음 삭제는 자료 관리자만 가능하며, 사내 재료가 받아 간 값이 있으면 거절.
- AI(MCP)의 import_catalog_batch · get_catalog_batch 또는 REST(/api/catalog/batches) 로 사용.

■ 그 밖에
- 문헌 재료 찾기가 등급 · 코드 · 제조사 · 규격명으로도 검색.
- 새 문헌 물성: 「압축 변형률별 공칭 응력」 · 「피로 변형률 진폭 (ε-N)」.

■ 운영 영향
- 마이그레이션 1건(b8d3f1a6c2e7 — 문헌 반입 묶음 · 라이선스 · 산점).
- 씨앗 데이터: 문헌 기본 정의 둘(배포의 refresh_builtins), 앱 안 가이드(플랫폼 사용 안내) 개정.
- 설정 변경 없음.
