# 새로 생긴 것 — 아이디는 시스템이 붙이고, VOC 에 파일을, 소성 표는 단조 증가로 (v1.249)

■ 가입·로그인에서 @samsung.com 을 안 쳐도 됩니다
아이디(녹스 ID)만 적으면 시스템이 `@samsung.com` 을 붙여 받습니다. 예전에 도메인 없이 가입한 계정은 이번에 `hong` → `hong@samsung.com` 으로 바뀌었고, 그래도 `hong` 만 쳐서 로그인됩니다 — 로그인 직후 「아이디에 @samsung.com 이 붙었습니다」 안내가 한 번 뜹니다.

■ 삭제한 계정은 「삭제됨」 탭에
계정 관리에서 삭제한 계정이 「정지」 로 섞여 보이고 「활성화」 로 되살아나던 것을 고쳤습니다. 삭제된 계정은 「삭제됨」 탭에서만 보이고 단추가 없으며, 그 아이디는 풀려서 재입사자가 같은 아이디로 가입할 수 있습니다.

■ VOC 에 파일을 붙입니다
의견 등록 때 파일(캡처·로그·장비 파일, 한 파일 25 MB)을 여러 개 붙일 수 있고, 상세에서 내려받거나 낸 사람·관리자가 붙이고 뗍니다. 게시판에서 여러 건을 골라 「N건 다운로드」 를 누르면 건마다 폴더(`item.json` + `attachments/`)로 묶인 zip 하나를 받습니다 — 이슈 트래커·보고서로 옮길 때.

■ 처리 단계 「단조 증가 보정」
변형률이 늘어도 응력이 그대로인 평탄부(접선계수 0)도 솔버가 거부합니다. 새 단계 `curve.monotone` 이 아무 열이나 기준 열에 대해 엄격히 증가로 만들고(평탄부는 최댓값의 1e-6 씩 — 물성으로는 없는 값), 몇 점을 얼마나 올렸는지 남깁니다. 인장 표준 레시피에 진소성 축 정렬 뒤·마지막 재샘플 앞으로 들어갔습니다 — 「표준 채우기」 를 누른 레시피부터. 「항복 강하 정리」 도 하강이 없어도 최소 기울기를 줬으면 평탄부를 올립니다.
