# 영구 삭제 · 채택 권한 · 기준정보 삭제 등 정정

■ 휴지통
- 영구 삭제가 중간에 실패한 경우 원본 · 곡선 파일이 먼저 삭제되던 문제 정정 — 파일은 삭제 확정 후 제거.
- 적용 부품이 등록된 재료의 영구 삭제 오류(500) 정정.
- 재료 복원 시 적용 부품의 파트 · 제품 · 사업부 「쓰는 곳」 수 복원.

■ 권한
- 「배치 되돌리기」: 채택을 거두거나 바꾸는 경우 해당 시험의 편집 권한 필요. 편집 권한 없이 본인이 만든 결과를 되돌려 다른 사람 시험의 채택을 바꿀 수 있던 문제 정정.

■ 기준정보
- 값 삭제: 휴지통의 자료가 사용 중인 값은 사유와 함께 삭제 제외. 해당 값이 포함되면 선택한 값 전체가 삭제되지 않던 오류(500) 정정.
- 시험 종류: 삭제 후 같은 키로 다시 만든 경우 새 종류로 조회 — 시험 목록 필터 · 장비 파일 정의 · 레시피가 삭제된 종류에 연결되던 문제 정정.

■ 문헌 모델 파라미터
- 온도 · 노화 등 갈래가 다른 벌을 차례로 받으면 앞의 벌이 덮이던 문제 정정 — 갈래별로 따로 저장, 출처에 갈래 표기(예: `one_paper[aging_hours=10.0]`).
- 이전에 갈래 표기 없이 받은 벌: 같은 벌을 다시 받으면 해당 갈래로 갱신.

■ 운영 영향
- 마이그레이션 없음.
- 씨앗 데이터: 공지 하나.
- 재처리 미리보기(`reprocess_adopted.py`): `--apply` 없이 실행 시 파일을 남기지 않음.
- 배포 시 자동 채우기: 휴지통 자료 제외, 곡선 파일 일부가 없어도 계속 진행.
