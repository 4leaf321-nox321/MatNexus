# 처리 — 부분 결과의 일괄 채택 보류 · 굽힘 접촉점 · 인장 직선성 경고

■ 부분 결과와 일괄 채택
- 일괄 처리의 「바로 채택」: 실패한 단계가 있는 부분 결과는 채택하지 않고 결과만 저장 — 처음 처리하는 시험도 동일. 줄에 「실패한 단계가 N개 있는 부분 결과라 미뤘습니다」 와 실패 단계 · 이유 표시, 미리보기에서도 동일 안내.
- 채택 검토대에서 실패한 단계 확인 후 채택하면 나온 값(인장강도 등)이 물성으로 반영. 확인 창에 「실패한 단계가 있는 부분 결과 N건」 과 빠진 단계 표시.
- 결과 탭의 한 건 채택은 기존과 동일.

■ 굽힘 시험의 접촉점
- 「굽힘 응력-변형률」 에 「접촉점 찾기」(기본 켜짐) 추가: 하중이 거의 0 인 채 처짐만 늘어나는 앞부분(누르는 노즈가 닿기 전)을 제외하고, 닿은 자리를 처짐 0 으로 지정 — 압축과 같은 규칙.
- 하중이 늦게 걸린 곡선에서 현 구간(ISO 178 변형률 0.05~0.25 %)이 평평한 앞부분에 걸려 굽힘 탄성률이 작게 산출되던 문제 정정.
- 처음부터 예하중이 걸린 곡선과 하중이 바로 오르는 곡선은 결과 동일. 「접촉 문턱 하중」 을 비우면 최대 하중의 0.5 %, 끄면 첫 점을 영점으로 사용(기존 동작).
- 이미 저장된 굽힘 결과는 그대로 — 다시 처리 시 반영.

■ 인장 탄성계수의 직선성 경고
- 굽힘 · 압축 탄성률과 같은 경고를 인장 탄성계수(최소제곱 회귀 · 자동 · 현)에도 적용: 구간 안 기울기 흔들림 ±3 % 초과 · 구간 앞뒤 절반 기울기 15 % 넘는 차이 · 현 구간에 신호 없음.
- 값은 그대로 산출, 채택 시 확인 필요. 회귀의 R² 0.98 미만 미산출 규칙은 기존과 동일. 할선 · 직접 입력은 판정 제외.

■ 운영 영향
- 마이그레이션 없음.
- 씨앗 데이터: 공지 하나 · 앱 안 가이드(사용 안내).
- 운영 점검 보고서 7절에 접촉점 처리 전의 채택 굽힘 결과 수 추가.
