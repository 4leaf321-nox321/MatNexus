# TestScope 연동 · 보유 장비 이관 · 초탄성 계수 선택

■ 보유 장비는 TestScope 에서 관리
- 「데이터 체계 › 보유 장비」 화면 · API · AI 도구(list_equipment) 삭제. 보유 장비 · 교정의 정본은 TestScope.
- 측정법 화면의 원본 데이터 기준 「보유」 표시(모든 장비가 미보유로 표시되던 것) 삭제.

■ TestScope 연결(시스템 관리자)
- 「관리 › 외부 연동」 에서 TestScope API 주소 · 화면 주소 · 읽기 토큰 입력. 토큰은 암호화 보관 후 다시 표시하지 않음, 빈 칸으로 저장하면 기존 토큰 유지.
- 「연결 확인」 으로 토큰 주인과 시험 항목이 이어진 물성 수 확인.

■ 측정법 — 우리 장비(TestScope)
- 물성 선택 시 그 물성을 잴 수 있는 TestScope 보유 장비(부서 · 위치 · 담당 · 교정 만료) 표시. 장비 이름은 TestScope 화면 링크, 30대까지 표시하고 나머지는 TestScope 에서 확인.
- TestScope 에 물성과 시험 항목의 연결이 없으면 「모름」, 연결은 있는데 장비가 없을 때만 「없음」 으로 구분.

■ 측정 의뢰 — 받는 부서 추천
- 새 의뢰의 받는 부서 아래에 항목을 할 수 있는 장비가 있는 부서(TestScope) 추천. 누르면 받는 부서로 선택.
- TestScope 에서 시험 항목 · 물성으로 정해지지 않은 항목은 「추천에서 빠진 항목」 으로 표시.

■ 초탄성 계수 선택(문헌 덱)
- 문헌 초탄성 계수 묶음이 여럿이면 큰 변형 안정성 · 등급 · 시험 모드(인장 우선, 압축 맞춤은 뒤) 순으로 선택. 고른 묶음의 시험 모드와 다른 묶음의 불안정 구간을 각주에 기록.
- 기본 범위(인장 100 % · 압축 · 등이축 · 평면 전단 50 %)에서 불안정한 계수에는 「주의」 각주 기록. 사내 카드에서 고른 계수도 카드 근거에 같은 주의 기록.

■ 운영 영향
- 마이그레이션 2건(b0fb5b052995 — 보유 장비 표 삭제, 2b126b605270 — 외부 연동 설정 표).
- 씨앗 데이터: 앱 안 가이드(플랫폼 사용 안내 · 용어집) 개정.
- 설정 파일 변경 없음. TestScope 연결은 배포 뒤 「관리 › 외부 연동」 에서 입력.
