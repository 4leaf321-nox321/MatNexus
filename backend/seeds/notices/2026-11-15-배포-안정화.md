# 배포 안정화 — 서비스 중단 상태로 끝나던 경우 정정

■ 배포 중단 시 서비스 복구
- AI 연결(MCP) 가상환경 준비 실패: 경고 후 앱 배포 계속(기존: 서비스가 멈춘 채 배포 종료).
- 이전 백업 폴더 삭제 실패(탐색기 · 백신 점유): 서비스 재시작 후 배포 중단, 운영 폴더 유지.
- 앱 가상환경 준비 실패: 복구 방법(롤백 명령) 안내 표시.

■ 화면 자산
- 이전 버전의 화면 파일을 한 세대만 유지(기존: 배포마다 누적). 누적된 파일은 이번 배포부터 자연 정리.

■ 배포 패키지
- 패키지 생성 시 화면 번들 검사 추가(가리키는 파일 존재 · 재빌드 일치) — 화면이 열리지 않는 번들의 배포 방지.
- 패키지 생성 실패 후 재시도: 이후 검증 통과 시 자동으로 다시 생성(기존: 태그만 남아 이전 버전이 다시 설치될 수 있었음).

■ 운영 영향
- 마이그레이션 없음.
- 씨앗 데이터: 공지 하나.
- 배포 스크립트 변경 — 이번 패키지의 `deploy.ps1` 부터 적용.
