# SP 코어 온톨로지 받기 — 「외부 연동」 화면에서 설정

■ Standard Platform(SP) 코어 온톨로지
- 「관리 › 외부 연동」 에 「Standard Platform 코어 온톨로지」 추가(시스템 관리자). SP 주소와 SP 관리자에게 받은 core:read 토큰 입력으로 수신 설정. 주소 끝의 /api/core 는 자동 보완.
- 토큰은 TestScope 와 같이 암호화 보관 후 다시 표시하지 않음 — 빈 칸으로 저장하면 기존 토큰 유지, 삭제는 「토큰 지우기」.
- 「연결 확인」 으로 SP 판과 받을 코어 타입 수 확인. 토큰 거절 · 주소 오류 · 연결 실패는 구분해 표시.
- 저장 즉시 다음 수신(하루 한 번)부터 적용 — 서버 재기동 불필요. 바로 받으려면 AI(MCP)의 sync_sp_core.
- 받은 코어 온톨로지는 따로 보관만 하며 기준정보 · 물성 값은 변경 없음.

■ 운영 영향
- 마이그레이션 없음.
- 전에 서버 .env 의 SP_CORE_URL · SP_CORE_TOKEN 으로 넣은 설정은 그대로 유효. 화면에 넣으면 화면 값 우선, .env 로만 연결 중이면 화면에 그 사실 표시.
- 씨앗 데이터: 공지 하나 · 앱 안 가이드(사용 설명서 「외부 연동」 항목).
