# 새로 생긴 것 — 공지 게시판 · 내 자료 변경 이력 · 연동 API 단위 (v1.258)

■ 공지가 게시판이 됐습니다
「공지 · VOC」 의 공지도 VOC 처럼 표로 봅니다 — 번호 · 제목 · 올린 사람 · 올린 날짜. 제목·내용으로 찾고, 「안 읽은 것만」 으로 거릅니다. 안 읽은 글은 굵게 「새 글」 이 붙고, 누르면 한 건 화면이 열립니다(열면 읽음으로 남습니다). 배포와 함께 올라온 안내는 「배포 안내」 로 적힙니다.
- **사이드바에 안 읽은 공지 수가 섭니다** — 「공지 · VOC」 옆. 팝업은 중요한 공지에만 켜므로, 나머지는 이 수로 알아챕니다.
- 쌓인 공지는 「모두 읽음」 으로 한 번에 끕니다.

■ 내 자료 변경 이력 — 내가 등록한 자료에 누가 무엇을 했나
사이드바 「내 활동 → 내 자료 변경 이력」. 자료 관리자나 편집을 받은 부서 사람이 **내 자료를 고치면** 누가 · 언제 · 어떤 근거(자료 관리자 · 편집을 받은 부서)로 고쳤는지 남고, 여기서 봅니다. 지운 것 · 카드를 확정하거나 내린 것 · 등록자를 넘긴 것도 여기 섭니다.
- 내가 직접 한 일은 안 보입니다. **내 이름으로 AI(MCP)가 한 일은 보입니다.**
- 일괄 수정은 한 줄에 몇 건인지로 적습니다.
- 이번 배포부터 쌓입니다. 그 전의 삭제·확정 기록도 지금 등록자에게 보이게 채워 두었습니다.

■ AI(MCP)가 한 일이 더 남습니다
재료·시료·시편 등록, 문헌 카탈로그에 넣은 정의·재료·값, 측정 의뢰 작성도 「AI(MCP) 경유」 로 변경 이력에 남습니다(전에는 카드·처리·레시피·형식·값 수정만). 문헌 값을 지운 일과 폐기된 키의 값을 옮긴 일은 되돌릴 수 없어 **사람이 해도** 남습니다. 「변경 이력」 의 「바뀐 것」 칸이 근거·건수·등급처럼 값 하나인 기록을 「없음 → 없음」 으로 보이던 것도 고쳤습니다.

■ 연동 스크립트를 쓰는 분은 확인하세요 — 화면용 REST API 의 숫자가 전부 SI 입니다
화면에서 보고 적는 숫자는 **그대로**입니다(두께 mm · 밀도 tonne/mm³). 바뀐 것은 API 가 주고받는 숫자입니다.
- 재료·시료의 `density` 는 **kg/m³**, 재료의 `spec_thickness` 와 시편의 `thickness`·`width`·`gauge_length` 는 **m** 입니다. 전에는 밀도가 tonne/mm³(10¹² 배 다름), 시편 치수가 넣은 단위(대개 mm, 1000배 다름)였습니다. 함께 오는 `density_unit`·`length_unit` 을 읽으세요.
- v1.257 에 곁에 두었던 `density_si` 는 걷었습니다 — `density` 자체가 SI 입니다. 재료 내보내기 파일에는 그대로 있습니다.
- **단위를 안 적어 보낸 값도 SI 로 읽습니다**(읽은 값을 그대로 되보내면 같은 숫자가 돌아옵니다). mm·tonne/mm³ 로 보내려면 `length_unit`·`spec_thickness_unit`·`density_unit` 을 함께 보내세요.
- 단위 실수는 거절합니다 — 밀도가 0.5~50,000 kg/m³ 밖이거나 시편 치수가 1 m 를 넘으면, 무엇을 적으면 되는지 말하며 되돌려 보냅니다.
- 재료의 「값 출처」(`property-sources`) 도 SI 이고 단위 칸 이름이 `si_unit` 입니다(전에는 `display_unit`).
- 해석용 파일은 전처럼 재료 내보내기·카드 덱이 단위계(기본 mm·N·tonne)를 고릅니다.
