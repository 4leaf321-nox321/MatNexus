# 덱 점검 정확도 개선 — 실린 값 판정 · 필요한 블록이 없는 정의 표시 규칙

■ 덱 점검(AI 덱 확인 포함)
- 카드 값을 조금씩 바꿔 다시 그렸을 때 덱 글자가 바뀌는지로 「실린 값」 판정. 숫자 일부가 우연히 같아 실리지 않은 값을 「찾음」 으로 표시하던 문제 해결.
- 실린 값이 하나도 없으면 점검 실패(빈 파일이 「통과」 로 나가던 문제 해결).
- 표는 마지막 점을 바꿔 덱이 바뀌면 「끝까지 실림」. Nastran · OptiStruct(총변형률 표) 덱을 「잘렸다」 로 잘못 판정하던 문제 해결. 표를 싣지 않는 형식에서는 표 점검 생략.

■ 해석용 물성 정의
- 「필요한 블록」(needs)을 적지 않은 정의는 줄 · 표가 읽는 블록 중 하나라도 카드에 있을 때만 내보내기 창에 표시. 전기 블록만 읽는 정의가 모든 카드에 떠 빈 파일을 내던 문제 해결.
- 기본 제공 형식 · 정의판은 변화 없음. 중립 JSON 은 모든 카드에 표시.

■ 운영 영향
- 마이그레이션 없음.
- 씨앗 데이터: 공지 하나 · 앱 안 가이드(사용 설명서).
- 「필요한 블록」 없이 만든 사람 정의는 일부 카드의 목록에서 빠질 수 있음 — 그 정의에 「필요한 블록」 기재 권장.
