# AI 연결(MCP) — 쓰기 전 확인 강화 · 미리보기 보완

■ 쓰기 전 확인
- AI 가 미리보기 직후 확인 없이 실행한 사례 확인(개발 서버 평가: 카드 코멘트 · 결과 채택) — 안내 강화.
- 모든 쓰기 도구: 미리보기를 사용자에게 보이고 「그대로」 확인을 받은 뒤 실행하도록 공통 안내 추가.
- 문헌 값 삭제 · 문헌 곡선 삭제 · 물성 키 폐기: 미리보기가 기본(기존: 호출 즉시 실행).
- AI 에게 쓰기를 요청한 경우 미리보기가 먼저 제시됨 — 내용 확인 후 「그대로」 로 답하면 실행.

■ 미리보기 · 조회 내용 보완
- 카드 확정 · 확정 요청 · 경화식 맞춰 보기: 근거 시험의 경고(속도 혼합, 공칭 치수 등) 표시.
- 카드 코멘트: AI 경유 여부 표시 — AI 가 남긴 코멘트와 사람의 검토 의견 구분.
- 시편 치수: 칸별 단위 표기(각도 칸이 길이 단위로 표기되던 문제 정정).
- 조회 실패 시 「없음」 이 아니라 조회 실패로 표시(채택 결과, 시편, 기존 시료).
- 재료의 카드가 20장을 넘는 경우 전체 수 표시, 이름으로 카드 찾기는 전체 카드 대상.
- 「레시피로 처리한 결과 수」 조회 방법 안내 추가.

■ 운영 영향
- 마이그레이션 없음.
- 씨앗 데이터: 공지 하나.
- MCP 서버 재시작 필요(배포 시 자동).
