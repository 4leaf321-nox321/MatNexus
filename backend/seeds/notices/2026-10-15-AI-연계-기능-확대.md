# AI(MCP) 연계 기능 확대 — 카드 확정 · 결과 채택 · 의뢰 제출 등

■ AI(MCP)로 수행 가능해진 작업
- 물성 카드 확정 · 사용 중지 · 초안으로 되살림
- 처리 결과 채택 · 채택 해제 · 여러 시험 일괄 채택
- 측정 의뢰 제출 및 상태 변경(접수 · 시험 시작 · 보류 · 결과 전달 · 완료 · 반려), 담당자 지정, 시험 연결
- 시험 원본 파일 업로드(10MB 이하)
- 기준정보 신규 값 등록 및 별칭 추가
- 시험 종류 저장, 해석용 정의 사용 여부 전환

■ 동작 방식
- 모든 작업은 미리보기 우선. AI가 변경 내용을 먼저 제시하고, 사용자 확인 후 실행.
- 권한은 기존과 동일. 카드 확정 · 되살림 및 통제 항목의 기준정보 신규 값은 자료 관리자, 별칭은 시스템 관리자만 가능.
- AI가 수행한 변경은 변경 이력에 「AI 경유」로 기록. 화면에서 수행한 작업의 기록 방식은 변경 없음.
- 삭제 작업은 AI에 미제공.

■ 운영 영향
- 화면 · 데이터 변경 없음. 마이그레이션 없음.
- 배포 시 MCP 서비스 함께 재시작, 새 기능 자동 반영.
