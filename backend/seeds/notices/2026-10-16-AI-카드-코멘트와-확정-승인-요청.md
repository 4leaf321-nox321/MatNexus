# AI 로 카드 코멘트와 확정 · 승인 요청 — 관리자 검색 정리

■ AI(MCP)로 추가 수행 가능한 작업
- 물성 카드 코멘트 기재(검토 의견 · 확정하지 않는 사유).
- 자료 관리자에게 카드 확정 요청 · 선언 값 승인 요청.
- 모든 작업은 미리보기 우선. AI가 내용을 먼저 제시하고 사용자 확인 후 실행.
- 토큰 소유자가 자료 관리자이면 요청 대신 직접 확정 · 승인 가능하다는 안내 표시.

■ AI 경유 표시
- AI가 남긴 코멘트 · 요청은 카드에 「이름 · AI(MCP) 경유 · 날짜」 로 표시.
- 알림 본문과 변경 이력에도 「AI(MCP) 경유」 기록. 화면에서 직접 한 작업은 기존과 동일.

■ 고친 것
- 휴지통에 든 재료의 파라미터 벌, 삭제한 시험의 처리 결과가 시스템 관리자의 전체 검색에 표시되던 문제 해결(열면 「찾을 수 없음」 이 나오던 항목).

■ 운영 영향
- 마이그레이션 없음. 앱 안 가이드(플랫폼 사용 안내 · 용어집) 개정.
- 배포 시 MCP 서비스 함께 재시작, 새 기능 자동 반영.
