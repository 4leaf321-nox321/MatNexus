# 물성 카드 번호와 카드 코멘트 — 확정 요청 결과 알림

■ 물성 카드 고유 번호
- 모든 물성 카드에 번호 부여(예: C-000038). 기존 카드는 등록 순으로 번호 부여.
- 번호는 한 번 부여되면 불변, 삭제된 카드의 번호도 재사용하지 않음.
- 표시 위치: CAE 카드 탭과 「물성 카드」 목록의 번호(선택 시 복사), 카드 고르기 창, 전체 검색, 덱 머리의 근거 줄, 데이터 내보내기, 알림 제목.
- 「물성 카드」 목록 · 카드 고르기 창에서 카드 번호 · 재료 번호로 검색 가능. 재료 목록에서 카드 번호로 그 재료 검색 가능.
- 「C-38」 · 「c38」 처럼 줄여 입력해도 같은 번호로 인식.

■ 카드 코멘트
- 카드 줄의 말풍선 단추 「코멘트 남기기」 로 검토 의견 · 확정하지 않는 사유 · 보완 요청 기재.
- 카드를 볼 수 있는 사람 누구나, 확정 카드에도 기재 가능. 카드 값은 불변.
- 코멘트 기재 시 카드를 만든 사람과 확정을 요청한 사람에게 알림 발송.
- 삭제는 남긴 사람과 자료 관리자만 가능. 근거 시험 이동 · 확정 요청 기록은 삭제 불가.

■ 확정 요청 결과 알림
- 확정을 요청한 카드가 확정되거나 사용 중지되면 요청한 사람에게 알림 발송.
- 「알림」 화면 하단 「어떤 알림을 받을까」 의 「확정 요청 결과 · 카드 코멘트」 에서 켜기 · 끄기 가능.

■ 고친 것
- 휴지통에 든 재료의 카드가 시스템 관리자의 전체 검색에 표시되던 문제 해결.

■ 운영 영향
- 마이그레이션 1개(물성 카드 번호). 앱 안 가이드(플랫폼 사용 안내 · 용어집) 개정.
- 배포 시 알림 규칙 자동 보충, MCP 서비스 함께 재시작.
