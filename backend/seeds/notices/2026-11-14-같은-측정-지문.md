# 같은 측정 알아보기 — 곡선 값 지문 · 경고 · 「같은 지문은 하나로」

■ 곡선 값 지문
- 시험 파일을 읽을 때 곡선마다 값 지문 산출. 지문은 곡선의 SI 값으로 산출하므로 줄끝 · 머리말 · 형식 · 단위만 다른 사본도 같은 지문.
- 자릿수를 다르게 적은 사본 · 점을 솎거나 자른 사본은 다른 지문(알아보지 못함).

■ 경고(막지 않음)
- 내용이 같은 원본 파일, 또는 값이 같은 곡선이 다른 시험에 있으면 시험 점검에 기록. 재시험 · 반복 측정일 수 있으므로 등록 · 처리는 막지 않음.
- 그 시험의 처리 결과는 경고를 가지므로 채택 시 확인 필요, 일괄 처리의 「바로 채택」 은 미룸.
- 「시험 등록」 창은 내용이 같은 파일이 이미 있으면 등록 후 바로 닫지 않고 안내(「닫기」 로 닫음).

■ 통계 · 분석
- 재료 「물성」 탭에 같은 지문을 채택한 시험이 있으면 안내와 「같은 지문은 하나로」 단추 표시, 카드 머리에 「같은 지문 N」.
- 「같은 지문은 하나로」 를 켜면 같은 지문은 먼저 등록한 시험 하나만 집계. 기본은 전부 집계.
- 물성 분석(비교 · 분포 · 추세) API 와 AI(MCP) 통계 조회도 같은 선택 지원.
