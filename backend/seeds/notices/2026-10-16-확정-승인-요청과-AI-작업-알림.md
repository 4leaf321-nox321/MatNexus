# 확정 · 승인 요청과 AI 작업 알림 — AI 로 표 입력 · 마스터커브 · Prony 까지

■ 확정 · 승인 요청
- 물성 카드 「확정 요청」: 초안 카드를 고칠 수 있는 사람(자료 관리자 제외)에게 표시. 자료 관리자에게 알림 발송, 카드에 요청 기록과 「확정 요청됨」 표지 기재. 카드 상태는 초안 유지, 같은 카드는 하루 한 번.
- 선언 값 「승인 요청」: 재료 「물성」 탭에 「승인을 기다리는 값 N건 — 승인 요청」 표시. 자료 관리자에게 기다리는 값 수와 남긴 말 발송, 값 · 등급 변동 없음.
- 요청 창에서 알린 인원 확인 가능. 받을 자료 관리자가 없으면 시스템 관리자에게 발송.

■ AI 작업 알림
- AI(MCP)가 카드 확정 · 사용 중지 · 초안으로 복원 · 처리 결과 채택을 수행하면 자료 관리자와 토큰 소유자에게 알림.
- 화면에서 수행한 작업은 알림 없음.
- 「알림」 화면 하단 「어떤 알림을 받을까」 에서 「확정 · 승인 요청」 · 「AI 가 확정 · 채택」 켜기 · 끄기 가능(자료 관리자 · 시스템 관리자).

■ AI(MCP)로 추가 수행 가능한 작업
- 곡선 없는 요약표의 시험 입력(「표로 시험 입력」 과 같은 판정)
- DMA 마스터커브 생성 및 Prony 적합
- 검증 모델 키트 조회
- 모든 작업은 미리보기 우선, 수행 내용은 변경 이력에 「AI 경유」 로 기록.

■ 운영 영향
- 마이그레이션 없음. 앱 안 가이드(플랫폼 사용 안내 · 용어집) 개정.
- 배포 시 알림 규칙 자동 보충, MCP 서비스 함께 재시작.
