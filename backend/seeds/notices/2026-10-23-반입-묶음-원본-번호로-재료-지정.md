# 반입 묶음 — 기존 문헌 재료를 원본 번호로 지정

■ 외부 공개 데이터 반입 묶음(자료 관리자)
- 기존 문헌 재료를 원본 번호(existing_mt_id)로 지정 가능. 개발 · 운영 서버의 번호가 같아 같은 묶음 파일을 두 서버에 그대로 사용.
- 미리보기 결과에 기존 재료로 연결되는 항목과 그 재료 이름 표시(attached). 번호 오기로 이웃 재료에 붙는 일을 적용 전에 확인.
- 없는 번호, 또는 uuid 와 원본 번호를 함께 적은 항목은 문제로 표시하고 반입하지 않음.

■ 운영 영향
- 마이그레이션 없음.
- 씨앗 데이터 변경 없음.
- 설정 변경 없음.
