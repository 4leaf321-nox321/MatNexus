# 새로 생긴 것 — 측정 의뢰 (v1.234)

■ 카탈로그 › 측정 의뢰 — 「이 시료의 이 물성을 재 달라」 가 기록으로 흐릅니다
지금까지 플랫폼은 잰 뒤(시료 → 시편 → 시험 → 카드)만 있었습니다. 누가 무엇을 왜 재 달라고 했고 어디까지 됐는지는 메일과 구두에 있었습니다. 이제 한 건은 번호를 달고 「접수 대기 → 접수 → 시험 중 → 결과 전달 → 완료」 를 거치며, 누가 언제 무슨 말로 옮겼는지 남습니다.
- 「새 의뢰」 에서 재료를 찾아 **시료**를 고르거나, **아직 등록 안 된 새 재료**면 무엇인지(이름·등급·업체·두께)를 글로 적습니다 — 받는 부서가 재료·시료를 등록한 뒤 「시료 잇기」 로 의뢰에 잇습니다. 항목마다 시험 종류·조건·방향·수량·받을 것(탄소성 카드·유변 카드·곡선…)을 적고, **받는 부서**를 고릅니다. 조건 칸은 시험 등록과 같은 칸, 같은 단위입니다. **시험 종류를 모르면 「미정」 으로 두고 무엇을 잴지(물성 이름)만 적으세요** — 받는 부서가 「종류 정하기」 로 정한 뒤 시험을 붙입니다.
- 「임시 저장」 은 나만 보는 작성 중, 「의뢰」 는 접수 대기 — 받는 부서 관리자에게 알림이 갑니다. 접수·보류·반려·결과 전달은 말 없이는 못 옮깁니다(언제쯤인지, 왜인지, 어디서 보는지).
- 받는 부서는 그 시료에 시편을 만들고 시험을 등록한 뒤, 의뢰 상세에서 항목에 **시험을 붙입니다**(같은 시료·같은 종류만). 붙으면 「접수」 는 저절로 「시험 중」 이 되고, 결과가 채택되면 진행률(채택/의뢰 수)이 오릅니다. 「결과 전달」 은 항목마다 채택 결과가 하나는 있어야 갑니다.
- 낸 사람은 결과를 확인하고 「완료」 로 닫습니다. 부족하면 「시험 중」 으로 되돌리고 말을 남깁니다.
- 목록은 「내가 낸 것 / 우리 부서가 받은 것 / 전체」 로 갈립니다. 낸 부서와 받는 부서만 봅니다 — 두 부서 사이의 약속이라 제3부서에는 보이지 않습니다.
- 알림 설정에 「새 측정 의뢰」(부서 관리자)·「측정 의뢰가 움직임」 이 늘었습니다.
