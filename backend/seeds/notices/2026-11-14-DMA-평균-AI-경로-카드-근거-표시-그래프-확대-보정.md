# DMA 시편 평균 보정 · 카드 근거 표시 · 그래프 확대 보정

■ DMA 온도별 카드(시편 평균)
- AI(MCP)로 만드는 시편 평균 카드: 평균 방식 선택 추가(기본 「온도 격자」 — 화면과 동일). 온도를 올리며 잰 시험 여럿이 0줄로 거절되던 문제 해결.
- 「온도 모으기」 평균: 한 시편이 같은 온도 폭 안에 여러 점을 잰 경우 시편마다 먼저 평균한 뒤 시편끼리 평균(촘촘하게 잰 시편이 평균을 끌던 문제 해결). 변동계수도 시편 기준. 이미 만든 카드의 값은 변경 없음.
- 워크벤치 경고 수: 「온도 격자」 평균 카드가 경고 카드로 세어지던 문제 해결. 시료(로트)가 섞인 평균 카드는 경고로 집계.

■ 카드
- 카드를 펼치면 「카드 근거」 목록 표시 — 평균에서 뺀 온도 · 시편 하나뿐인 줄 · 로트 섞임 · 값의 출처.

■ 그래프
- 휠 확대: 세로 방향도 커서가 가리킨 자리 기준으로 확대.
- 확대 상태의 이동: 데이터 범위 밖(빈 화면)으로 넘어가지 않음.

■ 운영 영향
- 마이그레이션 없음.
- 씨앗 데이터: 공지 하나 · 앱 안 가이드(사용 설명서).
