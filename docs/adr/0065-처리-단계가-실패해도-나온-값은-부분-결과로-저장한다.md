# 0065. 처리 단계가 실패해도 나온 값은 부분 결과로 저장한다 — 값만 재는 단계는 건너뛰고, 곡선이 여럿이면 채택하지 않는다

날짜: 2026-10-22
상태: 채택
관련: [ADR 0007](0007-원본과-처리결과-저장-구조.md)(결과는 불변 · 채택은 시험당 하나) ·
[ADR 0058](0058-워크벤치는-업무-단위다-업무가-전용-화면을-가진다.md)(채택 검토대)

## 배경

v1.285.0 에서 사용자 보고 셋이 같은 자리에서 나왔다.

- **할선 · 현 탄성계수에 R² 0.98 검사가 걸렸다.** 27건 중 1건만 값이 나왔다. 그 R² 는 두 점으로 정한
  선(원점을 지나는 할선)을 구간 점들에 견준 것이라, 토우가 조금만 있어도 떨어졌다 — 「구간이 직선인가」
  가 아니었다.
- **일괄 처리에서 한 단계가 실패하면 인장강도도 저장되지 않았다.** 탄성계수 단계는 값을 거절해도
  실패하지 않게 짜여 있었지만(인장강도를 지키려고), 그 값을 쓰는 항복강도가 `@youngs_modulus` 를 못
  찾아 실패했고 처리 전체가 멈췄다. 차례가 탄성계수 → 항복강도 → 인장강도라 인장강도는 계산조차 안 됐다.
  게다가 저장은 「반쯤 돈 결과가 채택되면 카드까지 간다」 는 이유로 막혀 있었다.
- **다온도 시험은 첫 곡선 하나만 처리됐다.** 일괄 처리가 곡선을 고르지 않으면 키 글자순 첫 곡선을 썼다.

## 결정

1. **할선 · 현은 R² 로 거르지 않는다.** 점 수(5개) 검사는 그대로다. 그 단계의 `elastic_r_squared` 는
   구간 점들의 회귀 R²(직선다움)로 내고, 0.98 미만이면 경고만 남긴다. 최소제곱 회귀 · 자동은 그대로
   거른다. 단계 버전 2.
2. **값만 재는 단계(`Plugin.measures`)는 실패해도 건너뛰고 계속한다**(`processing.apply(keep_going=True)`).
   곡선을 안 바꾸므로 뒤 단계는 같은 곡선 위에서 돈다 — 틀린 곡선 위에서 도는 일이 없다. 인장의
   탄성계수 · 오프셋 항복강도 · 인장강도 · 네킹 후보가 그렇다. **곡선을 바꾸는 단계가 실패하면
   예전처럼 멈춘다.** 실패한 단계가 내기로 한 값은 「잃은 값」 이 되어, 그것을 가리키는 뒤 단계도 실패한다
   — `@?`(있으면 쓰는 참조)로 가리켜도 그렇다(「없음」 이 아니라 「못 냄」 이다).
3. **나온 값은 부분 결과로 저장한다.** 실패한 단계는 결과의 `failures` 에 이유와 함께 남는다
   (`processing_results.failures`). 나온 값이 하나도 없으면 예전처럼 거절한다. 화면 · 결과 목록 ·
   채택 검토대 · MCP 가 「부분 결과」 를 말한다.
4. **일괄 채택은 지금 채택된 값을 잃게 하면 옮기지 않는다.** 부분 결과의 키가 지금 채택된 결과의 키를
   다 덮지 못하면 결과만 쌓고 채택은 그대로 둔다(줄에 까닭). 처음 처리하는 시험은 잃을 것이 없으니
   부분 결과도 채택한다 — 인장강도라도 물성으로 선다.
5. **일괄 처리가 곡선을 고른다**(`BatchRequest.curves`): `first`(기본 — 측정 곡선 먼저 · `raw` · 키 차례)
   · `all`(측정 곡선 전부, 장비가 계산한 곡선은 빼고) · 키 목록. **곡선을 둘 이상 돌린 시험은 채택하지
   않는다** — 채택은 시험당 하나라, 어느 곡선의 결과로 할지는 검토대에서 사람이 고른다. 처리의 첫 곡선
   차례도 시험 모듈과 같게 측정 곡선을 먼저 둔다(`curvedata.curve_order`).

## 대안

- **앞 단계 값만 저장(뒤는 안 돌림)** — 사용자 말 그대로지만 차례 때문에 인장강도가 살아나지 않는다.
- **실패한 단계를 건너뛰고 모든 단계를 계속** — 곡선을 바꾸는 단계(토우 보정)를 건너뛰면 뒤 값이
  틀린 곡선 위에서 나오고 틀린 티가 안 난다. 값만 재는 단계로 좁혔다.
- **부분 결과는 늘 채택하지 않는다** — 처음 처리하는 시험에서도 인장강도가 물성으로 안 선다(보고의 요청).
- **곡선이 여럿이어도 첫 곡선의 결과를 채택** — 사람이 고르지 않은 곡선이 시험의 물성이 된다.
