# 0038. 정의 문법을 넓혀 기본 형식을 정의로 옮긴다

날짜: 2026-09-28
상태: 채택
관련: [ADR 0023](0023-솔버-덱도-파일로-정의한다.md)(템플릿과 코드의 선 — 이 결정이 옮긴다) ·
[ADR 0037](0037-물성-모델마다-솔버-덱을-따로-낸다.md)(기본 형식 · 사용 중단 · 정의판) ·
[ADR 0006](0006-시험-종류를-부서가-만든다.md)(형식 프로파일은 데이터다)

## 배경

기본 제공 형식(코드 렌더러)은 틀려도 화면에서 고칠 수 없다. ADR 0037 은 **내리는** 길(사용
중단)을 만들었고, 고치는 길로 **정의판** — 같은 형식을 해석용 물성 정의로 다시 적은 것 — 을
두기로 했다. 그런데 기존 문법만으로 옮겨 보니(같은 날 오전) 51개 가운데 19개만 옮겨졌고
글자까지 같은 것은 Abaqus 셋뿐이었다. 막힌 자리는 큰 계산이 아니었다:

    재료 번호 자리표 · 주석 기호를 받는 머리       Abaqus 밖 전부
    단위계마다 갈리는 줄(/UNIT)                   Radioss 전부
    표의 첫 점 · 합 · 개수 · 번호                   SIGY · LIMIT1 · G∞ · NPTS · MPTEMP
    행 묶기 · 한 줄에 여러 행                       속도·온도별 곡선 · TABLES1 · Radioss 다섯씩
    글자 값 · 이름으로 행 고르기                    초탄성 식 · 점도 · JC 의 A·B·n
    조건 둘 이상                                  MAT1 둘째 줄
    값 검사                                       Prony 합 ≥ 1 · r ≤ 0 · b ≥ 0 · p < 1

ADR 0023 은 「템플릿은 조판만 한다 — 계산이 필요하면 코드로」 였다. 그 선이 정의판을 막는다.

## 결정

**막힌 자리마다 문법을 하나씩 넓힌다** — 실제로 쓰인 것만(`matcore/export/template.py` ·
`expr.py` 머리말이 정본).

    자리표      {id}(재료 번호) · {name:.60} · {식:형식} — 글자 줄·접두·접미·말에서
    식          비교 · and/or/not · A if 조건 else B · 글자 값 · has() · fmt() · round()
    표 함수     count · sum · first · last · min_of · max_of · distinct · joined
    표 정의     tables: {이름: {of, where, sort, x, y, by, clip, note, notes}}
    줄          each(묶음마다 줄 여럿) · pack(칸을 N 개씩 끊기 — Nastran 큰칸·Radioss 다섯씩·
                ANSYS TBDATA) · fail(값 검사) · 말만 남기는 줄
    칸          when · default · 형식 ["spec", ">10d"]
    묶음        header(comment) · provenance · radioss_unit
    needs       at_least

**코드에 남는 것**: 표 정리(`prepare` — 앵커·단조성), 단위 환산(`to_system`), 출처 머리(DB 에서
온 줄), Abaqus 온도별 탄성·열 키워드(`elastic`·`thermal` 묶음 — 빈 칸 검사), Radioss 단위 코드
(tonne → Mg), 중립 JSON(구조를 통째로 적는 형식이라 줄 문법이 아니다).

## ADR 0023 의 걱정 — 「디버깅할 수 없는 코드」 — 에 대한 답

0023 은 템플릿이 프로그래밍 언어가 되면 타입 검사도 시험도 못 받는다고 걱정했다. 셋이 달라졌다:

1. **식은 여전히 식이다.** 반복·대입·함수 정의가 없다. `each`·`pack` 은 선언이다(무엇을 몇
   개씩) — 순서도가 아니다.
2. **시험을 받는다.** 정의판 50벌을 코드판과 **글자까지** 견주는 시험이 잠근다
   (`tests/unit/test_export_twins.py` — 덱 글자 · 사람에게 남기는 말 · 거절까지, 시험 카드
   45벌 × 단위계 둘). 정의판이 틀리면 CI 가 멈춘다. 코드판을 고쳐도 멈춘다 — 둘은 늘 같다.
3. **저장 전에 읽어 본다.** 식·자리표·형식·조건·표 정의를 `each` 안까지 다 읽고, 서버를 멈출 수
   있는 것(정수 거듭제곱 `10^10^10` · 끝없는 칸 폭)을 막는다.

## 결과 (2026-09-28)

- **중립 JSON 을 뺀 50개가 전부 코드판과 글자까지 같다** — 알림·거절까지. 시험 카드 45벌과
  개발 DB 카드 37벌, SI · mm-N-tonne. 잘림·교차(LS-DYNA 표)·앵커(첫 점 2e-6)·차례가 섞인 행·
  초탄성 네 식·Prony 7항(UPRN)을 지난다.
- 사보타주 10건 중 9건을 문다. 못 무는 하나는 합의 덧셈 차례(마지막 자리 1e-16) — 덱에 찍히는
  유효숫자(최대 13자리)에서 안 드러난다.
- 씨앗 `backend/seeds/export-profiles/기본-형식-정의.json` 50벌, 개발 DB 에 **꺼진 채** — 운영에
  넣는 길이 빠져 있었다. 2026-10-01 부터 배포가 넣는다([ADR 0047](0047-기본-형식-정의판은-배포가-꺼진-채-넣는다.md)). 코드판이
  틀리면 사용 중단하고 정의판을 켜서 고친다.
- **편집기의 조용한 결함 셋이 함께 드러났다** — 정의판 50벌을 편집기의 변환(줄 → 폼 → 묶음 →
  줄)에 통과시켜 보고서다(`builtinTwins.test.ts`):
  - `join: ""`(칸을 붙여 씀)을 버렸다 → 서버가 `", "` 를 끼운다. **예제 덱에서 시작한 고정폭
    정의(LS-DYNA·Radioss·Nastran)가 저장 한 번에 칸 사이에 쉼표가 들어갔다.**
  - `needs`·`keywords`·`suffix` 를 버리고 늘 켜서 저장했다 → 「낼 수 있나」 판정이 사라지고,
    꺼진 정의가 메뉴에 섰다.
  - 묶음 몸 줄의 말(`note`)을 지웠다.

  고쳤고, 폼으로 못 그리는 줄은 「고급 줄」 로 원형 그대로 들고 다니며 JSON 으로 고친다.

## 대가

- 문법이 커졌다. 편집기는 폼으로 다 못 그린다 — `each`·`pack`·`fail`·표 정의는 JSON 이다.
- 코드판을 **지우지는 않는다**(아직). 둘이 늘 같으니 지울 수 있지만, 지우면 기본 형식이 DB
  씨앗이 되고 운영 서버마다 들여와야 한다. 문헌 덱(워크벤치)은 코드판 두 형식만 받는다
  (`litdeck.FORMATS`). 그 둘을 정한 뒤에 본다. — **같은 날 풀렸다**: 문헌 덱·BOM 덱이 형식
  목록(정의판 포함)에서 판정해 고른다([ADR 0039](0039-문헌-덱은-사내-물성-매핑을-거친다.md)).

## 버린 대안

- **파이썬 코드를 정의에 넣기(eval)** — 정의는 누구나 적는 데이터라 곧 원격 실행이다.
- **Jinja 같은 범용 템플릿** — 반복·필터가 넓어 저장 전 검사가 안 되고, 칸 폭 조판(고정 10칸 ·
  큰칸 16칸 · 줄 끝 공백 없음)을 다시 짜야 한다.
- **내장 형식을 덧칠** — ADR 0037 에서 버렸다(코드를 고쳐도 옛 덧칠이 이긴다).
