# 0071. 공개 피로 반입의 받는 쪽 — 새 키 · ΔK 축 · 1점 산점 · 공유 출처 · 조건 칸 목록

관련: [0068](0068-외부-공개-데이터는-반입-묶음-파일로-한-번에-들인다.md) · 요청
`75_MaterialCollector/docs/[요청] MatNexus 공개 피로·고무 반입 규모와 새 키.md`

## 배경

수집기가 공개 피로 DB(적층제조 · 고엔트로피 · 단일 연구실) · 용접 이음 피로 DB · 고무 나머지를 묶음 13개(값 약
7.4만 행 — 지금 카탈로그의 2.8배)로 정리하고 개발 미리보기만 했다. 막힌 것은 다섯이었다: 균열 성장률 곡선 701벌이
ΔK 축을 기다리고, 점 1개짜리 산점 274벌이 「곡선은 둘부터」 에 걸리고, 변형률 제어 응력 · 비틀림 · ΔKth 등의 키가 없고,
조건 칸 이름을 맞출 정본이 없고, 같은 출처를 여러 묶음이 쓸 때 지우기가 어떻게 되는지 몰랐다.

## 결정

1. **산점은 점 하나도 받는다**(`MIN_SCATTER_ROWS = 1`). 곡선은 둘부터 그대로다. 산점의 점은 대표값에서 빠지므로
   1점이어도 피로한도 대표에 섞이지 않는다 — 낱값으로 넣으면 섞인다.
2. **공유 출처는 마지막 묶음과 함께 사라진다.** 묶음을 지울 때 그 묶음 값이 쓰던 출처 가운데 **묶음이 만든 것**
   (`batch_id` 있음)이 비면 지운다. 아직 쓰이는 출처는 표지를 남긴다 — 전에는 첫 묶음이 표지를 걷어 버려 마지막
   묶음이 그 출처를 몰랐고, 값 없는 출처가 남았다. 손으로 넣었거나 이관해 온 출처는 값이 없어져도 남긴다.
3. **새 키 11개를 씨앗으로**(`local-definitions.json`): 순환 응력 진폭(변형률 제어) · 피로 소성 변형률 진폭 · 비틀림
   피로강도(전단 응력 진폭) · 비틀림 전단 변형률 진폭 · 비틀림 계수 넷(τ′f · b0 · γ′f · c0) · 균열 진전 하한 ΔKth
   (Pa·m^0.5) · Paris 식 계수(`term` C · m, da/dN 은 m/cycle · ΔK 는 MPa·m^0.5 규약) · **용접 이음 피로강도**.
   - 비틀림을 「피로강도」(하중 모드=torsion)에 넣지 않는다 — τ 가 σ 의 대표값이 될 수 있다.
   - 용접 이음 S-N 을 재료의 「피로강도」 에 넣지 않는다 — 이음 형식 · 용접법 · 두께에 갈리는 **이음의 값**이 모재
     값과 한 키에 섞여 보인다. 이음 형식 · 용접법 · 두께 · 응력 기준을 축으로 둔 별도 키다.
   - 용접 이음 하중-수명(L-N)은 받지 않는다 — 판 · 부품 치수에 묶인 값이다.
4. **원본 정의에 축을 덧붙인다**(`axis-extensions.json`) — 균열 성장률(`mechanical.crack_growth_rate`)에
   `delta_k_pa_sqrt_m` · `stress_ratio_R` · `temperature_k` · `frequency_hz` · `environment`. DB 만 고치면 배포마다
   도는 이관이 원본 축으로 덮으므로 **이관기와 씨앗 맞추기가 둘 다 붙인다**. 원본 축은 그대로 앞에 두고 뒤에
   덧붙이기만 한다. ΔK 축은 MPa·m^0.5 로 적으면 Pa·m^0.5 로 옮긴다(`X_AXIS_UNITS`).
5. **문헌 조건 칸 목록의 정본을 둔다**(`condition-fields.json`, `GET /catalog/condition-fields`) — 수집기가 제
   쪽에 따로 들던 「공통 칸」 을 여기로. 정의의 조건축에도 이 목록에도 없는 조건 칸은 반입 미리보기가 **경고**로
   센다(막지 않는다, MCP `import_catalog_batch` 의 `warnings`). 정한 것: 수집기가 쓰던 이름 대부분 그대로,
   `aging_weeks` 는 `aging_hours` 로(1주 = 168 h), `loading_mode` 는 밑줄(`rotating_bending`), `stress_basis` 는
   기준만(값은 늘 진폭), 용접부 영역 `weld_zone` · 용가재 `filler_metal` 을 더했다.

## 대안

- **이관 정의를 원본에서 고치기**: MaterialTwin 은 MatNexus 가 고치지 않는 원본이다.
- **균열 성장률을 새 로컬 키로**: 같은 물성이 두 키로 갈려 값 검색이 반씩 나뉜다(정의 만들기가 막는 그 일).
- **조건 칸을 서버가 거절**: 원본 데이터셋마다 칸이 다르고 대부분은 정당한 기록이다 — 세기만 한다.

## 하지 않은 것

- 다축 등가 진폭 · 확률 S-N(Weibull) · Walker · SWT 키 — 데이터 모양이 정해지면.
- 규모 확인: 공개 피로 7묶음을 개발에 적용한 뒤 검색 · 비교 · 물성 지도 · Ashby · 재료 상세를 잰다. 산점 점이 값
  검색을 뒤덮으면 「산점 점 빼고」 거르개를 더한다.
- 용접 이음 4묶음은 법무 확인 뒤(데이터 CC BY 4.0 · 데이터 논문 CC BY-NC-ND).
