# 0085. 묶음은 시험마다 채택 대신 쓸 결과를 고를 수 있고, 카드 · 덱은 그렇다고 적는다

날짜: 2026-11-14
상태: 채택
관련: [ADR 0080](0080-묶음이-낸-값은-묶음이-출처를-적고-등가값은-등급-3을-넘지-않는다.md)(등가값 · 등급 상한 3)

## 배경

VOC 49: 「채택」 은 「이 시험의 공식 물성은 이것」 이라는 선언이고, 통계 · 카드는 채택된 결과만 쓴다. 그런데
부품 · 적층판의 3점 굽힘 「등가 E」 처럼 공식 물성으로 올리지는 않지만 해석용 선형 카드는 필요한 값이 있다.
묶음은 시험 id 만 받고 채택 결과를 읽어서, 그런 값을 카드로 만들려면 채택해야 했고 그러면 재료 통계에
등가 E 가 섞였다.

## 결정 (사용자 결정 — 가안)

1. **묶음 요청에 시험마다 「쓸 결과」**(`results`: 시험 id → 결과 id). 안 적은 시험은 채택 결과를 쓴다.
2. **서버가 고른 결과가 그 시험의 것인지 본다**(`MNX-GROUPING-0016`). 보류 중인 시험은 지금처럼 못 넣는다.
3. **구성원에 표지가 남는다** — 채택과 다른 결과를 쓴 구성원은 `members[].unadopted`. 그 묶음으로 만든 카드는
   `source.unadopted` 와 근거 한 줄 「미채택 결과로 만든 카드 — 시험 N건은 …」, 덱 머리말에도 같은 줄.
4. **채택은 그대로다** — 재료 통계 · 물성 분석에 안 섞인다.
5. 등가 E 의 자리 · 출처 · 등급은 ADR 0080 그대로(탄성 E 칸, `equivalent:3점 굽힘`, 등급 상한 3).

## 대안

- **지금처럼 채택만** — 등가 E 를 쓰려면 공식 물성으로 채택해야 해서 재료 통계에 섞인다.
- **묶음 대신 카드에서 결과를 고른다** — 묶음의 평균 · 흩어짐 · 경고(변동계수)가 사라진다.

## 결과

- 화면 글로벌 피팅 창: 채택 결과가 필요한 묶음에 「채택하지 않은 결과도 쓰기」 — 켜면 미채택 시험도 후보에
  뜨고, 고른 시험마다 쓸 결과를 고른다.
- 구성원을 모으는 여섯 자리는 `grouping.services.result_id_of` 로 「이 묶음이 쓸 결과」 를 읽는다(묶음을 모으는
  동안만 두는 컨텍스트 — 인자로 끌고 다니지 않는다).
- MCP 에는 묶음을 만드는 도구가 없어 바뀐 것이 없다.
