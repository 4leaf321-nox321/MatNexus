# 0088. 접선 탄성률은 가장 가파른 창 하나가 아니라 그와 구별 안 되는 구간 전체로 잰다 — 응력 띠의 「닿음」 은 다섯 점 연속

- 날짜: 2026-11-14
- 상태: 채택(사용자 결정)
- 관련: VOC 43 · 44, ADR 0062(규격이 처리 방법을 든다)

## 배경

굽힘 · 압축 탄성률(`matcore/slopes.py`)의 두 방법이 잡음에 약했다.

**접선**(ASTM D790 · D6272 · D695 · E9 · ISO 844 · D1621 의 기본)은 너비 w 의 창을 처음 50 % 응력까지
40 자리로 밀며 **가장 큰** 회귀 기울기를 냈다. 잡음이 있으면 창마다 기울기가 몇 % 씩 흔들리고, 그중 최대를
고르면 늘 잡음이 위로 튄 창이 뽑힌다. 답을 아는 합성 곡선(E 3 GPa, 토우 5 % · 직선 60 % 까지)으로 쟀다 —
D790 기본 창(0.001)에서 응력 잡음이 최대의 0.1 / 0.25 / 0.5 % 일 때 1000점 곡선은 +6 / +15 / +32 %,
3000점은 +3.5 / +9 / +18 %. 창을 두 배로 넓히면 약 1/3 로 준다(창 하나의 기울기 오차 ∝ σ / (w^1.5 √밀도)).
굽힘 강성도 같은 창에서 재 같은 만큼 높았다. 인장 자동 구간이 같은 함정을 이미 겪었다(`tensile.py` — 「가장
가파른 창으로 바꿨더니 잡음이 이겼다, 200 GPa 직선에서 223 GPa」).

**응력 띠**는 띠 끝을 「문턱을 처음 넘은 한 점」 으로 정했다. 하중이 한 점 튀어 위 끝 문턱(40 %)을 일찍 넘으면
구간이 거기서 끊기고 그 점이 기울기를 끌어올린다 — +20 % 로 튄 점 하나가 든 500점 곡선의 13~16 % 가 5 % 넘게
틀렸고 최악은 +45 % 였다.

## 결정

1. **접선은 「가장 가파른 처음 직선 구간」 을 잰다.** 가장 가파른 창 k 를 찾고, 기울기가
   `b_k − 2 × max(SE_k, 창 SE 의 중앙값)` 이상인 창을 모두 덮는 구간(가장 이른 시작 ~ 가장 늦은 끝, 50 % 한계
   안)을 한 번 회귀한다. 그 값 · 구간 · 점 수 · R² 를 결과로 남긴다.
2. **묶인 창이 셋이 안 되면 가장 가파른 셋을 덮는다.** 묶이는 창이 그 하나뿐인 경우(잡음 곡선의 0.1~0.7 %)
   옛 값이 조용히 나오는 꼬리를 없앤다.
3. **응력 띠의 「닿음」 은 다섯 점 연속**(회귀 최소 점 수와 같다) 문턱 위의 첫 점. 곡선 끝이라 연속이 없으면
   한 점 도달. 토우 보정의 응력 기준 구간도 같은 규칙이다.
4. 기본 창 너비(0.001)와 규격 표의 창 값은 그대로 둔다.
5. 단계 버전을 올린다(탄성률 3 · 토우 보정 2). 저장된 결과는 건드리지 않는다 — 운영에서 영향받는 채택 결과
   수를 먼저 세고(`scripts/count_slope_results.py`) 다시 처리를 권할지 정한다.

## 대안

같은 실험으로 견줬다(L 곡선 1000점, 창 0.001, 잡음 0.1 / 0.25 / 0.5 / 1 %).

| 안 | 편향(중앙) | 버린 까닭 |
| --- | --- | --- |
| 지금 그대로 | +6 / +15 / +32 / +64 % | — |
| 창 넓히기(0.002) | 약 1/3 | 편향이 남고 직선이 짧은 곡선은 휨이 섞인다. 규격 표를 바꿔야 한다 |
| 상위 3 · 5 창의 중앙값 | +5 / +13 / +25 / +50 % | 거의 안 준다 |
| 창마다 R² ≥ 0.99 | — | 잡음 0.25 % 부터 거의 전부 「값 없음」 |
| 가장 가파른 창을 3w 로 넓혀 재회귀 | +0.2 ~ +3.6 % | 잡음 없는 곡선의 값을 바꾼다(직선 없는 곡선 −2.7 ~ −7 %) |
| 홀짝 나누기 | 0 근처 | 흩어짐 ±30 % |
| **묶은 구간 전체(채택)** | 0.0 ~ −0.1 %, 95 % 가 ±2 % 안 | — |

문턱을 3 × SE 로 올리면 꼬리는 없어지지만 토우가 긴 곡선 · 직선 없는 곡선이 더 낮아져 2 × SE + 최소 3창을
골랐다. 응력 띠는 이동 중앙값(창 5 · 9)도 효과가 같았으나 빈 칸 처리와 설명이 더 든다.

## 결과

- 직선 구간이 있는 곡선: 잡음 · 튄 점 · 점 밀도 · 창 너비를 바꿔도 편향 ±1 % 안(튄 점 +10 % 에서 −2 %).
  잡음이 없으면 값이 전과 같다(구간 · 점 수 · R² 칸은 창 하나에서 직선 구간 전체로 바뀐다).
- **직선 구간이 없는 곡선**(PP 처럼 처음부터 휘는 것)은 잡음이 크면 2~9 % 낮게 나온다. 전에는 2~67 % 높았다.
  그런 재료는 현(ISO 178) 같은 고정 구간이 더 맞다.
- 토우가 최대의 20 % 까지 가고 잡음이 1 % 이상이면 −1 ~ −4 %.
- 토우 보정에서 토우 점을 접선값으로 바꾼 뒤의 접선은 토우 구간 기울기 쪽으로 끌릴 수 있다(토우 20 % · 응력
  띠 10~40 % 에서 −2.3 ~ −2.9 %).
- 다시 처리하면 접선 결과는 대개 3~30 % 내려가고 굽힘 강성 · 구조 강성 묶음도 함께 내려간다. 묶음 · 카드는
  다시 채택 · 다시 묶어야 바뀐다.
- 응력 띠: 오르는 곡선은 비트 단위로 같다. 잡음이 최대의 1 % 이상인 곡선은 흩어짐 안에서 0.2~0.6 %p 낮아진다.
  아래로 튄 점이 문턱 바로 뒤에 있으면 구간 끝이 그 점 너머로 밀린다(드묾, 영향은 흩어짐 안).
- 실험은 응력 잡음만 넣은 합성 곡선이다. ASTM D790 원문은 저장소에 없어 「steepest initial straight-line
  portion」 인용은 대조가 필요하다.
