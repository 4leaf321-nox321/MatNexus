# 0079. 시료 이동은 받을 재료를 고르되, 분류가 같고 시료째다 — 합치기는 하지 않는다

날짜: 2026-11-14
상태: 채택
관련: [ADR 0042](0042-다른-두께에-넣은-시편은-고른-것만-옮긴다.md)(다른 두께로 옮기기) ·
[ADR 0035](0035-보기는-모두에게-고치기는-사람에게.md)(고칠 권한)

## 배경

VOC 59: 재료를 잘못 골라 등록한 시료를 바른 재료로 옮길 길이 없었다. 「다른 두께로 옮기기」 는 받을 재료를
`{grade}_{details}_{두께}` 로 계산해 **같은 부서 · 같은 Grade · Details** 안에서만 찾았다. 재료 합치기도
없었다. 옮겨도 T-번호 · 처리 결과 · 채택은 그대로 유지된다는 것은 확인했다. 사용자는 「받을 재료를 직접
고르는 시료 이동만」 을 골랐다.

## 결정

1. **받을 재료를 사람이 고른다**(`POST /samples/move-plan` · `/samples/move`). 미리보기는 쓰지 않는다.
2. **분류가 같아야 한다**(Family · Category · Grade, Grade 는 대소문자 무시). 다른 분류로 옮기는 것은 이동이
   아니라 다른 재료의 시험을 만드는 일이다. Details · 두께는 달라도 된다.
3. **시료째만** — 시료를 쪼개 옮기면 측정 의뢰 연결(의뢰는 시료에 붙는다)이 어긋난다. 시편이 없는 시료는
   옮길 시험이 없어 막는다.
4. **권한** — 받는 재료를 고칠 수 있어야 한다(남의 재료에 시료를 넣는 것은 그 재료를 고치는 일). 시료와 그
   시편도 모두 고칠 수 있어야 한다. 부서가 달라도 고칠 수 있으면 옮긴다.
5. **카드 · 기록은 두께 이관과 같은 틀** — 걸린 카드에 코멘트(「다른 재료로 옮겨졌습니다」)가 반드시 붙고
   정리(사용 중지)를 고른다. 묶음 · 대표 곡선 기록은 원 재료에 남는다. 감사 `samples.moved`.

## 대안

- **재료 합치기** — 카드 · 부품 · 문헌 연결 · 선언 물성 · 계수 묶음을 함께 옮길지 정해야 해 이번 범위 밖이다.
- **시편 단위로도 고른 재료로** — 일부 시편만 옮기면 새 시료를 만들어야 하고 의뢰 연결이 어긋난다.
- **분류가 달라도 허용** — 「잘못 고른 Grade」 를 고치는 데는 맞지만, 다른 재료의 시험을 조용히 만드는 길이
  된다. 그 경우는 재료의 분류를 고치거나 다시 올린다.

## 결과

- 화면: 시료 줄의 「다른 재료로 옮기기」. 카드 처리 부품(`RelocateCards`)을 두께 이관과 함께 쓴다.
- MCP `move_samples`(미리보기 기본). 시험: API 넷(옮김 · 분류 · 권한 · 카드 코멘트), 화면 둘.
