# 0084. 재료 기본 칸(밀도 · 푸아송비)은 값 옆에 근거를 두고, 카드는 그 근거로 등급을 매긴다

날짜: 2026-11-14
상태: 채택
관련: [ADR 0016](0016-시험이-주지-않는-물성은-선언한다.md)(선언 물성) · [ADR 0049](0049-선언-물성은-자료-관리자-승인으로-한-단계-오른다.md)(승인은 값에 묶인다) ·
[ADR 0080](0080-묶음이-낸-값은-묶음이-출처를-적고-등가값은-등급-3을-넘지-않는다.md)

## 배경

VOC 50: 문헌값을 채택하면 탄성계수는 선언 물성으로 들어가 출처 · 문헌 등급이 함께 간다. 밀도 · 푸아송비는
재료의 기본 칸(숫자 하나)에만 써지고 출처가 버려졌다. 카드는 그 값을 「재료에 적힌 공칭값(등급 3)」 으로 봐,
문헌 등급 4(추정)의 값이 더 믿을 만한 3으로 올라가 보였다.

## 결정 (사용자 결정 — 가안)

1. **칸 옆에 근거를 둔다** — `materials.column_evidence`(마이그레이션 `e7b3c9d15f42`). 칸마다 선언 물성 줄과
   같은 모양(값 · 출처 · 근거 문서 · 받아 온 문헌 근거)이라 문헌 대조(`declared_catalog.stamp`)와 지문을 그대로
   쓴다. 값을 읽는 화면 · 통계 · 검색 27곳은 그대로다.
2. **재료 고치기가 근거를 받는다** — `density_source` · `density_reference` · `density_catalog_value_ids`
   (푸아송비도 같다). 문헌 값 id 를 주면 서버가 숫자를 대 보고 그 문헌 등급을 붙인다(다르면 422).
3. **사람이 값만 고치면 근거를 지운다.** 같은 값을 되보내면(폼째 저장) 그대로 둔다.
4. **카드는 근거가 있으면 `declared:<출처>+catalog<N>` 와 근거 문서를 싣는다** — 등급은 선언 물성과 같은
   규칙(문헌 등급 · 출처). 근거가 없거나 값이 바뀌었으면 지금처럼 `material`(등급 3).
5. 문헌 반영 창과 MCP `adopt_catalog_values` 가 기본 칸에도 근거를 보낸다.
6. 이미 받아 온 값은 운영 작업에서 `scripts/backfill_column_evidence.py` 로 거슬러 채운다 — 재료가 문헌 재료에
   이어져 있고 칸 값이 그 문헌 값과 같을 때만(세어 보기가 기본).

## 대안

- **나안: 밀도 · ν 도 선언 물성으로 옮겨 카드가 그쪽을 먼저 읽기** — 값이 두 곳에 살아 기본 칸을 읽는 27곳과
  어긋날 위험이 크다.
- **출처를 모르는 칸 값을 등급 4 로** — 사람이 밀시트를 보고 친 값까지 「근거 없음」 이 된다. 지금처럼 3.

## 결과

- 재료 응답에 `column_sources`(칸별 출처 · 근거 문서 · 문헌 등급).
- 카드 블록에 `density_reference` · `poisson_ratio_reference` 가 실려 덱 각주가 근거 문서를 적는다.
