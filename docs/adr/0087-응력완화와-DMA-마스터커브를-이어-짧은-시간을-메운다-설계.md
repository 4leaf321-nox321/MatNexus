# 0087. 응력완화와 DMA 마스터커브를 이어 짧은 시간을 메운다 — 설계

날짜: 2026-11-14
상태: **채택 — 1단계 구현**(2026-11-15, v1.331.0). 정할 것 넷은 맨 아래 「결정」.
관련: [ADR 0081](0081-응력완화-Prony-의-가장-짧은-tau-는-첫-측정-시각이다.md)(응력완화의 가장 짧은 τ) ·
[ADR 0086](0086-DMA-온도별-카드는-격자-보간-로그-평균을-기본으로-한다.md)

## 문제

응력완화 시험은 하중을 거는 동안(대개 1 s 앞)의 완화를 모른다. ADR 0081 로 순간 탄성률 E₀ 가 첫 측정 시각에
따라 뛰지 않게 묶었지만, 그만큼 **짧은 시간(충격 · 고속) 강성은 이 카드에 없다**. 같은 재료의 DMA 마스터커브는
주파수 영역에서 그 짧은 시간(높은 주파수)을 잰다. 둘을 이으면 한 Prony 가 10⁻⁶ s ~ 10⁴ s 를 근거 있게 덮는다.

## 지금 있는 것

- DMA: 마스터커브(기준 온도 T_ref · 이동 상수 WLF/Arrhenius) → 주파수 영역 Prony(`matcore.prony`) → 점탄성 카드.
- 응력완화: 시간 영역 E(t) → 시간 영역 Prony(`extensions/relaxation`) → 점탄성 카드. 시험 온도는 조건 또는
  온도 채널 중앙값(VOC 52 에서 채움).
- 둘을 잇는 코드는 없다.

## 제안하는 길

1. **같은 것을 재는가부터 본다** — 같은 재료 · 방향, DMA 가 인장 · 굽힘 E′(전단 G′ 면 같은 ν 로 E 로), 응력완화
   시험 온도 T_R 이 마스터커브의 이동을 맞춘 온도 범위 안. 벗어나면 잇지 않고 까닭을 댄다.
2. **DMA 를 응력완화 온도로 옮긴다** — 마스터커브의 이동 상수로 a_T(T_R) 를 구해 주파수 축을 옮긴다(외삽이면
   막는다). 주파수 영역 Prony 의 Eᵢ · τᵢ 로 E(t) 를 시간 영역에서 계산한다(같은 계수라 변환이 정확하다).
3. **겹치는 구간에서 대 본다** — 응력완화 첫 측정 ~ DMA 가 덮는 가장 긴 시간 사이에서 두 E(t) 의 비를 낸다.
   비가 기준(예: ±15 %)을 넘으면 잇지 않고 말한다 — 시편 · 로트 · 변형률 크기(선형 구간)가 다를 수 있다.
4. **한 벌로 맞춘다** — 짧은 시간은 DMA, 긴 시간은 응력완화의 E(t) 를 시간 격자(자릿수마다 점 몇 개)에 모아
   시간 영역 Prony 를 다시 맞춘다. 겹친 구간은 두 쪽을 함께 넣는다(가중은 점 수로 같게).
5. **카드 · 덱에 근거를 남긴다** — 「t < t₁ 은 DMA 마스터커브(T_ref → T_R 이동)에서, t ≥ t₁ 은 응력완화에서」,
   겹친 구간의 비, 이동 상수, 두 시험의 이름. 등급은 두 근거 중 낮은 쪽.

## 정해 주실 것

1. **겹친 구간의 허용 비**(제안 ±15 %) — 넘으면 잇지 않는다 vs 경고만.
2. **어디서 만드나** — 묶음(글로벌 피팅)에 「응력완화 + 마스터커브」 를 한 종류로 둘지, 점탄성 카드 만들기에서
   「짧은 시간을 DMA 로 메우기」 선택지로 둘지(제안: 묶음 — 구성원 · 경고 · 쓴 것이 남는 틀이 이미 있다).
3. **변형률 크기** — DMA(작은 진폭)와 응력완화(유지 변형률)가 둘 다 선형 구간인지 확인할 근거(LVE 한계)를 요구할지.
4. **온도가 다를 때** — 응력완화 여러 온도를 한 번에 잇는지(마스터커브를 함께 이동) vs 한 온도씩.

## 결정 (2026-11-15 — 사용자: 1단계 시작, Q1~Q4 권장안)

조사 · 반박 검증(합성 재료 — 일반화 Maxwell 14항, 시간-온도 중첩이 정확히 성립하게 만든 것)을 거쳐 고쳤다.

1. **겹친 구간** — 비교 지표는 겹친 구간 비의 **중앙값**이다. 위의 「최댓값 ±15 %」 는 지금 DMA Prony 와 함께면
   같은 재료도 58 % 가 나와 무엇이든 막혔다(점이 몇 개뿐이다). 중앙값으로 같은 재료 1.6 %, 로트 10 % 차 13 %, 온도
   기록 2 K 오차 12 %, 비선형 46 %. **5 % 넘으면 잇되 경고 · 25 % 넘거나 겹친 응력완화 점이 셋 미만이면 막는다**
   (잠정 — 실재료 쌍으로 다시 정한다).
2. **어디서** — 묶음(글로벌 피팅) 한 종류 `relaxation.dma_coupled`. 계산은 확장(`extensions/relaxation/coupling.py`),
   중심에는 확장 이름 없는 일반 장치만: 구성원 규칙의 시험 종류별 갈래(`by_test_type`) · 마스터커브 구성원
   (`from: master_curve`) · 재료의 채택 결과에서 스칼라 모으기(`material_scalars`), 묶음 카드의 시험 종류 선언
   (`card_test_type` — 카드는 응력완화의 것, 방향도 그 시험에서 본다). 화면은 시험 종류마다의 조건(`needs_by_type`)
   으로 후보를 거른다.
3. **선형 구간** — 재료의 선형점탄성 한계(DMA 변형률 스윕의 채택 결과)가 있으면 유지 변형률과 견주어 넘으면 경고,
   없으면 「근거가 없다」 경고. 막지 않는다 — 큰 비선형은 1 의 비교가 막는다.
4. **온도** — 한 온도씩. 함께 옮기기는 시간-온도 중첩이 그 재료에서 맞는지 실재료로 본 뒤.

덧붙여 정한 것: DMA 쪽 Prony 는 **완화시간을 자릿수마다 못 박아** 다시 맞춘다(v1.328.0 의 `fit_decades` — 자유 τ
적합은 겹치는 저주파 끝에서 E′ 가 +40 % 틀렸다). 이을 때는 DMA 곡선을 짧은 끝부터 DMA 창 끝의 1/10 까지만 넣는다.
전단(G′) 마스터커브는 1단계에서 받지 않는다(ν 를 어디서 받을지가 남는다). 응력완화 묶음(`relaxation.prony`)이
온도 섞임을 경고만 하던 것은 막기로 바꿨다(v1.328.0).

결과(합성): 응력완화만 E₀ 0.2 GPa 대, 이으면 참값 ±5 %. 시험 `tests/unit/test_ext_relaxation_coupling.py` ·
`tests/api/test_ext_relaxation_api.py`. **실재료 쌍으로 검증하지 않았다** — 선 값은 잠정이다.

### 후속 (2026-11-15 — 전단 마스터커브 · MCP)

5. **전단(G′) 마스터커브** — E = 2(1+ν)G 로 옮겨 같은 길로 잇는다(묶음 판 2). **ν 는 사용자 결정대로** 묶음
   옵션(`poisson_ratio`) → 재료의 푸아송비 → 둘 다 없으면 거절한다 — `dma.to_shear` · DMA 온도별 카드와 같은
   규칙이고 값을 지어내지 않는다. 재료의 칸은 중심의 일반 장치 `material_fields`(구성원 규칙에 적은 재료의 기본
   칸을 구성원 값에 싣는다, 확장 이름 없음)로 온다. 전단 판정은 카드(`fitting._modulus_basis`)와 같은 근거로
   넓혔다 — 측정 채널이 G′ 이거나 변형 모드가 전단 계열. 쓴 ν 와 출처를 값 · 상세 · 경고 · 카드(`modulus_basis` ·
   `dma_poisson_ratio`)에 남긴다. ν 를 상수로 둔 환산이라 ν ≥ 0.45(고무)면 따로 경고한다. **카드의 ν 는 묶음의
   ν 를 따르지 않는다** — 공용 카드 길이 재료 · 입력의 ν 를 물려받고, 묶음은 「같게 두라」 고 경고만 한다(재료의
   ν 로 묶었으면 저절로 같다). 다르면 덱이 만드는 짧은 시간의 G 가 잰 G′ 와 어긋난다 — 카드 길에서 둘을 견주는
   것은 중심 쪽 남은 일이다.
6. **MCP 로 만든다** — 범용 쓰기 도구 `create_group(plugin_id, test_run_ids, options, note, dry_run=True)`. 묶음
   전용 도구를 두지 않은 까닭: 백엔드 계약(`POST /api/groups`)이 묶음마다 같고, 묶음 종류 · 구성원 조건 ·
   옵션을 `GET /api/groups/kinds` 가 이미 선언으로 주어 도구 하나가 모든 묶음을 덮으며, 설명 예산(64,000자)에
   도구 하나 자리뿐이었다. 백엔드에 묶음 미리보기 길이 없어 미리보기는 **계산하지 않고** 구성원 조건(시험
   종류마다 `needs_by_type` · 채택 결과 · 대표 마스터커브 · 보류 · 재료 하나 · 최소 수 · 모르는 옵션)만 본다.
   계산의 거절은 만들 때 까닭과 함께 오고 아무것도 안 남는다. AI 가 만든 묶음은 감사에 남는다
   (`group_result.created_by_client`).
