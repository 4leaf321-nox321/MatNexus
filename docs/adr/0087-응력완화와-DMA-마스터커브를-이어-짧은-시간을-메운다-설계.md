# 0087. 응력완화와 DMA 마스터커브를 이어 짧은 시간을 메운다 — 설계

날짜: 2026-11-14
상태: **제안**(구현 전 — 정해 주실 것은 맨 아래)
관련: [ADR 0081](0081-응력완화-Prony-의-가장-짧은-tau-는-첫-측정-시각이다.md)(응력완화의 가장 짧은 τ) ·
[ADR 0086](0086-DMA-온도별-카드는-격자-보간-로그-평균을-기본으로-한다.md)

## 문제

응력완화 시험은 하중을 거는 동안(대개 1 s 앞)의 완화를 모른다. ADR 0081 로 순간 탄성률 E₀ 가 첫 측정 시각에
따라 뛰지 않게 묶었지만, 그만큼 **짧은 시간(충격 · 고속) 강성은 이 카드에 없다**. 같은 재료의 DMA 마스터커브는
주파수 영역에서 그 짧은 시간(높은 주파수)을 잰다. 둘을 이으면 한 Prony 가 10⁻⁶ s ~ 10⁴ s 를 근거 있게 덮는다.

## 지금 있는 것

- DMA: 마스터커브(기준 온도 T_ref · 이동 상수 WLF/Arrhenius) → 주파수 영역 Prony(`matcore.prony`) → 점탄성 카드.
- 응력완화: 시간 영역 E(t) → 시간 영역 Prony(`extensions/relaxation`) → 점탄성 카드. 시험 온도는 조건 또는
  온도 채널 중앙값(VOC 52 에서 채움).
- 둘을 잇는 코드는 없다.

## 제안하는 길

1. **같은 것을 재는가부터 본다** — 같은 재료 · 방향, DMA 가 인장 · 굽힘 E′(전단 G′ 면 같은 ν 로 E 로), 응력완화
   시험 온도 T_R 이 마스터커브의 이동을 맞춘 온도 범위 안. 벗어나면 잇지 않고 까닭을 댄다.
2. **DMA 를 응력완화 온도로 옮긴다** — 마스터커브의 이동 상수로 a_T(T_R) 를 구해 주파수 축을 옮긴다(외삽이면
   막는다). 주파수 영역 Prony 의 Eᵢ · τᵢ 로 E(t) 를 시간 영역에서 계산한다(같은 계수라 변환이 정확하다).
3. **겹치는 구간에서 대 본다** — 응력완화 첫 측정 ~ DMA 가 덮는 가장 긴 시간 사이에서 두 E(t) 의 비를 낸다.
   비가 기준(예: ±15 %)을 넘으면 잇지 않고 말한다 — 시편 · 로트 · 변형률 크기(선형 구간)가 다를 수 있다.
4. **한 벌로 맞춘다** — 짧은 시간은 DMA, 긴 시간은 응력완화의 E(t) 를 시간 격자(자릿수마다 점 몇 개)에 모아
   시간 영역 Prony 를 다시 맞춘다. 겹친 구간은 두 쪽을 함께 넣는다(가중은 점 수로 같게).
5. **카드 · 덱에 근거를 남긴다** — 「t < t₁ 은 DMA 마스터커브(T_ref → T_R 이동)에서, t ≥ t₁ 은 응력완화에서」,
   겹친 구간의 비, 이동 상수, 두 시험의 이름. 등급은 두 근거 중 낮은 쪽.

## 정해 주실 것

1. **겹친 구간의 허용 비**(제안 ±15 %) — 넘으면 잇지 않는다 vs 경고만.
2. **어디서 만드나** — 묶음(글로벌 피팅)에 「응력완화 + 마스터커브」 를 한 종류로 둘지, 점탄성 카드 만들기에서
   「짧은 시간을 DMA 로 메우기」 선택지로 둘지(제안: 묶음 — 구성원 · 경고 · 쓴 것이 남는 틀이 이미 있다).
3. **변형률 크기** — DMA(작은 진폭)와 응력완화(유지 변형률)가 둘 다 선형 구간인지 확인할 근거(LVE 한계)를 요구할지.
4. **온도가 다를 때** — 응력완화 여러 온도를 한 번에 잇는지(마스터커브를 함께 이동) vs 한 온도씩.
