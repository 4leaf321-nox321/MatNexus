# 0032. 인장 교점은 생성 단계에서 넘긴다

날짜: 2026-09-22  
상태: 채택

## 배경

`tensile.proof_stress` 는 오프셋 선과 관측 곡선이 만난 공칭 응력과 변형률을 함께
구한다. 기존 `tensile.true_plastic` 은 응력만 받고 곡선에서 그 응력을 처음 넘는
지점을 다시 찾았다. S355처럼 응력이 한 차례 상승해 피크에 도달한 뒤 하강하고 다시
상승하는 곡선에서는 내력과 같은 응력이 실제 오프셋 교점보다 앞 구간에도 나타난다.
응력만으로 다시 찾으면 그 앞선 교차를 고를 수 있다. 중간에 400점 재표본화가 있으면
전달할 응력과 재표본 곡선의 값도 정확히 일치하지 않을 수 있다.

## 결정

처리 플러그인에 직렬화되는 `meta` 와 분리된 선택적 `prepare_options` 콜백을 둔다.
파이프라인은 단계 옵션의 복사본을 참조 해석 전에 콜백에 넘긴다. 콜백은 계산 엔진의
특정 플러그인 이름을 알아야 하는 규칙을 추가하지 않는다.

`tensile.true_plastic` 만 기존 저장 옵션을 보정한다. 항복 정책이 기본값인
`proof_stress` 이고, 원 옵션의 `proof_stress` 가 정확히 `@proof_stress` 이며,
`proof_strain` 키 자체가 없을 때에만 `@proof_strain` 참조를 보충한다. 숫자 항복강도,
하항복강도 참조, 명시적인 `proof_strain` 값, 다른 항복 정책은 그대로 둔다.

교점 좌표가 있으면 진소성 단계는 그 변형률을 현재 곡선에 삽입한다. 다른 채널은
변형률 기준으로 보간하고, 공칭 변형률과 응력에는 전달된 교점 값을 그대로 쓴다.
삽입 지점 뒤에 관측점이 두 개 이상 있어야 하며, 좌표는 유한하고 곡선의 관측 범위
안이어야 한다. 기존 관측점과 정확히 같은 좌표면 중복 행을 만들지 않는다. 재표본화된
응력이 전달 응력과 엄격히 일치해야 한다는 조건은 두지 않는다.

좌표가 없는 수동 숫자 항복강도나 하항복강도 경로는 기존 첫 응력 교차 동작을 유지하고,
결과 노트에 해당 좌표 없이 응력으로 교차를 찾았음을 밝힌다.

## 결과

- 이전 `@proof_stress` 레시피도 교점 변형률을 함께 전달하게 된다.
- 참조 보충 규칙은 해당 플러그인에만 있으며, API 메타데이터나 다른 플러그인의 기본값을
  바꾸지 않는다.
- paired 좌표 경로는 생성 단계가 찾은 구간을 보존하고, 기존 수동 항복 경로는 유지한다.
