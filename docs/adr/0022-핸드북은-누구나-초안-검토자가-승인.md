# ADR 0022 — 핸드북은 누구나 초안을 쓰고, 검토자가 승인한다

- 상태: 채택 (2026-08-28)
- 관련: ADR 0006(부서 관리자의 역할), ADR 0010(기준정보 키)
- 코드: `app/modules/guide/`, `frontend/src/modules/guide/`, `frontend/scripts/guide_seed.mjs`,
  `backend/scripts/import_guides.py`, 마이그레이션 `b3e8f1a2c9d4`

## 배경

「가이드」 메뉴가 stub 이었다. 손에 있는 것은 `규격/` 의 HTML 25편 — 시편 규격(인장·
DMA·경도·충격·부식…), 물성 계산(인장→소성, DMA→Prony, 크리프, 피로, 파괴…), 시험
방법(노화·마모). 전부 같은 뼈대(`h1` → 번호 매긴 `h2` 절 → 표·SVG)이고 제 `<style>`
을 안고 있다.

원하는 것 셋: **찾기 쉽고**, 나중에 **사람이 손으로 고칠 수 있고**, 나중에 **AI(MCP)**
도 고칠 수 있을 것. 그리고 마크다운을 모르는 사람이 많다.

## 결정

**단위는 절이다.** 문서째 두면 「ASTM E8 두께 변수」 를 찾으려고 74KB 를 스크롤한다.
절이 단위면 검색 결과가 절로 떨어지고, 편집이 절 하나로 끝나고, 앱의 자리(시험
종류·시편 규격)가 절을 가리킬 수 있다.

**정본은 편집기 문서(ProseMirror JSON)다. Markdown 이 아니다.** 검토해 보니 이
문서들에 필요한 것이 Markdown 에 없다 — 셀 병합 표(시편 치수 매트릭스가 이 모양),
그림 캡션·크기, 안내 상자. Markdown 으로 바꾸면 그 표들이 깨진다. 사람은 리치
텍스트 편집기(Tiptap)로 쓰고 편집기가 문서를 정한다. 마크다운은 사람 눈에 안 보인다.

**서식은 앱이 정하고, 사람은 뜻만 고른다.** 제목(2·3·4단계) · 문단 · 굵게 · 기울임 ·
코드 · 링크 · 목록 · 인용(안내 상자) · 표(병합 포함) · 그림 · 구분선. 글꼴·색·크기는
없다 — 원본이 문서마다 제 `<style>` 을 안고 있어 25가지 얼굴이었고, 그것을 한 벌로
만드는 장치가 이것이다. 넣지 않은 서식은 붙여넣어도 사라진다.

**그림은 파일이다.** 붙여 넣는 순간 서버에 올리고 본문에는 주소만 넣는다. base64 로
박으면 본문이 그림 크기만큼 부풀고 같은 그림이 절마다 복제된다.

**누구나 초안, 검토자가 승인.** 절의 본문은 승인된 것이고, 고치려면 리비전을 낸다
(로그인한 누구나). 검토자(부서 관리자 이상 — 재료·프로파일을 만드는 역할과 같다,
ADR 0006)가 승인하면 그 리비전이 본문이 된다. 검토자는 자기 것을 바로 낼 수 있다.
**검토 없이 본문이 바뀌는 길은 없다** — 나중에 AI 가 쓰게 될 때 특히 그렇다. 앞의
판은 리비전에 남는다.

**검색은 trigram.** 본문에서 글자만 뽑은 `body_text` 에 `pg_trgm` GIN. 한국어는
띄어쓰기가 단어 경계가 아니라 `tsvector` 로는 「치수변수」 로 「치수」 를 못 찾는다.
재료 이름 검색과 같은 선택이다.

**가져오기는 편집기와 같은 코드로.** HTML → 편집기 문서 변환을 Node(`@tiptap/html`)
가 한다 — 화면에서 붙여 넣은 것과 같은 결과가 나와야 「가져온 것만 다르게 생긴」 절이
안 생긴다. 씨앗(JSON + SVG)을 저장소에 두고 Python 스크립트가 DB 에 넣는다.

## 대안

- **Markdown 정본.** AI 편집에는 편하다. 그러나 사람이 못 쓰고, 병합 표·그림 캡션이
  깨진다. 기각. 나중에 MCP 는 JSON 을 직접 주고받는다.
- **게시판식 편집기(CKEditor·TinyMCE).** 글꼴·색 단추가 기본이고 떼기 어렵다 →
  25가지 얼굴로 돌아간다. 기각.
- **폴더 트리 분류.** 하나의 분류만 허용한다. 「DMA 시편 치수」 는 시편이면서 DMA
  다. 종류(`kind`)와 대상(`topic`) 두 축을 둔다. `topic` 은 시험 종류 key 와 같은
  값을 써서 시험 화면이 「이 종류의 가이드」 를 자동으로 끌어올 수 있게 한다.
- **부서 관리자만 편집.** 초안이 안 쌓인다. 현장의 사람이 「이 값 틀렸다」 를 그
  자리에서 적을 수 있어야 핸드북이 산다. 승인 문턱이 그것을 지킨다.
