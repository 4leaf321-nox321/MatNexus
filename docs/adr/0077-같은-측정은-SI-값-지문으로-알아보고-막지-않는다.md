# 0077. 같은 측정은 SI 값 지문으로 알아보고, 막지 않는다 — 점검 · 채택 확인 · 통계에서 고름

날짜: 2026-11-14
상태: 채택
관련: [ADR 0076](0076-확인할-경고는-결과와-함께-남고-채택에서-확인을-받는다.md)(경고는 채택에서 확인) ·
[ADR 0008](0008-통계는-반복시편-산포와-대표곡선이다.md)(통계는 반복 시편의 산포)

## 배경

VOC 54: 같은 곡선이 두 번 들어가 통계에 이중으로 셌다. 업로드는 원본 파일의 SHA 만 견줘 「내용이 같은
파일이 이미 N건」 을 시험 메모에 적었는데, 업로드 창은 바로 닫혀 그 말을 아무도 못 봤고 채택 · 통계는
그것을 몰랐다. 개발 DB 에서 같은 재료 · 시험 종류에 같은 SHA 의 채택 시험이 둘 이상인 조합이 8개였다.
그리고 SHA 는 줄끝 · 머리말 · 형식 · 단위만 달라도 다른 파일이 된다. 사용자는 「단위가 다르게 보내진
사본은 탐지 못할 것 같다는 점을 유의해 방법을 제안해 달라」 고 했고, 막지 않고 경고만 하기로 정했다.

## 결정

1. **곡선의 값 지문**(`curves.fingerprint`, `matcore.curves.fingerprint`) — 시험 종류가 정의한 채널의
   **SI 값**을 유효숫자 10자리로 반올림해 해시한다(열 이름순, 빈 칸은 빈 칸끼리). 곡선은 읽을 때 이미
   SI 로 바뀌므로 **단위만 다른 사본(N/kN · mm/m · %/비율)도 같은 지문**이 된다. 정의 밖 채널(장비가 더
   적은 시간 · 온도 모니터)은 넣지 않아, 그것만 다른 사본도 같게 본다. 마이그레이션 `b5e9c2d47a18`,
   옛 곡선은 `scripts/backfill_curve_fingerprints.py` 가 저장된 곡선으로 채운다(다시 읽지 않는다).
2. **막지 않는다.** 재시험 · 반복 측정이 정상인 자리다. 같은 원본 SHA 는 `duplicate_file`, 원본은 다르고
   지문이 같으면 `duplicate_curve` 로 **시험 점검**에 남긴다 — ADR 0076 의 틀을 타고 처리 결과의 경고가
   되어 **채택할 때 확인을 받고**, 일괄 「바로 채택」 은 미룬다.
3. **통계는 사람이 고른다.** 재료 통계 · 분석(비교 · 분포 · 추세)은 기본으로 다 세고, 겹친 수
   (`duplicate_count`)를 말한다. 「같은 지문은 하나로」(`unique`)를 고르면 **먼저 등록한 시험 하나**만 센다.
4. **업로드 창이 말한다.** 같은 파일이 이미 있으면 등록은 하되 창을 바로 닫지 않고 알린 뒤 「닫기」 를
   기다린다.

## 대안

- **같은 지문이면 업로드를 막는다** — 재시험 · 반복 측정을 막는다(사용자 결정: 경고만).
- **SHA 만 쓴다**(지금 그대로) — 형식 · 단위만 다른 사본을 못 잡는다.
- **근사 특징 비교(최대하중 · 끝 변위 0.1~0.5 %)** · **모양 + 단위 상수 배율** — 자릿수가 다르게 적힌
  사본 · 단위를 잘못 적은 사본까지 잡지만, 크기를 지운 모양 비교는 개발 DB 의 서로 다른 시편 29개 중
  13쌍을 같게 봤다. 정확 지문 다음 단계로 미룬다.
- **통계에서 같은 지문을 기본으로 뺀다** — 재시험이 정상인 자리에서 사람이 모르는 사이에 n 이 줄어든다.

## 결과

- 못 잡는 것: 자릿수가 다르게 적힌 사본(1.235 kN 과 1234.56 N), 점을 솎거나 자른 사본, 단위를 잘못 적은
  사본(값 자체가 다르다).
- 시험 고정물을 다시 올려 「시편 여럿」 을 흉내 내는 시험들은 공통 설정(`tests/conftest.py`)이 서로 다른
  측정으로 친다 — 중복 점검을 보는 시험만 `@pytest.mark.duplicates` 를 단다. 안 그러면 41건이 채택 확인에
  멈췄다(그 시험들이 보려는 것은 중복이 아니다).
- 개발 DB: 곡선 340개에 지문을 채웠고, 같은 지문이 여러 시험에 있는 묶음 49개(대부분 예제 파일 재사용).
