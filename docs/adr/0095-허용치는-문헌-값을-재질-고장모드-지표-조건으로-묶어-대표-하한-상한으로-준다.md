# 0095. 허용치는 문헌 값을 재질 · 고장모드 · 지표 · 조건으로 묶어 대표 · 하한 · 상한으로 준다

날짜: 2026-11-17
상태: 채택
관련: [ADR 0094](0094-문헌-범위의-끝은-대표값-뒤로-서고-끝만-있으면-그렇다고-말한다.md)(범위의 끝 판정) ·
[ADR 0041](0041-카드의-대표-곡선은-평균만이-아니다.md)(표본이 적을 때 P5) · [ADR 0027](0027-물성-카탈로그를-들인다.md)(카탈로그)

## 배경

HWAX 연결에서 해석 플랫폼이 파손 판정에 쓸 허용치를 받을 길이 없었다. 사람이 문헌 카탈로그 값을 손으로 json 에
모았다. 여러 재료를 가로지르는 도구는 `find_by_property` 하나였고 조건 · 출처 · 시험규격을 빼고 돌려주어 재료마다
상세를 다시 열어야 했다. 고장모드 축은 물성 분류에 없다(분야 · 물성군 · 물성) — `yield_strength` · `tensile_strength`
처럼 물성 키에 숨어 있다. 하한 · 상한은 칸이 아니라 따로 된 줄의 조건 글자였다(ADR 0094).

사용자 결정(2026-11-17): 1차는 문헌만, 사내 시험 통계는 다음.

## 결정

1. **`GET /catalog/criteria`**(`catalog/criteria.py`) · MCP `get_criteria`(도구 133개). 재질은 문헌 재료 id ·
   이름(목록과 같은 검색, 50종까지) · 사내 재료(이어진 문헌 재료) 중 하나 — 없으면 거절(`MNX-CATALOG-0081`).
2. **한 줄 = 한 재료 · 한 물성 · 한 조건.** 범위 표지(`bound` · `value_type` · `statistic`)와 관리 기록을 뺀 조건이
   같은 값을 묶는다 — 「400 to 700」 의 하한 · 상한이 가운데 값과 한 줄로 돌아오고, 온도 · 방향이 다르면 다른 줄이다.
   평균하지 않는다. 줄마다 대표(범위의 끝이 아닌 값 중 대표값 순위가 앞선 것) · 하한 · 상한 · 같은 조건의 나머지
   수(`others`) · 응력 성분(direction · loading · mode …) · 온도 · 시험법(조건의 `test_standard` · `test_method`) ·
   출처 · 등급 · 주의. 끝만 있으면 대표가 비고 「범위의 끝만 있다」.
3. **고장모드 · 지표 표는 코드 안 표**(`MODES`, 어휘는 `GET /catalog/criteria/modes`). 항복 · 극한(인장 · 압축 ·
   굽힘 · 전단) · 파단 변형 · 피로한도 · 파괴인성(ΔKth 포함) · 접합(박리 · 중첩전단 · 다이쉬어 · 응집) · 충격.
   모델 계수(σf′ · Johnson-Cook A …)는 허용치가 아니라 넣지 않는다. 곡선 · 산점의 점 · 원본에서 빠진 값 · 식의
   변수도 뺀다(S-N 점 하나가 피로 허용치로 서면 안 된다).
4. 거르개: 고장모드 · 지표 · 물성 키 · 시험법(포함, 대소문자 무시) · 최대 등급. **tier 4 도 기본으로 싣는다**
   (기본 제외하지 않는다는 방침) — 줄마다 등급과 주의가 붙는다.

## 대안

- **물성 분류에 고장모드 축을 더한다(기준정보)** — 마이그레이션 · 화면 · 관리 권한이 따라온다. 허용치로 읽는 키는
  스무 개 남짓이고 거의 바뀌지 않아 코드 표로 시작했다. 늘어나면 기준정보로 옮긴다.
- **사내 시험의 하위 5 % 를 같은 응답에** — 표본이 적을 때 P5 를 쓰지 않기로 한 결정(ADR 0041)과 함께 정할
  일이다(다음 단계). 지금은 `get_distribution` 을 가리킨다.
- **`find_by_property` 에 조건 · 출처를 더한다** — 그 도구는 「값으로 재료를 찾는」 길이다. 하한 · 상한을 한 줄로
  묶고 고장모드로 거르는 것은 다른 물음이라 도구를 나눴다.

  304 계열은 방향별로 항복 · 인장 · 연신율.
