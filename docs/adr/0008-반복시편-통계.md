# ADR 0008 — 반복 시편 통계

- 상태: 채택
- 날짜: 2026-08-17
- 관련: ADR 0007(불변 결과와 채택), 65 `modules/statistics`

## 결정

시편 여러 개의 채택된 결과를 묶어 흩어짐을 낸다. **묶음은 재료 + 시험종류 +
방향**이고, 결과는 `EnsembleResult` 로 남길 수 있다(불변).

```
n · 평균 · 표본SD(n-1) · 중앙값 · MAD · IQR · min · max · CV · 평균의 95% CI
곡선은 격자 점마다 위 통계를 전부 → 평균 곡선 · 중앙값 곡선 · 산포
이상치는 modified z-score(MAD 기반, 기본 3.5)로 **표시만** 한다
```

## 왜 지금인가

배치 적용이 들어가면서 한 재료에 채택된 시험이 15건 쌓였다. 그런데 "이 재료의
항복강도는?" 을 보려면 **시험을 하나씩 열어야** 했다 — 값은 다 있는데 모아 볼
곳이 없었다.

## 결정한 것들과 근거

### 묶음은 재료 + 시험종류 + 방향

인장은 압연 방향에 따라 물성이 다르다. MD 5개와 TD 5개를 한 통계로 묶으면 CV 가
15% 로 나오는데, **그것은 산포가 아니라 다른 것을 섞은 것이다.** 강판은 20% 넘게
차이 나기도 한다.

시료(lot)까지 나누지 않는 이유: 보통 같은 재료로 취급하고, 나누면 표본이 2~3개로
줄어 통계가 성립하지 않는다.

### 정렬을 대신 하지 않는다

시편들의 x 격자가 다르면 계산하지 않고 거부한다. 여기서 조용히 보간하면 **그
보간이 결과에 섞이고 아무도 모른다.** 정렬은 처리(`curve.resample`)의 일이다.
65 도 같은 판단이다 — *"Statistics performed no alignment."*

**다만 거부하고 끝내지 않는다.** 공통 구간을 계산해 알려 준다:

```
3번째 곡선의 x 가 첫 곡선과 다릅니다 (20점 vs 18점). 통계는 정렬을 대신 하지
않습니다 — 레시피에 '균등 격자로 재샘플' 단계를 넣고 구간을 [0.001, 0.3] 로
고정한 뒤 다시 처리하세요. 가장 짧은 곡선은 'SECC_MDOI_1.0__01__MD_03__TEN_01'
입니다.
```

그 값은 시편을 전부 봐야 나오므로 **사람이 손으로 구할 수 없다.** 실제로 그
안내를 따라 배치를 다시 돌리니 15건이 같은 50점 격자가 되고 앙상블 곡선이 나왔다.

### 공통 구간까지만 낸다

시편마다 파단 변형률이 다르다. 하나는 0.28 에서 끊기고 하나는 0.35 까지 간다.
전체 구간을 쓰면서 짧은 것을 빼면 **뒤로 갈수록 n 이 줄어드는데 그것이 그래프에
안 보인다** — 곡선이 뒤에서 갑자기 매끈해지고 이유를 알 수 없다.

### 이상치를 버리지 않는다

modified z-score(MAD 기반)로 후보만 표시한다. **평균 기준으로 재면 이상치가
평균을 끌고 가 정작 그것이 안 걸린다.**

- **표본 2개면 판정하지 않는다.** 둘이 다르면 어느 쪽이 이상한지 알 방법이 없다.
  65 는 같은 이유로 **양쪽을 다** 검토 대상으로 표시한다.
- **MAD 가 0 인 경우가 실제로 온다.** 같은 파일을 여러 번 올리면 값이 정확히
  같다. z 가 무한대가 되므로 점수 없이 사실만 남긴다.

### t 분포를 쓴다

시편은 3~10개다. 그 수에서 정규분포를 쓰면 신뢰구간이 실제보다 좁게 나온다 —
n=3 이면 4.303 이어야 할 것이 1.96 이 된다. 두 배가 넘는 차이다.

### 평균이 뜻없는 항목은 뺀다

채택된 결과의 스칼라 12개 중 셋은 평균이 의미 없다.

| | 왜 |
|---|---|
| `necking_candidate_index` | 배열 위치다. 평균 14.0 은 아무 뜻이 없다 |
| `elastic_r_squared` | 적합도다. 평균보다 **최솟값**이 중요하다 |
| `proof_offset` | 설정값이다 — 다르면 평균이 아니라 **경고**여야 한다 |

`proof_offset` 이 시편마다 다르면 0.2% 로 잰 것과 0.5% 로 잰 것을 섞은 것이다.
평균을 내지 않고 그 사실을 말한다.

### 저장은 명시적으로 (ADR 0007 과 같은 모델)

화면은 늘 최신을 계산한다. 시험이 하나 더 붙으면 평균이 달라지는 것이 맞다.
남겨야 할 때만 `EnsembleResult` 를 만들고, **쓴 시험과 그때 채택돼 있던 결과를
통째로 박아 둔다** — 그러지 않으면 "이 평균이 어디서 나왔나" 를 답할 수 없고,
그 숫자는 근거가 없다.

## 대안

**통계가 알아서 재샘플한다** — 편하지만 보간이 결과에 섞인다. 기각.

**이상치를 자동으로 뺀다** — 시편 하나가 낮은 것이 재료 특성일 수 있다. 뺀 통계는
실제보다 좁은 산포를 보여 주고, 그것은 "이 재료는 안정적이다" 라는 **틀린 결론**이
된다. 기각.

**전체 구간에서 있는 것만 평균** — n 이 점마다 달라지는데 그래프에 안 보인다. 기각.

## 결과

### 얻은 것

- 재료 상세에 '물성' 탭. "이 재료의 항복강도는?" 에 한 화면에서 답한다.
- 앙상블 곡선이 **Phase 4 피팅의 입력**이 된다.
- 격자가 어긋났을 때 **무엇을 하면 되는지**가 화면에 있다. 실제로 그 안내를
  따라가 한 바퀴가 돌았다.

### 남은 위험

**값의 검증은 실데이터를 기다려야 한다.** 지금 표본 15개가 전부 같은 18점
파일이라 CV 가 1e-14% 다. 구조는 검증됐지만 "이 재료의 CV 가 3% 다" 같은 판단은
실제 시험 파일이 있어야 한다. `002_Material` 의 "원본" 도 1KB 발췌본이었다.

**곡선 통계를 JSONB 에 둔다.** 재샘플 뒤라 점이 많지 않아(50~200) 지금은 맞다.
수천 점이 되면 `Curve` 처럼 Parquet 로 옮겨야 한다.
