# 0086. DMA 온도별 카드의 시편 평균은 격자 보간 로그 평균을 기본으로 한다 — 합집합 · 짝짓기는 고른다

날짜: 2026-11-14
상태: 채택
관련: 온도별 저장 탄성률 카드(2026-10-22, v1.285.0 보고)

## 배경

VOC 48: 온도별 E′ 카드를 시편 여럿으로 만들면 첫 표의 온도 점마다 다른 시편에서 ±0.5 K 안의 점을 찾고, **모든
시편에 짝이 있는 온도만** 남겼다(`viscoelastic.average_tables`). 온도를 올리며 잰 시험은 시편마다 점이 찍힌
온도가 조금씩 달라 거의 다 빠졌고(점 간격 1.5 K 이상이면 0줄), 한 온도씩 잰 시험(25 · 50 · 75 °C 를 시편마다
따로)은 한 표로 못 합쳤다. 값은 산술 평균이라 E′ 가 몇 자릿수 바뀌는 전이 구간에서 큰 값 쪽으로 쏠렸다.

## 결정 (사용자 결정 — 제안한 기본값)

1. **방식을 셋으로** — `grid`(공통 온도 격자) · `union`(잰 온도를 모두 모음) · `matched`(지금). 화면은 표 여럿이면
   `grid` 가 기본, API 는 하위 호환으로 `matched` 가 기본이다.
2. **격자 평균** — 간격 1 K. 시편마다 **자기가 잰 범위 안에서만** log E′ · log E″ 를 선형 보간하고(외삽 없음),
   격자 온도마다 기여한 시편으로 로그 평균(기하 평균)한다.
3. **합집합** — 온도 차례로 늘어놓고 ±0.5 K 안을 같은 온도로 보아 로그 평균한다.
4. **줄마다 기여 시편 수**(`sample_count`)를 싣는다. 2개 미만인 줄은 남기되 카드 근거에 적는다.
5. **로트가 섞이면 경고만** — 시료가 둘 이상이면 근거에 적는다(막지 않는다). 운영 메모의 「일부 시험이 다른
   묶음일 수 있음」 대응.
6. E′ 변동계수는 지금처럼 값(선형)으로 낸다.

## 대안

- **산술 평균 그대로** — 전이 구간에서 큰 값 쪽으로 쏠리고 전이가 넓어진다.
- **넓은 허용폭으로 짝짓기**(±2 K) — 전이 구간에서 다른 온도의 값을 섞는다(E′ 가 몇 K 에 열 배 변한다).
- **외삽해서 범위를 맞춘다** — 한 시편이 안 잰 온도의 값을 지어낸다.

## 결과

- `matcore.viscoelastic.average_grid` · `average_union`, 카드 블록 행에 `sample_count`.
- 미리보기(만들기 전에 평균 표를 보는 길)는 이번에 만들지 않았다 — 카드는 초안으로 만들어지고 근거에 뺀 것 ·
  얇은 줄이 적힌다.
