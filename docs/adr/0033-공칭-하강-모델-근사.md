# 0033. 공칭 하강은 진단하고, 평탄화는 선택 구간 모델로 명시한다

날짜: 2026-09-22
상태: 채택

## 배경

공칭 응력-변형률의 하강만으로 상항복강도(ReH), 하항복강도(ReL), 뤼더스 변형률을
자동으로 정할 수 없다. 측정 장비·시험편·단면 변화·재료 거동이 같은 모양을 만들 수
있고, 실제 자료의 말단 급락은 선택한 항복 구간과 무관하게 보존되어야 한다. 자동으로
찾은 최솟값을 진소성 시작값으로 연결하면 측정 진단과 사용자가 선택한 모델 입력이
섞인다.

외부 자료도 원자료 보존, 수동 경계 선택, 모델 선택과 보정의 분리를 전제로 한다.

- [Altair Material Modeler — prepare data](https://help.altair.com/material_modeler/topics/material_modeler/prepare_data_t.htm)
- [Ansys MCalibration quick tutorial](https://www.ansys.com/content/dam/resource-center/datasheet/mcalibration-quick-tutorial.pdf)
- [Matereality/LSDYNA 2012 발표자료](https://www.matereality.com/Presentations/LSDYNA2012.pdf)

## 결정

1. `tensile.yield_drop` 의 `envelope`, `isotonic`, `cut`, `keep` 은 기존 하강 진단·곡선
   정리 동작을 유지한다. 단계와 선택지의 표현은 공칭 하강을 특정 재료 현상이나 특정
   해석기 제약으로 단정하지 않도록 한다.
2. 자동 `upper_yield_strength`, `lower_yield_strength`, `luders_strain` 결과와 Produced
   선언을 제거한다. 과거 레시피가 `@lower_yield_strength` 를 참조하면 참조 해석기가
   값이 없다고 명확히 보류한다. 과거 저장 결과를 자동 변환하지 않는다.
3. 저장 호환을 위해 `lower_yield` method key는 남긴다. 이 key는 규격 항복 평가가
   아니라 **선택 구간 평탄화(모델 근사)**다. `plateau_start`, `plateau_end` 공칭
   변형률과 `plateau_stress` 목표 응력을 모두 사용자가 지정해야 한다.
4. 시작은 끝보다 작아야 하고 요청 구간은 관측 범위 안이어야 한다. inclusive mask에
   원관측점이 두 개 이상 있어야 하며 목표 응력은 유한한 양수여야 한다. 선택된 응력
   행만 목표값으로 치환하고, 다른 행·열·원본 Frame은 보존한다. 변경점 수는 실제
   치환된 행 수다.
5. `min_slope` 를 함께 주는 것은 평탄화와 별도 단조화의 의미를 섞으므로 보류한다.
   사용자는 평탄화 뒤 별도 단조화 단계를 명시한다. 기존 E→Rp→진소성 경로는
   변경하지 않는다.

## 결과

모델 입력은 더 이상 곡선의 전역 최솟값이나 자동 항복 추정에 의존하지 않는다. 결과에는
`model_plateau_stress`, `model_plateau_start`, `model_plateau_end` 와 실제 변경점 수가
남고, 노트에는 요청 구간·실제 관측 구간·점 수와 규격 하항복강도/뤼더스 측정이 아님을
기록한다. 기존 네 generic 방법과 탄성계수·오프셋 항복·진소성 계산은 그대로 사용할
수 있다. 규격 항복 평가와 네킹 이후 재료 모델 검증은 별도 범위로 남긴다.

## 추가 결정: 하측 포락선의 자동 규칙 — 2026-09-23

시험마다 구간과 목표값을 사람이 정하면 같은 DB에 쌓인 처리 결과의 기준이 달라진다.
명시 목표값 평탄화인 `lower_yield`와 별도로, 기존 사건 검출과 하측 포락선을 묶은
`lower_envelope_auto_v1`을 제공한다. 전체 처리의 기본 방법은 바꾸지 않는다.

v1은 사건 범위, 하강·회복 문턱 각각 0.005, 최소 기준 봉우리 비율 0.05,
최소 기울기 0, 미회복 말단 원본 보존으로 고정한다. 수동 구간·목표값과 다른 수치
옵션은 적용하지 않고 그 사실을 노트에 남긴다. 입력 열 이름은 선택할 수 있다.
자동 규칙의 변경은 새 프로필 ID로 구별한다. 자유 설정은 기존 수동 방법에서 한다.

계산 단계의 `StepResult.effective_options`가 있으면 커널은 그 사본을
`Stage.options`에 기록한다. 따라서 기존 저장 경로로 실제 사용한 옵션과 프로필
ID가 남고, 요청 당시 `steps_snapshot`은 그대로 보존된다. 별도 DB 필드는 추가하지
않는다. 일반 기본값을 묵시적으로 적용하는 방식은 나중에 기본값이 바뀌었을 때
무엇을 사용했는지 구분하기 어려워 채택하지 않는다.

실제 편집 여부와 검토 필요 여부는 별도 진단으로 남긴다. 미회복 말단만 있으면
편집하지 않으며, 관측 종료까지 열린 부분 회복도 검토 대상으로 표시한다. 사건이
없다는 결과는 v1 검출 기준에 한정한다. 변형률 중복·역전은 전역 정렬로 숨기지 않는다.

실자료의 PC1과 MTIL-M03B2024_1에서는 회복 구간 끝점이 보호 말단의 봉우리와
겹쳐, 바꾸지 않은 기존 말단 하강까지 접합 오류가 됐다. 보호 경계 양쪽 값이 모두
원본과 같을 때만 기존 하강을 허용하고 남은 하강으로 기록한다. 편집으로 생긴 하강은
이 예외로 허용하지 않는다. 자동 하측 곡선의 계산 완료는 전체 곡선의 단조성,
규격 하항복 물성 또는 후속 카드 사용 가능 여부의 승인을 뜻하지 않는다.

## 추가 결정: 방법별 자동 설정과 관측점 접합 — 2026-09-23

하측 포락선만 자동으로 만들면 다른 방법에서는 시험마다 구간을 다시 정해야 한다.
상측·하측 포락선, 단조 회귀, 중앙값 평탄부, 양끝 직선, 최소제곱 직선, Huber 직선에
각각 고정된 자동 v1 프로필을 제공한다. 기존 수동 방법과 전체 레시피의 기본값은
유지한다. 기본 프로필 선택과 실제 설정 저장에는 앞서 도입한 경로를 그대로 쓴다.

실자료의 검출 사건을 그대로 회귀 구간으로 쓰면 시작 봉우리보다 낮은 다음 봉우리가
끝점으로 선택된다. 양끝 직선의 비감소 조건이 불가능해지고, 다른 직선·평탄부 방법은
원곡선과의 접합에 하강을 만들거나 공유 끝점인 보호 말단을 바꾼다. 따라서 네 자동
근사 프로필은 적합 구간과 원값으로 남길 양쪽 관측 앵커를 구별한다.

오른쪽 앵커는 검출 사건의 끝 관측점으로 고정하며, 그 뒤 미회복 말단을 목표값으로
사용하지 않는다. 왼쪽은 실제 적합 시작값에 연결 가능한 가장 가까운 이전 관측점으로
정한다. 초기 자동 E 평가 후보 구간은 보존하며, 후보가 없으면 초기 상승부의 40%
응력 도달 행을 보수적인 경계로 쓴다. 이 보호 경계가 탄성계수의 타당성을 승인하는
것은 아니다. 겹치는 사건은 병합하고, 보호 영역을 넘어야 하면 해당 자동 처리를
보류한다. 관측 행을 정렬하거나 제거하지 않는다.

양끝 직선은 앵커를 직접 잇는다. 중앙값·OLS·Huber는 양쪽 앵커 응력 사이의
비감소 적합값을 구하고 짧은 직선 연결 구간으로 이어 붙인다. OLS와 Huber는
직선의 두 끝값에 제약을 주어 계산하며, 점별로 잘라 직선을 다른 모양으로 바꾸지
않는다. 선택된 구간·앵커·연결·제약·변경량을 결과에 기록한다. 큰 근사를 허용할지는
모델 정책이므로 실자료 통과율에 맞춰 임의의 잔차 허용 한도를 추가하지 않는다.

상측 포락선이 이전 봉우리보다 낮은 보호 말단에 닿으면 상측 조건과 원값 보존을
동시에 만족할 수 없다. 이 경우 다른 방법으로 바꾸지 않고 보류한다. 기존 하측
자동 v1의 곡선·설정은 유지한다. 기존 E·내력·진소성 계산과 실제 카드 조건은 처리
곡선 검증과 별도로 비교한다.

## 측정값과 모델 입력의 순서

E는 근사 전 시험곡선에서 평가하고 후속 모델 근사에 고정된 값으로 전달한다.
근사된 최대응력으로 E의 자동 응력 띠를 다시 고르면 E가 선택한 근사법에 따라
달라질 수 있다. 원곡선에서 평가한 내력·교점 좌표·최대하중 위치의 후보도 먼저
기록한다. 모델 곡선의 시작 항복점과 원측정 내력은 별도 대상이다.

현재 표준 목록에는 하강 단계가 없지만, 추가 시 등록 순서 35가 E의 50보다
앞에 들어간다. 또한 모델 곡선에서 내력을 다시 계산하면 같은 `proof_stress`
키를 덮는다. 이 두 연결 문제는 단순히 곡선 근사 함수를 바꾸어 해결되지 않는다.
이번에는 E를 먼저 고정한 명시 비교 레시피에서 단계별 측정값과 모델값을 나눠
검증한다. 방법별 권장 위치와 측정값·모델 앵커의 정식 저장 계약은 후속 개선으로
남기며, 기존 레시피의 순서를 일괄 변경하지 않는다.
