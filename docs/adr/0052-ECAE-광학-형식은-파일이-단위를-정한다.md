# 0052. ECAE · 광학 형식 — 파일 형식이 단위를 정하고, 주파수 · 파장 표가 카드까지 간다

날짜: 2026-10-02
상태: 채택
관련: [ADR 0048](0048-선언-물성은-온도-주파수-파장-중-한-축을-탄다.md)(조건 축) ·
[ADR 0036](0036-나가는-숫자의-기본-단위계는-mm-N-tonne.md)(기본 계 mm·N·tonne) ·
[ADR 0038](0038-정의-문법을-넓혀-기본-형식을-정의로-옮긴다.md) · [ADR 0047](0047-기본-형식-정의판은-배포가-꺼진-채-넣는다.md)(정의판)

## 배경

요청(2026-10-02): 「지원하지 않는 물성 — 특히 eCAE · 광학 CAE 쪽」 을 물었고, 답은 이랬다 — 유전율 · 굴절률은
선언 물성으로 **적을 수는** 있는데(ADR 0048) **어느 덱으로도 못 나간다.** 이어진 요청: 「예제는 없는데,
일반적으로 쓰는 eCAE · 광학 프로그램을 대상으로 해 달라. 양식은 인터넷에서 찾아봐.」

막혀 있던 자리가 넷이었다.

1. **블록이 없었다.** 카드 블록 13개의 칸이 전부 역학 · 열 물성 키였다 — 전기 · 광학 값이 앉을 칸이 없다.
2. **단위계가 전기 단위를 몰랐다.** S/m · Ω·m 는 전류가 들어 mm·N·tonne 이 값을 정하지 않는다(전류를 A 로
   두느냐 mA 로 두느냐에 따라 저항률이 Ω·mm 와 mΩ·mm 로 갈린다). 블록에 그 단위를 들이면 기본 계(mm·N·tonne)
   내려받기가 전부 422 가 된다 — 그 블록을 안 쓰는 Abaqus 덱까지.
3. **선언 값은 첫 점 하나만 카드에 갔다.** Dk 를 1 MHz · 1 GHz · 10 GHz 에 적어도 1 MHz 의 값 하나만 실렸다 —
   고속 신호 해석이 보는 분산이 통째로 빠진다.
4. **대상 형식은 단위가 정해져 있다.** Abaqus · ANSYS 는 단위가 없는 솔버라 고른 계로 옮겨 적으면 된다.
   AEDT(`.amat`) · CST(`.mtd`) · FloXML 은 SI 로 읽히고(CST 는 파일에 선언), Zemax 는
   파장을 µm 로 받는다. 기본 계(mm·N·tonne)의 숫자를 그대로 적으면 **밀도가 10¹² 배 틀린 재료가 오류 없이**
   들어간다.

### 양식의 근거 (인터넷 · 공개 저장소에서 찾아 글자로 대조)

| 형식 | 근거 |
| --- | --- |
| Ansys Electronics Desktop `.amat` | PyAEDT 저장소의 재료 파일(`iron_pyaedt.amat` · `Materials.amat`), 공개 HFSS 프로젝트의 `permittivity='pwl($Dk,Freq)'` + 주파수 데이터셋(Hz) |
| CST Studio Suite `.mtd` | CST 재료 라이브러리 파일 — `[Definition]` 의 VBA 명령, Schott 유리 재료의 `.DispersiveFittingFormatEps "Real_Tand"` · `.AddDispersionFittingValueEps`, 금 재료의 영률(kN/mm²) · 열팽창(1e-6/K) |
| Simcenter Flotherm FloXML | FloXML 스키마(`XmlAttributes.xsd` · `xmlSchema.xsd`)와 공식 예제, Siemens 의 재료 · IGBT 매크로(온도 의존 `tref` 는 °C + 273.15 = K) |
| ANSYS APDL | `MP` 라벨 RSVX · PERX · LSST · MURX · EMIS |
| Zemax AGF | Ansys Optics 의 AGF 형식 설명, 공개 카탈로그(Schott · Zeon) — 식 번호 1 = Schott 식 |
| CODE V | 공개 `.seq` 파일의 `PRV / PWL … / '이름' … / END` |
| n,k 표 | Lumerical 재료 데이터베이스 Import data 설명(파장 · n · k 세 열) |

## 결정

1. **블록 둘을 코드로 더한다** — `electrical`(비유전율 · 유전손실 · 비투자율 · 전기전도율 · 체적저항률 · 저항
   온도계수, 표의 축 `frequency`)과 `optical`(굴절률 · 소광계수 · 아베수 · 방사율, 표의 축 `wavelength`). 칸마다
   문헌 키를 든다. 기본 물성 항목 넷(비투자율 · 소광계수(파장) · 아베수 · 방사율)과 그 연결을 씨앗에 더한다.
2. **계가 정하지 않는 단위는 어느 계에서나 SI 그대로다**(`systems.UNSCALED` — S/m · Ω·m). 값도 기호도 SI 로
   두고, 계의 기호표에는 안 넣는다(「이 계가 옮겼다」 로 읽히지 않게). 이 값을 싣는 형식은 값마다 단위를 적는
   것(중립 JSON)이거나 단위가 정해진 것뿐이다.
3. **형식이 단위를 정했으면 렌더러가 그것을 선언한다**(`Renderer.fixed_units`). `render` 가 고른 계 대신 그 계로
   옮기고, 파일 이름 · 덱 검사 · 묶음 · BOM 이 같은 답을 본다(`export.effective_system`). BOM 은 한 파일 한 계라
   줄마다 바꾼 형식이 다른 계를 정해 두었으면 그 줄을 이유와 함께 뺀다. 형식 목록이 `fixed_units` 를 싣고, 화면이
   형식 줄에 「단위는 형식이 정합니다 — SI」 를 적는다. 정의(템플릿)도 `"units": "si"` 로 같은 선언을 한다.
4. **선언 값의 주파수 · 파장 점을 블록의 표로 편다**(`declared_slots.fill`). 블록 표에 `frequency` · `wavelength`
   열이 있으면 그 축의 표다. 점이 여럿인 항목만 펴고, 축 값을 합집합으로 모아 없는 칸은 비운다(0 으로 채우면
   손실 0 인 재료가 된다). 한 점짜리 값은 표에 안 넣는다 — 모든 줄에 넣으면 「주파수와 상관없다」 를 우리가
   정하는 셈이다. 표가 이미 있는 블록은 안 건드린다. 값 하나에는 어느 주파수 · 파장 · 온도의 값인지가 따라간다
   (`<칸>_frequency_hz` · `_wavelength_m` · `_temperature_k`) — 이름이 단위를 말하므로 계를 바꿔도 안 옮긴다.
5. **형식 일곱** — AEDT · CST · Flotherm · ANSYS(전기) · Zemax AGF · CODE V · n,k 표. 공통 규칙:
   - **없는 값을 만들지 않는다.** 비투자율을 모르면 안 적는다(솔버 기본값 1 이 쓰인다). σ = 1/ρ 는 정의라서
     옮기되 그렇다고 적는다. n,k 표는 세 열을 요구해 k 가 없는 파장을 0 으로 적고 몇 개인지 말한다.
   - **표를 못 실으면 말한다** — AEDT 의 온도 표, ANSYS 의 TCR · 주파수 표, CST 의 비투자율 표.
   - **Flotherm 은 값 하나씩만 적는다**(2026-10-03 대조로 고쳤다). FloXML 은 원소마다 온도 단위가 다르다 —
     열전도 온도 의존 `tref` · 주변 온도는 켈빈(Siemens 매크로가 °C + 273.15)인데 제어 곡선 · 고정 온도는 °C 로
     보인다. 열전도 곡선의 온도, 저항률 기준 온도, 저항률 계수가 상대값(1/K)인지 절대값(Ω·m/K)인지는 공개 근거가
     없다. 틀리면 곡선이 273 K 밀리거나 구리 저항률이 10⁸ 배가 되므로 표 · 계수는 싣지 않고 그렇다고 말한다.
     처음에는 재료 스프레드시트의 열 머리 「(deg C)」 만 보고 °C 로 적었다 — 매크로가 더하는 273.15 를 못 봤다.
   - **분산식은 Zemax 만 우리가 맞춘다**(`matcore.dispersion`) — Schott 식은 n² 에 대해 계수가 일차라 최소제곱이
     닫힌 꼴로 풀리고 같은 점에서 늘 같은 계수가 나온다. 항은 점보다 하나 적게(최대 여섯) — 잔차를 볼 자유도를
     남긴다. 맞춤 결과(항 수 · 최대 잔차)를 늘 알리고 1e-4 를 넘으면 짚는다. CST 는 점을 넘기고 맞춤은 CST 가 한다.
6. **정의판** — 여섯은 정의판을 씨앗에 둔다(50 → 56). Zemax AGF 는 계수를 **맞춰야** 해서 정의 문법이 할 일이
   아니다 — JSON 과 함께 코드판만 둔다(ADR 0023 「계산이 필요하면 코드로」).

## 대안

- **전기 단위를 계에 넣어 옮긴다**(mm 계의 저항률 = Ω·mm). 전류 단위를 우리가 정하는 일이다 — ANSYS
  Workbench 의 「mm, t, N, s, mV, mA」 와 「mm, t, N, s, V, A」 에서 값이 다르다. 기각.
- **형식마다 렌더러가 SI 로 거꾸로 옮긴다.** `to_system` 이 이미 옮긴 덱을 다시 SI 로 되돌리는 셈이고, 새 렌더러가
  빠뜨리면 조용히 틀린다. 형식이 「나는 SI 로 받는다」 를 선언하고 옮기는 곳은 한 곳에 두는 편이 낫다. 기각.
- **Zemax 에 Sellmeier 식으로 맞춘다.** 공명 파장이 분모에 있어 비선형 맞춤이고 시작값에 따라 답이 갈린다 —
  같은 카드가 같은 AGF 를 내야 덱이 재현된다. 기각(플라스틱 카탈로그가 Schott 식을 쓴다).
- **주파수 표를 블록마다 따로 짓는다**(declared_card 처럼). 블록 이름을 코드에 적는 일이 다시 생긴다 — 표의
  축 열 이름(`frequency` · `wavelength`)을 규약으로 두면 확장 블록도 따라온다.

  쓰는 사람이 재료 하나로 읽혀 값이 그대로인지 보고 알려 주면 여기 적는다.

  이방성(PCB 면내 · 두께 방향 Dk, 직교 열전도)도 아직 하나의 값이다.
