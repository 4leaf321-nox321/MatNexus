# 0075. 2구간 S-N 은 따로 선 블록이고, 꺾임은 전수 탐색으로 찾는다

날짜: 2026-11-14
상태: 채택
관련: VOC 61 · [0066](0066-DMA-온도별-탄성률-표는-점탄성-탭에서-만들고-탄성계수와-따로-싣는다.md)(S-N 그래프 덧붙임)

## 배경

VOC 61: 「S-N 곡선이 두 구간(bilinear)으로 꺾이는 거동을 물성 카드에 넣고 싶다」. HyperLife 같은 피로
도구는 Slope-intercept 2-segment(SRI1 · b1 · Nc1 · b2 · SE)로 이 꼴을 받는다. 제안은 둘이었다 — ① 플랫폼
자동 2구간 피팅(같은 시험군의 파단점으로 Nc1 · b1 · b2, 런아웃은 피팅에서 빼되 그래프에 표시, 기존 1구간
유지), ② 로컬에서 맞춘 값을 카드에 직접 입력. 작성자는 로컬 구현에서 꺾임 탐색을 첫 값 ±0.25 자릿수 안에서만
검증했고, 플랫폼 안에서 여러 번 계산해 값을 찾을 수 있을지 확실하지 않다고 했다.

확인한 것(2026-11-14):

- S-N 은 전부 피로 확장(`extensions/fatigue`)이다 — 묶음 · 블록 `sn_curve` · 덱 셋(LS-DYNA `*MAT_ADD_FATIGUE`
  LCID=-3 · OptiStruct `MATFAT` · Nastran `MATFTG`). MATFAT · MATFTG 는 이미 `SRI1 B1 NC1 B2` 칸이 있고
  `B2 = B1` 로 냈다.
- 덱 정의판 셋(`*_fatigue_def`, 씨앗)이 `sn_curve.basquin_a · b` 를 읽는다.
- 카드는 계산에서만 생기고 값을 고칠 길이 없다(`PATCH` 는 이름 · 메모만) — ②는 새 경로가 된다.
- 블록 그래프 선언(`PowerLine`)은 멱함수 선 하나만 그렸다.
- LS-DYNA 매뉴얼: R11 은 S-N 구간 카드(`Ai Bi STHRESi`)를 LCID -1 · -2 에만, R13 은 LCID < 0 전부에 연다.

## 결정

1. **방법 ①만 한다**(사용자 결정). ②는 ①이 덮지 못하는 경우(플랫폼에 시험이 없는 외부 계수)가 생기면 그때.
2. **꺾임은 전수 탐색**. 꺾임을 정하면 연속인 두 직선이 선형이라(`log N = y_k + c1·max(x-x_k,0) +
   c2·min(x-x_k,0)`) 한 번에 풀린다. 구간마다 파단점이 최소 수(기본 3)만큼 드는 응력 범위 전체를 400칸으로
   훑고 가장 좋은 칸을 다듬는다 — 초기값 · 수렴 문제가 없고 같은 점이면 같은 답이다. 회귀 방향은 한 직선과 같다
   (수명을 응력에, E739). 런아웃은 뺀다.
3. **1 · 2구간은 막지 않고 판정을 낸다**(사용자 결정 — 권장안). 2구간은 계수가 많아 늘 조금은 낫다. 한 직선과
   견준 F 검정(2 · n-4)과 ΔBIC 가 둘 다 2구간 쪽이어야 「근거 있음」, 아니면 「2구간 근거 약함 — 한 직선 권장」
   경고와 `bilinear_supported = 0`. 카드를 만들지는 사람이 정하고, 덱 알림에도 따라간다.
4. **블록을 가른다**(`sn_bilinear`). 같은 블록이면 정의판이 2구간 카드에서 둘째 기울기를 버리고 한 직선 덱을
   **조용히** 낸다. 블록이 다르면 양쪽 형식이 서로의 카드를 「모자란 블록」 으로 거절한다.
5. **LS-DYNA 는 S-N 구간 카드**(LCID=-3 + Card 2a, STHRES1 = 꺾임 응력, STHRES2 = 0), 덱에 「R13 이상」.
   MATFAT · MATFTG 는 SN 줄을 2구간 그대로(SRI1 = 2·A1 범위 절편).
6. **그래프 선의 선언에 꺾임**(`PowerLine.knee` · `exponent2`, 중심). 카드와 묶음 결과 화면이 같은 선언으로
   그리고, 묶음 결과는 계수 키가 결과에 있는 블록을 고른다.

## 대안

- **같은 `sn_curve` 에 `model=bilinear`** — 칸 · 그래프 · 덱을 덜 만들지만 정의판이 조용히 한 직선을 낸다. 기각.
- **LS-DYNA 곡선(LCID > 0, LTYPE = 1 log-log)** — 점 셋으로 정확하지만 `*DEFINE_CURVE` 의 축(N · S)이 매뉴얼에
  없다. 기각. **LCID = -1 구간 카드**(R11 도 받음) — `a = A^(-1/b)` 가 MPa 에서도 10^49 를 넘어 단정밀도가 못
  읽는다. 기각.
- **국소 탐색**(첫 값 둘레, 로컬 구현) — 꺾임이 범위 끝에 있으면 못 찾는다(사보타주: 앞 · 뒤 30 % 만 훑으면 시험이
  문다). 기각.
- **판정이 약하면 2구간을 막는다** — 데이터가 적은 시험군은 2구간을 아예 못 쓴다. 기각(사용자).

  `PowerLineOut`, 화면 `plotLine.ts`(꺾인 선) · `GroupsPanel`(그래프 고르기). 확장 계약서 · 가이드 씨앗.
- 시험: 합성 2구간을 1e-5 안에서 되찾음 · 꺾임이 범위 양 끝이어도 찾음 · 같은 점이면 같은 답 · 직선은 근거 약함
  · 덱 칸(매뉴얼 자리) · 덱에서 되읽은 수명이 곡선과 같음 · 한 직선과 2구간 형식이 섞이지 않음 · 표 입력부터 덱까지.
  사보타주 아홉 전부 물었다.
- 한 직선의 묶음 · 카드 · 덱은 그대로다(덱 글자 · 기존 시험 그대로).
- 2구간 덱 셋은 **코드판만** 둔다(정의판 짝 없음, `test_export_twins.CODE_ONLY`) — 정의판은 이어짐 검사와
  「근거 약함」 알림을 못 해 이어지지 않는 카드를 그대로 낸다(폼 덱과 같은 판단). 파일 이름 꼬리는
  `_fatigue2seg` — 한 직선(`_fatigue`)과 같은 카드에서 나와도 이름이 안 겹친다.
- **남은 것**: VOC 담당의 시험군 데이터와 로컬 결과로 견주는 회귀 시험(요청함). 런아웃을 버리지 않고 하한으로 쓰는
  추정(중도 절단 자료)은 한 직선과 함께 따로 볼 일이다.
