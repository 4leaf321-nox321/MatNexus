# 0096. 시험에 곡선 출처를 적고, 곡선 모양으로 거꾸로 짚되 막지 않는다

날짜: 2026-11-17
상태: 채택
관련: [ADR 0093](0093-덱은-소성-없이-나간-줄을-빠짐없이-알리고-받는-덱의-탄성-값을-지킬-수-있으며-출처를-덱-글자가-든다.md)(같은
연결의 덱 결함) · [ADR 0078](0078-물성-사용-보류는-자료-관리자가-걸고-채택-카드-통계에서-뺀다.md)(빼는 길은 보류)

## 배경

HWAX 연결에서 해석 덱 카드(*MAT_024 의 소성 표)에서 복원한 곡선이 「시험」 으로 들어와 실측처럼 쓰였다고 했다. 코드로
확인한 것: 덱 파일을 읽어 시험을 만드는 길은 없지만, 덱 곡선을 CSV 로 바꿔 올리면 막을 것도 표시할 칸도 없었다 —
시험에 출처 칸이 없고(`Curve.kind` 는 장비 계산 곡선을 가를 뿐), MCP `get_test_run` 은 채택 값마다 `origin: measured`
를 고정으로 붙였다. 문헌 쪽에서는 디지타이즈 곡선이 덱 각주에 「문헌 실측 곡선」 으로 적혔고(벌의 `method` 를 안
읽었다), 탄성 구간 없이 시작하는 곡선을 첫 점을 항복으로 보고 공칭 → 진응력으로 한 번 더 바꿨다.

사용자 결정(2026-11-17): 덱 복원 곡선은 **경고만**(통계 · 카드에서 빼지 않는다).

## 결정

1. **시험에 곡선 출처 칸**(`test_runs.curve_origin`, 마이그레이션 `d4a8c2e61b37`, 기본 `measured`) —
   `measured` · `digitized` · `deck_restored` · `synthetic`(`shared/curve_origins`). 올릴 때(화면 「곡선 출처」 ·
   API · MCP `upload_test_run`) · 고칠 때(PATCH, 감사에 남는다) 적는다. 모르는 코드는 거절(`MNX-TESTS-0047`).
2. **경고만 한다.** 실측이 아닌 시험으로 만든 카드는 근거 경고(「실측이 아닌 곡선」, `_stale_warnings` 와 같은 자리)와
   덱 머리 줄을 단다. 시험 상세에 배지, MCP `get_test_run` 의 `origin` 은 시험의 출처 그대로 · `origin_caveat`.
   커버리지는 출처 분류(`measured`)를 바꾸지 않고 방법 글자에 「실측이 아닌 곡선 N건」 — 잰 값의 수가 달라지지
   않게. 빼고 싶으면 사용 보류(ADR 0078)가 그 길이다.
3. **곡선 모양으로 거꾸로 짚는다**(`matcore/curve_quality`, `GET /processing/test-runs/{id}/curve-quality`, MCP
   `curve_quality`, 도구 134개). 채택 결과(없으면 공칭 응력-변형률 열이 있는 최근 결과)의 곡선에서:
   첫 점 응력 · 꺾임(두 직선 맞춤의 앞 · 뒤 기울기) · 초기 기울기/영률 · 꺾임 뒤 기울기/영률(영률은 재료에 적어 둔
   값) · 점 사이 직선성(표에서 다시 만든 곡선). 모양은 `nominal` · `plastic_table` · `rebuilt` · `unclear`. 출처가
   실측인데 모양이 소성 표 · 다시 만든 곡선이면 `agreement` 경고.
4. **앞부분이 잘린 잰 곡선을 소성 표로 읽지 않는다.** 첫 점이 높아도 원점에서 첫 점까지의 할선 기울기만큼 첫 점 뒤로
   직선이 이어지면(첫 점 뒤 기울기 ÷ 할선 ≥ 0.1) 앞부분이 잘린 것이다 — 영률 없이 가른다. 개발 DB 의 채택된 인장
   45건: 공칭 27(앞부분이 잘린 SPCC 0.35 포함) · 소성 표 모양 12(탄성 구간 없이 항복점에서 시작하는 데모 곡선
   SCATTER_DP600, 0.01 안팎) · 다시 만든 곡선 6(흐름 점검용으로 지은 곡선).
5. 문헌 쪽: 디지타이즈 곡선은 「문헌 곡선(그림에서 읽음)」 으로 적고, 탄성 구간 없이 시작하는 곡선에는 「이미 진응력 ·
   소성 표라면 변환이 두 번」 을 덧붙인다.

## 대안

- **실측이 아니면 통계 · 카드에서 뺀다** — 사용자 결정으로 하지 않았다. 디지타이즈한 문헌 곡선처럼 쓸 만한 것도 있고,
  빼는 판단은 보류(ADR 0078)가 사람에게 맡긴다.
- **곡선 모양만으로 출처를 정한다** — 덱 표에 탄성 직선을 붙여 다시 만든 곡선은 모양이 잰 곡선과 같다(점 사이
  직선성만 다르다). 사람이 적은 출처와 모양이 말하는 것을 둘 다 두고, 어긋남을 말한다.
- **덱 파일(.k)을 시험으로 읽는 형식을 만든다** — 그 곡선을 시험으로 만드는 길을 더 여는 것이다. 덱 값은 카드 ·
  문헌 쪽의 것이다.
